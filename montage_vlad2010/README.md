# montage_vlad2010

Монтаж 3 роликов под тегом `влад2010` (студия, холодный сет).

## Источники

| файл | длительность | release asset |
|---|---|---|
| video1.mp4 | 27.160с | `Untitled.Video.2010.1_2160p.mp4` (158 507 346 байт, sha256 `96740174...` по release API) |
| video2.mp4 | 25.960с | `Untitled.Video.2010.2_2160p.mp4` (152 289 102 байт, sha256 `7e7cdcb2...` по release API) |
| video3.mp4 | 24.440с | `Untitled.Video.2010.3_2160p.mp4` (143 664 665 байт, sha256 `ddaaa8c1...` по release API) |

Скачаны из релиза `влад2010`, все три совпадают по размеру с release API.

## Комната и герой

Референс-кадры (`ffmpeg -ss 10 -frames:v 1`) сравнены с историческими батчами. Подтверждена знакомая студия: серый вязаный свитер, нейтральная бежево-серая стена, характерная поза с опорой на скрещённые руки на столе — та же линия, что в `vlad1610`/`влад1710`. Пайплайн унаследован от **`влад1710`** (самый свежий батч этой студии).

## Проверка на дубли (§8)

Длительности всех трёх видео (27.160с, 25.960с, 24.440с) сверены с исторической базой героя — точных совпадений не найдено. Содержание всех трёх тематически различно (тестовая часть ЕГЭ по русскому / 16-е задание, запятые / приставки), слово «ссылка» встречается в транскрипте каждого видео ровно один раз.

## Палитра

Комната и сет холодные, без переключения — продолжение исторической классификации студии «влад» (`#C9F5FF`). `pipeline.py` унаследован от `влад1710` без правок.

## ASR-правки

Пайплайн: sherpa-onnx zipformer (ru) + silero VAD → `asr_batch.py` → `build_words.py` → ручная правка через `apply_fixes.py`, каждая неоднозначная правка проверена `redecode_ts.py` перед применением.

- **Все три видео:** `"егэ"` → `"ЕГЭ"` (регистр).
- **video1:** CTA — широкий передекод 24.6-27.1с подтвердил отдельный токен «в» перед «шапки» (токенизатор не выделил его отдельным словом), «шапки» → «шапке».
- **video2:** CTA («ссылка на тренажёр в шапке профиля») распознана полностью и чисто, без фиксов кроме регистра.
- **video3:** CTA — широкий передекод 21.9-24.5с подтвердил отдельный токен «в» перед «шапки», «шапки» → «шапке».

Транскрипты в этой партии получились чистыми — без гарблинга «в ЕГЭ» и без пропущенных сегментов, в отличие от предыдущих батчей кампании. После применения правок — проверка на пересечения временных меток слов: пересечений и отрицательных длительностей не найдено ни в одном видео.

`build_words.py`, `asr_batch.py`, `pipeline.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` унаследованы из `влад1710` без правок кода (кроме имени ASS-файла в `gen_render.py`).

## Карточки и тайминги

`data1.py`/`data2.py`/`data3.py` — хук (0-2.6с, акцентный, формулирует боль по конкретной теме, не пересказ первой фразы) + 9-11 карточек на видео (1-3 слова, кегль 85-95/40-48px) + бегущая подпись (из слов, PT Sans Narrow Bold) + 4 эмфасис-зум окна на ролик. Валидация пройдена (`validate.py`): нет пересечений карточек/хука/зума, последняя карточка заканчивается точно на DURATION, хук закрывается строго до первой карточки.

- video1 (тестовая часть ЕГЭ по русскому): хук «ТЕСТОВАЯ ЧАСТЬ / ПО РУССКОМУ БЕСИТ?», 11 карточек, CTA.
- video2 (запятые, задание 16): хук «ЗАПЯТЫЕ В 16-М / СТАВИШЬ НАУГАД?», 10 карточек, CTA.
- video3 (приставки): хук «ПИШЕШЬ ПРИСТАВКИ / НАУГАД?», 9 карточек, CTA.

Иконка приложения (ЕГЭ ТРЕНАЖЁР) появляется на оба голосовых упоминания в каждом ролике (автоматически по паттерну `тренаж` в `words{N}.json`):
- video1: окна (19.444, 22.444) и (25.468, 27.16)
- video2: окна (15.988, 18.988) и (24.228, 25.96)
- video3: окна (14.348, 17.348) и (22.74, 24.44)

## Громкость

Двухпроходный EBU R128 (`loudnorm.py`, TP-цель −2.0 на обоих проходах, §4.5.1) + финальная проверка TP на готовом AAC-файле. Все три прошли на обычном проходе, лимитер-эскалация не понадобилась:

| видео | pass1 измерено | финальный AAC (после кодирования) |
|---|---|---|
| video1 | I=-21.39 TP=-4.94 LRA=2.90 | I=-14.54 LUFS, TP=-1.79 dBTP |
| video2 | I=-21.10 TP=-3.92 LRA=2.50 | I=-14.81 LUFS, TP=-1.45 dBTP |
| video3 | I=-21.60 TP=-3.95 LRA=2.70 | I=-14.81 LUFS, TP=-1.60 dBTP |

## QA

Стоп-кадры на хук/карточка/иконка/зум/CTA извлечены и просмотрены для всех трёх видео (21 кадр). Хук закрывается строго до старта первой обычной карточки; карточки не вылезают за края кадра, текст не на лице/рту, поля соблюдены; иконка приложения полностью непрозрачна, крупная (280px), справа на уровне головы, не перекрывает лицо, появляется на оба упоминания в каждом ролике; CTA «ссылка в шапке профиля» идентичен во всех трёх; акцент только ледяной голубой, один сет на ролик. Один кадр (video1 на 19.5с) попал в начало fade-in окна иконки — ожидаемо. Ещё один кадр (video3 на 15.0с) показал нечёткую/полупрозрачную иконку, но оба соседних кадра (14.5с и 16.0с, внутри того же, уже полностью проявленного окна) показали полностью чистую непрозрачную иконку — это одиночный артефакт JPEG-экспорта конкретного стоп-кадра, а не дефект рендера или альфа-канала оверлея. Дефектов не найдено.

## Файлы в этой папке

`pipeline.py`, `asr_batch.py`, `build_words.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` — унаследованы от `montage_vlad1710/` без правок кода. `gen_render.py` — правка на один путь (имя ASS-файла `subs_v2010_{i}`). `data1.py`/`data2.py`/`data3.py` — карточки/хук/эмфасис/длительность. `apply_fixes.py` — ASR-правки. `validate.py` — инлайн-проверка таймингов. `asr{1,2,3}.json`/`words{1,2,3}.json` — распознавание речи. `subs_v2010_{1,2,3}.ass` — готовые субтитры. `render{1,2,3}.sh` — сгенерированные ffmpeg-скрипты рендера.

Исходные видео (video1/2/3.mp4) и промежуточные/финальные рендеры НЕ архивируются — только код и транскрипты. Готовые ролики лежат в `work/влад2010/влад2010_{1,2,3}.mp4`.
