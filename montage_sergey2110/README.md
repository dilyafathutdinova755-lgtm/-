# montage_sergey2110

Монтаж 3 роликов под тегом `сергей2110` (тёплый сет, кирпичная стена, книжный шкаф, настольная лампа).

## Источники

| файл | длительность | release asset |
|---|---|---|
| video1.mp4 | 26.796с | `15._1080p.mp4` (23 964 543 байт, sha256 `11c4f4c1...` по release API) |
| video2.mp4 | 24.151с | `18._1080p.mp4` (24 818 449 байт, sha256 `46b276ff...` по release API) |
| video3.mp4 | 22.444с | `_1080p.mp4` (22 223 563 байт, sha256 `e3738804...` по release API) |

Скачаны из релиза `сергей2110`, все три совпадают по размеру и digest с release API.

**Как и в `максим2110`/`дмитрий2110`:** исходники уже лежат в 1080×1920 (не 4K). `gen_render.py` скорректирован — `zoom_segments_filter` вызван с явным `w0=1080, h0=1920`.

## Комната и герой

Референс-кадры (`ffmpeg -ss 10 -frames:v 1`) сравнены с историческими батчами. Подтверждена **кирпичная студия**: светлая льняная рубашка, кирпичная стена, книжный шкаф с настольной лампой, картина с горным пейзажем — та же линия, что в `сергей1510`/`сергей1610`/`сергей1710`. **Не** путать с панельной комнатой `сергей2010` (кремовые панели, оливовое кресло, торшер) — у героя «сергей» две разные физические студии, и хронологически самый свежий батч для каждой считается отдельно. По mtime директорий: `montage_sergey1710` (18 окт) — самый свежий батч именно этой, кирпичной студии (панельная `сергей2010` от 20 окт новее по дате, но другая комната). Пайплайн унаследован от **`сергей1710`**.

## Проверка на дубли (§8)

Длительности всех трёх видео (26.796с, 24.151с, 22.444с) и полные ASR-транскрипты сверены с исторической базой кирпичной студии — точных совпадений не найдено. Темы: обществознание/задание 15, биология/задание 18, обществознание/факторы экономического роста — три разных ролика. Слово «ссылка» встречается в транскрипте каждого видео ровно один раз.

## Палитра

Кирпичная студия продолжает исторический тёплый сет: accent `#FCF5AA`, без переключения. `pipeline.py` унаследован от `сергей1710` без правок цвета.

## ASR-правки

Пайплайн: sherpa-onnx zipformer (ru) + silero VAD → `asr_batch.py` → `build_words.py` → ручная правка через `apply_fixes.py`, каждая неоднозначная правка проверена `redecode_ts.py` перед применением.

- **Все три видео:** `"егэ"` → `"ЕГЭ"` (регистр). CTA во всех трёх — широкий передекод подтвердил отдельный токен «в» перед «шапки»/«тапки» (video1: 25.0-26.8с, video2: 22.5-24.1с, video3: 21.0-22.5с), тот же повторяющийся по кампании паттерн.
- **video1:** `"банка пи пи"` — тот же паттерн, что в этой же комнате в `сергей1710/video1`: «ФИПИ» разбивается на два токена «пи»; широкий передекод 20.8-22.3с подтвердил тот же разрыв («банка пипи»), склеено в «банк ФИПИ» по смыслу и прецеденту этой студии.
- **video2:** `"тренажоре"` → `"тренажёре"` (широкий передекод 15.5-16.6с дал чистое «в ЕГЭ тренажёре» — пропущенная «ё» в узком сегменте); CTA — `"тапки"` (т вместо ш, акустическая ошибка модели) исправлено на «шапке» по тому же передекоду, который дал чистое «в шапке профиля».

После применения правок — проверка на пересечения временных меток слов: пересечений и отрицательных длительностей не найдено ни в одном видео.

`build_words.py`, `asr_batch.py`, `pipeline.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` унаследованы из `сергей1710` без правок кода (кроме `gen_render.py` — см. выше про `w0`/`h0`). `validate.py` принесён из более свежего батча (`дмитрий2110`) — в `сергей1710` этого инструмента ещё не было.

## Карточки и тайминги

`data1.py`/`data2.py`/`data3.py` — хук (0-2.6с, акцентный, формулирует боль отца по конкретному заданию сына, не пересказ первой фразы) + 9-10 карточек на видео (1-3 слова, кегль 85-95/40-48px) + бегущая подпись (из слов, PT Sans Narrow Bold) + 4 эмфасис-зум окна на ролик. Валидация пройдена (`validate.py`): нет пересечений карточек/хука/зума, последняя карточка заканчивается точно на DURATION, хук закрывается строго до первой карточки, зум-окна не пересекаются.

- video1 (обществознание, задание 15, банк ФИПИ): хук «ЗАДАНИЕ 15 ПО ОБЩЕСТВУ / СЫН ЗАВИСАЕТ?», 10 карточек, CTA.
- video2 (биология, задание 18, искали ошибку пальцем): хук «ЗАДАНИЕ 18 ПО БИОЛОГИИ / СЫН НЕ ВИДИТ ОШИБКУ?», 10 карточек, CTA.
- video3 (обществознание, факторы экономического роста, игра на запоминание): хук «ФАКТОРЫ ЭКОНОМИЧЕСКОГО РОСТА / СЫН ЗАБЫВАЕТ?», 9 карточек, CTA.

Иконка приложения (ЕГЭ ТРЕНАЖЁР) появляется на оба голосовых упоминания в каждом ролике (автоматически по паттерну `тренаж` в `words{N}.json`):
- video1: окна (18.62, 21.62) и (24.892, 26.796)
- video2: окна (15.98, 18.98) и (22.276, 24.151)
- video3: окна (14.036, 17.036) и (20.756, 22.444)

## Громкость

Двухпроходный EBU R128 (`loudnorm.py`, TP-цель −2.0 на обоих проходах, §4.5.1) + финальная проверка TP на готовом AAC-файле. Все три прошли на обычном проходе, лимитер-эскалация не понадобилась:

| видео | pass1 измерено | финальный AAC (после кодирования) |
|---|---|---|
| video1 | I=-17.04 TP=-3.19 LRA=2.10 | I=-14.10 LUFS, TP=-1.82 dBTP |
| video2 | I=-17.77 TP=-3.24 LRA=3.60 | I=-14.28 LUFS, TP=-1.66 dBTP |
| video3 | I=-17.37 TP=-3.19 LRA=2.80 | I=-14.35 LUFS, TP=-1.83 dBTP |

## QA

Стоп-кадры на хук/карточка/иконка/зум/CTA извлечены и просмотрены для всех трёх видео (12 кадров). Хук закрывается строго до старта первой обычной карточки; карточки не вылезают за края кадра, текст не на лице/рту, поля соблюдены; иконка приложения полностью непрозрачна, крупная (280px), справа на уровне головы, не перекрывает лицо, появляется на оба упоминания в каждом ролике; CTA «ссылка в шапке профиля» идентичен во всех трёх; акцент только сливочно-жёлтый `#FCF5AA` (тёплый сет студии), один сет на ролик. Эмфасис-зум отработал корректно на уже-1080p источнике после правки `w0`/`h0` в `gen_render.py` — длительности рендеров совпадают с DURATION. Дефектов не найдено.

## Файлы в этой папке

`pipeline.py`, `asr_batch.py`, `build_words.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` — унаследованы от `montage_sergey1710/` без правок кода. `gen_render.py` — правка на имя ASS-файла (`subs_s2110_{i}`) и на явный `w0=1080, h0=1920` в вызове `zoom_segments_filter`. `validate.py` — принесён из `montage_dmitry2110/` (инлайн-проверка таймингов карточек/хука/зума). `data1.py`/`data2.py`/`data3.py` — карточки/хук/эмфасис/длительность. `apply_fixes.py` — ASR-правки. `asr{1,2,3}.json`/`words{1,2,3}.json` — распознавание речи. `subs_s2110_{1,2,3}.ass` — готовые субтитры. `render{1,2,3}.sh` — сгенерированные ffmpeg-скрипты рендера.

Исходные видео (video1/2/3.mp4) и промежуточные/финальные рендеры НЕ архивируются — только код и транскрипты. Готовые ролики лежат в `work/сергей2110/сергей2110_{1,2,3}.mp4`.
