## ASR-правки

- video1: искажённый токен «чай» (12.204-12.424) — не расслышан с первого раза в фразе «из-за которого чай заданий там уже»; повторное распознавание сегмента с контекстом подтвердило «часть» («...из-за которого часть заданий там уже»); далее токен «актуальны» также оказался искажением — повторное распознавание дало «уже неактуально» (отрицание было потеряно при первом проходе); «банка» → «банк», «фипи» → «ФИПИ» (регистр); «шапте» → «шапке»; клэмп переполнения времени последнего слова (23.2→23.16).
- video2: без явных искажений (компаунд «самовычисление» подтверждён повторным распознаванием как реально произнесённое слово, не правился); «шапки» → «шапке», «профиль» → «профиля»; клэмп переполнения времени последнего слова (23.104→23.05).
- video3: спурный токен «в» перед «слова» удалён — повторное распознавание дало «два похожих слово исключения» без «в»; «иг» → «ЕГЭ» (искажённое распознавание, подтверждено контекстом «для ЕГЭ»); «тренажоря» → «тренажёре»; «который» → «которые» (подтверждено повторным распознаванием — «которые тренирует», согласование с «игры» не идеальное даже в реальной речи, не правилось дальше); «шагте» → «шапке».

`build_words.py` и `asr_batch.py` унаследованы из `никита3009` без правок кода.
