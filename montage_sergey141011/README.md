## Решение — переиспользование готового монтажа

Видео и аудио байт-в-байт идентичны `сергей1410`, поэтому полный пайплайн (ASR, передекоды, дизайн карточек, рендер) заново не запускался. Переиспользованы уже готовые, прошедшие QA результаты монтажа `сергей1410`:

- Все код/данные-файлы в этой папке — точные копии из `montage_sergey1410/`, без изменений содержания.
- `subs_s141011_{1,2,3}.ass` — переименованы (sed) из `subs_s1410_*.ass`, содержимое идентично.
- `render{1,2,3}.sh` — скопированы без изменений; внутри всё ещё ссылаются на старые имена файлов субтитров (`subs_s1410_*`) — ожидаемо для архивной копии, фактический рендер не перезапускался.
- Финальные видео для доставки получены из уже готовых `comp{1,2,3}.mp4` (`crf23`) из `sergey1410`, без повторного прохода через ffmpeg-рендер/loudnorm/QA.

Комната и герой (панельная комната, тёплый сет), карточки/тайминги, ASR-правки, QA — полностью описаны в `montage_sergey1410/README.md`, этот батч их не меняет.
