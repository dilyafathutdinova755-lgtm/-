## ASR-правки

- **video1:** «егэ» → «ЕГЭ» caps (дважды). «пи»+«пи» слипшиеся токены → объединены в «ФИПИ» (подтверждено передекодом сегмента 13.0-14.5с: «банк пи пи» → «банк фипи» по смыслу). Отдельный искажённый токен «пипи» → «ФИПИ» (подтверждено передекодом сегмента 15.3-18.3с: «на заданиях фипи не дожидаясь точной цифры»). CTA ASR сразу распознал корректно («ссылка на тренажёр в шапке профиля») — вставки «в» не потребовалось. Тайминг последнего слова — clamp до 20.631.
- **video2:** «егэ» → «ЕГЭ» caps (дважды). CTA ASR распознал корректно без правок. Тайминг последнего слова — clamp до 21.911.

Все правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `сергей071011`, адаптированы под 2 видео вместо 3 (цикл `for idx in ['1','2']`).
