## Проверка на дубли (протокол §8)

Комната визуально совпадает с батчем **владик11** (та же ниша с полками, гипсовый бюст, бежевое кресло, серый свитер). Это визуальное совпадение с конкретным прошлым батчем (не просто «тот же спикер») запустило усиленную проверку:

- Сверка sha256 против всех 18 исторических исходников влад-семьи (vlad, vlad2, vladik, vladik1, vlad11, vladik11) — совпадений нет.
- Полный ASR-транскрипт сверен именно с владик11 (не просто «с семьёй») — три новых, ранее не звучавших сюжета:
  1. У задания ЕГЭ нет метки версии, как в игре.
  2. Ошибка засчитывается как поражение только после честной повторной попытки, а не при подглядывании.
  3. В приложении нет игровой валюты и платных бустеров, в отличие от pay-to-win игр.

Ни один сюжет не пересекается с тремя сюжетами владик11 (очки против процентов, транскрипт объяснения видео, рейтинг в лидерборде). Дубликат исключён.

## Палитра

Пиксельный замер фона (R/B ratio): 1.131 / 1.124 / 1.128 → холодный сет, совпадает с владик11 (≈1.19-1.20). `pipeline.py` унаследован уже с холодным акцентом (`ACCENT = "&H00FFF5C9&"`), переключения не требовалось.

## ASR-правки

- «геймера» → «геймеры» (video1, согласование числа).
- «бустера» → «бустеры» (video3, согласование числа).
- «поиграем» → «по» + «играм» (video3, склеенный токен разделён по времени).
- «игрыздонатом» → «игры» + «с» + «донатом» (video3, склеенный токен разделён на три).
- «профиль» → «профиля» (video3, падеж CTA).

`build_words.py` унаследован из владик11 уже с фиксом бага переполнения времени последнего слова — повторного исправления не потребовалось (проверено через grep перед началом работы).
