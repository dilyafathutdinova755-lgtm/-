# Монтаж «Максим» — 3 ролика (тег `максим1`)

Исходники: релиз с тегом `максим1`. Новый герой (подросток, тёмная
комната, яркая красно-оранжевая лампа, постеры на стене) — первое
появление в этой сессии; отдельные более ранние теги `макс`/`максимка`
в этой ветке не обрабатывались (нет локальных данных для сравнения),
проверка на дубли выполнена по протоколу §8 внутри самой партии —
разные ASR-транскрипты и разные длительности, дублей нет.

Освещение — яркая красно-оранжевая лампа доминирует в кадре, тёмная
комната — классифицирован как **тёплый сет** (§1.2), акцент `#FCF5AA`.

Три новых сюжета:
1. Стыдно было показать результат пробника даже родителям; месяц
   вечерних заходов в ЕГЭ Тренажёр без особой веры; повторный пробник —
   балл вырос на 9 пунктов без репетитора и курсов.
2. Чуть не занял денег у друга на платный курс; друг сам предложил
   сначала попробовать бесплатный тренажёр; деньги друга остались при
   нём, прогресс начался бесплатно и раньше срока.
3. Реакция на комментарий «троечники не доводят до конца ни одно
   приложение дольше трёх дней» — три недели подряд в ЕГЭ Тренажёре
   против трёх дней из комментария, дело не в силе воли, а в формате
   (нечего бросать — всего 15 минут за раз).

Результаты — `../maksim1/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_m{1,2,3}.ass` | готовые субтитры |
| `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1, правка
10.09.2026): все три ролика легли в −1.6…−1.9 dBTP на готовом
AAC-файле, интегральная громкость −14.5…−14.8 LUFS — с первой попытки.
