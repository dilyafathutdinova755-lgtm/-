## Проверка на дубликат (протокол §8, усиленный режим)

1. **sha256** всех трёх новых файлов сверен со всеми 18 историческими файлами семьи (`никита`, `никита2`, `никитааааа`, `никитка`, `никитка1`, `ник1`) — совпадений нет.
2. **Полный ASR-транскрипт** сверен с тремя сюжетами `никитка1` (похожие второстепенные персонажи в литературе, группировка повторяющихся ошибок по темам, исключение вчерашней закрытой темы из задания дня) — новые три сюжета (предмет остаётся бесплатным после открытия всего банка, разбор без личного мнения автора, счёт почти закрытых тем отдельно от общего процента) не пересекаются ни с одним прежним.

## Сюжеты (все три — про историю, разные)

1. **Видео 1** — увлечённый историей выпускник боится, что бесплатный доступ закончится, как только откроется весь банк заданий; тренажёр остаётся бесплатным даже после полного открытия предмета, без перевода на платную основу задним числом.
2. **Видео 2** — в видеоразборе задания по истории личное мнение автора смешивается с фактами по источнику; тренажёр даёт разбор без личных оценок, только последовательность фактов — не нужно вручную отделять факт от чужого мнения.
3. **Видео 3** — важно не общий процент, а сколько тем закрыто почти полностью; тренажёр считает темы, закрытые от 90%, отдельным числом — оно растёт заметнее, чем общий средний процент.

## Правки ASR

- **Видео 1**: «пустники» → «выпускники» (VAD-клиппинг начала слова, повторяющийся паттерн); «уличённые» → «увлечённые» (мисхиринг); «гига тренажёр» → «ЕГЭ тренажёр»; «шапки» → «шапке» (CTA).
- **Видео 2**: «трапте» → «шапке» (искажённая CTA), «профиль» → «профиля» (падеж).
- **Видео 3**: «капте» → «шапке» (искажённая CTA).

## QA

Пройден чеклист §4.6 целиком:
- Хук закрывается до старта первой карточки (gate-check пройден на всех трёх перед рендером).
- Карточки ≤4.01с (все три видео — длинные фразы разбиты на несколько карточек по этой причине).
- Межстрочный интервал 0.90, акцент крупнее белого на ~10%, обводка тонкая.
- Бегущая подпись непрерывна, один слот, без обводки, по одному слову.
- Иконка «ЕГЭ Тренажёр» — 2 окна на видео (по числу упоминаний голосом), непрозрачность 100%, вне лица.
- Эмфасис-зум — 4 акцентные фразы на видео, без наезда друг на друга.
- CTA единый: «ссылка в шапке профиля».
- Стоп-кадры на хуке/карточке+иконке/CTA проверены для всех трёх видео. На видео3 первая проверка CTA (t=30.5с) попала в 0.32с окно фейд-ина иконки и показала полупрозрачный цвет; пересъёмка на t=31.2с подтвердила полную непрозрачность — не дефект.
