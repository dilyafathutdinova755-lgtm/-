# Партия «владик11»

6-й тег для семьи презентера Влад/Владик (после `vlad`, `vlad2`, `vladik`, `vladik1`, `vlad11`). Новая комната: белые стены, деревянный шкаф-ниша с книгами и гипсовым бюстом, бежевое кресло на фоне, серый вязаный свитер — не совпадает ни с одной из прежних комнат семьи (ни с панельной стеной `vlad`/`vlad2`, ни с кремовым креслом `vladik`/`vladik1`/`vlad11`).

## Проверка на дубликат (протокол §8)

1. **sha256** всех трёх новых файлов сверен со всеми 15 историческими файлами семьи (`vlad`, `vlad2`, `vladik`, `vladik1`, `vlad11`) — совпадений нет.
2. **Полный ASR-транскрипт**: все три новых сюжета — про **«выпускников-геймеров»** (очки прогресса как счёт в матче, текстовая расшифровка разбора под шум стрима, рейтинг среди друзей вместо игрового) — тема геймеров не встречалась ни в одной прежней партии семьи, пересечений нет.

Вывод: новая съёмка в новой комнате, не повторная заливка.

## Сюжеты (все три — про выпускников-геймеров, разные)

1. **Видео 1** — геймеры дотошно следят за игровой статистикой, но прогресс по ЕГЭ представляют смутно; тренажёр переводит решённые задания в очки, которые растут как счёт матча — понятно по числу очков, а не по абстрактному проценту.
2. **Видео 2** — во время видеоразбора заданий на фоне стрима половина объяснения теряется из-за шума комментатора; тренажёр показывает текстовую расшифровку разбора прямо под видео — пропущенную фразу можно прочитать глазами, не переключаясь между окнами.
3. **Видео 3** — геймеры привыкли к игровому рейтингу, но не находят ничего похожего в подготовке к ЕГЭ; тренажёр считает место среди друзей по количеству закрытых заданий — меняется сразу после нового результата, без ожидания конца сезона.

## Правки ASR

- **Видео 1**: «они» (искажённый распознанный токен) разбит на «а»+«не» — восстановлена фраза «понятен по числу очков, **а не** по абстрактному проценту».
- **Видео 2**: «показывай» → «показывает» (повторяющийся паттерн неверной формы глагола); удалён спурный вставленный токен «а» между «егэ» и «тренажёр» в CTA («ссылка на егэ **а** тренажёр» → «ссылка на егэ тренажёр»).
- **Видео 3**: «геймера» → «геймеры» (согласование числа с «выпускники»); «находит» → «находят» (согласование числа с подлежащим).

Заново применён фикс `build_words.py` (последнее слово в сегменте больше не вылетает за границу сегмента) — скопирован из партии `vlad11`, где бага ещё не было исправлено; исправлено на месте перед сборкой карточек.
