# Монтаж «Дима» — 3 ролика (тег `димааа`, новая съёмка)

Исходники: релиз с тегом `димааа`. Файлы датированы `15.09`
(`Untitled.Video.15.09.{1,2,3}_2160p.mp4`). Тот же герой, что в
партии `дима1` (очки, редеющие волосы, тёмно-синяя рубашка/поло), но
новая съёмка — домашний кабинет с растением и книжным шкафом вместо
офиса с монитором и доской. Проверено протоколом §8: sha256 не
совпадает ни с одним файлом партии `дима1`, три новых сюжета по ASR —
не дубль.

**Тёплый сет** — определён замером пикселей стены (не только на
глаз): R/B≈1.44-1.49 в разных зонах кадра, заметно выше любого
холодного эталона (1.13-1.26) и в кадре во всех трёх видео виден
включённый тёплый настольный светильник на полке. Акцент `#FCF5AA`,
оранжевый не использован.

## Сюжеты (родительская перспектива)

1. **Сравниваешь с братом из другой школы?** Родители постоянно
   сравнивают результат ребёнка по ЕГЭ с результатом двоюродного
   брата из другой школы. ЕГЭ Тренажёр считает место среди реальных
   одноклассников из своей школы — сравнение построено на одинаковых
   заданиях у всех участников списка, брат из другой программы в нём
   просто не участвует.
2. **Звонишь бабушке уточнить термин?** Родители звонят
   бабушке-учительнице, чтобы уточнить термин ЕГЭ, который ребёнок
   забыл перед контрольной. ЕГЭ Тренажёр хранит такие термины в
   карточках прямо в приложении — карточку можно найти поиском по
   слову за секунду, без срочного звонка родственнику. Звонок бабушке
   остаётся для разговора, а не для проверки термина.
3. **Путает похожие термины на обществознании?** Родители узнают, что
   ребёнок путает похожие юридические термины в задании ЕГЭ по
   обществознанию. ЕГЭ Тренажёр показывает два похожих термина рядом
   и спрашивает, какой подходит к примеру — термин, который спутали,
   возвращается в следующий вопрос ещё раз, и термины перестают
   смешиваться уже через пару таких заданий.

## Исправленные артефакты ASR (до рендера)

1. **Видео 1:** CTA «шапки профиля» → «шапке профиля» (тот же
   повторяющийся падежный сбой, что почти в каждой прошлой партии).
2. **Видео 2:** «забыл перед **контроль**» → «...перед
   **контрольной**» (обрезанное слово); «за секунду **бессрочного**
   звонка родственнику» → «...**без срочного** звонка родственнику»
   (два слова слились в одно бессмысленное — «бессрочный звонок» не
   имеет смысла в контексте, а «без срочного звонка» точно
   продолжает мысль ролика); CTA «шапке **профиль**» → «...**профиля**»
   (пропущено окончание).
3. **Видео 3:** между «в задании ЕГЭ» и «обществознанию» пропущен
   предлог «по» (грамматически необходим); CTA «шапки профиля» →
   «шапке профиля» (тот же сбой, что в видео 1).

Все правки — только в JSON с таймкодами речи для отображения на
экране, звук ролика не трогали.

Результаты — `../dimaaa/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя, тёплый сет) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_dm{1,2,3}.ass` | готовые субтитры |
| `gen_render.py`, `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `loudnorm.py` | двухпроходный EBU R128 + финальная проверка TP на AAC |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды (с ручными правками, см. выше) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1):

| видео | I (LUFS) | TP на готовом AAC (dBTP) |
|---|---|---|
| 1 | −14.24 | −1.72 |
| 2 | −14.13 | −1.88 |
| 3 | −13.99 | −1.87 |

Все три легли точно на целевые −14 LUFS с комфортным запасом от
потолка −1.0 dBTP.

QA-чеклист §4.6 пройден полностью на всех трёх стоп-кадрами: хук
закрывается до первой карточки, тёплый акцент читается раздельно от
белого, карточки не висят дольше 4с, иконка полноразмерная и
непрозрачная и выходит на оба упоминания «тренажёр» в каждом ролике,
бегущая подпись идёт непрерывно одним словом в фиксированном слоте,
эмфасис-зум не выталкивает карточку за края кадра на пике (проверено
отдельно на длинных словах «ВОЗВРАЩАЕТСЯ» и «УЧИТЕЛЬНИЦЕ»), CTA единый
«ссылка в шапке профиля» (после правок ASR — с корректной грамматикой
на экране во всех трёх).
