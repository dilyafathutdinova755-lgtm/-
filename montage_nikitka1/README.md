# Монтаж «Никита» — 3 ролика (тег `никитка1`, новая партия presenter'а)

Исходники: релиз с тегом `никитка1`. Файлы датированы `16.09`
(`Untitled.Video.16.09.{1,2,3}_2160p.mp4`). Тот же герой, что в партиях
`никита`, `никита2`, `ник1`, `никитка` (подтверждено по лицу и по
характерному ноутбуку с наклейкой тигра), но новая съёмка — светлая
комната с книжным шкафом и лампой Эдисона вместо прежних интерьеров,
зелёный свитер вместо серого худи NEVORA. Проверено протоколом §8:
sha256 всех трёх новых файлов не совпадает ни с одним файлом всех
четырёх прошлых партий («никита», «никита2», «ник1», «никитка»).

**Тёплый сет** — определён замером пикселей стены: R/B≈2.40-2.42 во всех
трёх кадрах, ещё выше прежних тёплых эталонов (maksimka1≈2.08,
никитка≈1.98) — в кадре виден включённый тёплый Эдисон-светильник на
полке во всех трёх видео. Акцент `#FCF5AA`, оранжевый не использован.

## Сюжеты

1. **Путаешь похожих героев в задании по литературе?** Выпускники путают
   похожих второстепенных персонажей в задании ЕГЭ по литературе даже
   при хорошем знании сюжета. ЕГЭ Тренажёр показывает двух похожих
   персонажей бок о бок и просит назвать характерную деталь каждого —
   следующая пара приходит сразу при верном ответе, сравнение
   встраивается между другими заданиями без отдельного захода в раздел
   литературы, и персонажи различаются увереннее уже после нескольких
   таких сравнений.
2. **Не понимаешь, в какой теме чаще всего ошибаешься?** Выпускники не
   понимают, по какой конкретной теме ЕГЭ они ошибаются чаще всего, если
   ошибки разбросаны по всей программе. ЕГЭ Тренажёр группирует
   повторяющиеся ошибки по темам одним списком — тема с наибольшим
   числом повторов поднимается наверх сама, без необходимости
   пролистывать все ошибки в поисках закономерностей.
3. **Получаешь одну и ту же тему дня несколько раз подряд?** Выпускники
   получают в других приложениях для ЕГЭ одну и ту же тему дня несколько
   раз подряд, хотя уже закрыли её вчера. ЕГЭ Тренажёр автоматически
   исключает вчерашнюю закрытую тему из сегодняшнего задания дня — тема
   выбирается из оставшихся слабых мест, и повторный выбор одной темы
   подряд не происходит без причины.

## Исправленные артефакты ASR (до рендера)

1. **Видео 1:** «показывай» → «показывает» (согласование глагола);
   «постепенные персонажи» → «похожие персонажи» (мисхиринг, по
   контексту и по совпадению с более ранним «похожих... персонажей» в
   этом же ролике); CTA «шапки профиль» → «шапке профиля» (падеж +
   пропущенное окончание).
2. **Видео 2:** «пустники» → «выпускники» (обрезанный VAD префикс после
   паузы, тот же паттерн, что и раньше); вставлен пропущенный предлог
   «по» перед «какой конкретной теме» (грамматически обязателен);
   «бегая» → «ЕГЭ» (дважды, тот же паттерн мисхиринга «ЕГЭ», что и в
   прошлых партиях); «провистывать» → «пролистывать» (искажённое
   слово); CTA «капти профиль» → «шапке профиля» (сильно искажённый,
   но узнаваемый по паттерну CTA).
3. **Видео 3:** вставлен пропущенный предлог «в» перед «других
   приложениях» (грамматически обязателен); «бегая»/«ега» → «ЕГЭ» (два
   разных варианта мисхиринга в одном ролике); CTA «шапки профиль» →
   «шапке профиля».

Все правки — только в JSON с таймкодами речи для отображения на экране,
звук ролика не трогали.

Результаты — `../nikitka1/*_smontirovano.mp4`, 1080×1920, 25fps.

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1):

| видео | I (LUFS) | TP на готовом AAC (dBTP) |
|---|---|---|
| 1 | −14.78 | −1.75 |
| 2 | −14.83 | −1.78 |
| 3 | −14.80 | −1.89 |

Все три чуть ниже целевых −14 LUFS — источник упирается в TP-потолок
раньше достижения −14 в линейном режиме (§4.5.1, ожидаемо для этой
конкретной записи, не брак).

QA-чеклист §4.6 пройден полностью на всех трёх стоп-кадрами: хук
закрывается до первой карточки, тёплый акцент читается раздельно от
белого, карточки не висят дольше 4с, иконка полноразмерная и
непрозрачная и выходит на оба упоминания «тренажёр» в каждом ролике
(отдельно перепроверено на видео 2 — кадр на самом старте фейд-ина
иконки выглядел полупрозрачным, но это ожидаемое переходное состояние
фейда, стоп-кадр чуть позже подтвердил полную непрозрачность), бегущая
подпись идёт непрерывно одним словом в фиксированном слоте, CTA единый
«ссылка в шапке профиля» с корректной грамматикой на экране во всех
трёх.
