# Монтаж «Максимка» — 3 ролика (тег `максимка1`)

Исходники: релиз с тегом `максимка1`. Файлы датированы `12.09`, тот же
формат имён, что и у прочих партий (`Untitled.Video.12.09.{1,2,3}_2160p.mp4`).
Новый герой — тёмные волосы, серый свитер, комната с постерами на
стене и оранжевой лампой в кадре. Съёмка вечером при тёплом свете
лампы — **тёплый сет** (§1.2): акцент `#FCF5AA`.

## Сюжеты

1. **Откуда цифра в ответе?** Выпускники пересматривают готовые ответы
   перед контрольной и не понимают, откуда взялась итоговая цифра. ЕГЭ
   Тренажёр показывает решение целиком на видео — сначала условие,
   потом каждый промежуточный шаг, и только в конце сам ответ. Такой
   разбор помогает увидеть ошибку в рассуждении, а не только в ответе:
   логика решения запоминается прочнее одной угаданной цифры.
2. **На экзамене время летит?** Дома одиннадцатиклассники решают без
   ограничения по времени, а на самом экзамене время утекает
   незаметно быстро. ЕГЭ Тренажёр включает обратный отсчёт при каждом
   пробнике — время на часть варианта заканчивается точно так же, как
   на настоящем экзамене, таймер учитывает регламент по каждому
   предмету. Ощущение утекающего времени становится привычным ещё до
   дня самого экзамена.
3. **Забываешь про ЕГЭ неделями?** Потом приходится наверстывать всё
   за один долгий вечер. ЕГЭ Тренажёр напоминает о трёх миссиях дня
   уведомлением — навёрстывать разом больше не приходится. Уведомления
   приходят один раз в день и не повторяются, если миссия уже закрыта:
   ежедневная миссия занимает меньше времени, чем один долгий вечер
   навёрстывания.

Длительности разные (33.43 / 35.65 / 33.16с) — протокол §8 не потребовал
отдельной проверки на дубли, три явно разных сюжета.

## Исправленные артефакты ASR (до рендера)

Во всех трёх роликах CTA «ссылка на ЕГЭ Тренажёр **в шапке** профиля»
потеряла слово «в» и распозналась как «шапк**и**» (родительный падеж
вместо дательного) — одинаково во всех трёх видео, акустически слабое
слово выпало на стыке. Исправлено вручную в `words{1,2,3}.json`:
вставлено «в», «шапки» → «шапке» — перед рендером, иначе на экране
всех трёх роликов показывалась бы грамматическая ошибка.

Плюс по одному отдельному артефакту в каждом ролике (контекстно
однозначные, не расслышанные ASR):
- **Видео 1:** «том» → «потом» (VAD откусил приставку после паузы,
  тот же паттерн, что «вы-» в «выпускники» в партии `ник1`); «они
  только в ответе» → «а не только в ответе» (смысл фразы не сходился
  без разбора ошибки «а не только в ответе»).
- **Видео 2:** «обратный отчёт» → «обратный отсчёт» (речь явно про
  таймер обратного отсчёта, не про «отчёт»); «и временно часть
  варианта» → «и время на часть варианта» (грамматически не сходилось).
- **Видео 3:** «уведомление приходят» → «уведомления приходят»
  (согласование числа: подлежащее должно быть во множественном числе).

Все правки — только в JSON с таймкодами речи для отображения на
экране, звук ролика не трогали.

Результаты — `../maksimka1/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя, тёплый сет) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_mk{1,2,3}.ass` | готовые субтитры |
| `gen_render.py`, `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `loudnorm.py` | двухпроходный EBU R128 + финальная проверка TP на AAC |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды (с ручными правками, см. выше) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1):

| видео | I (LUFS) | TP на готовом AAC (dBTP) |
|---|---|---|
| 1 | −14.13 | −1.89 |
| 2 | −14.20 | −1.89 |
| 3 | −14.15 | −1.84 |

Все три легли точно на целевые −14 LUFS с комфортным запасом от
потолка −1.0 dBTP.

QA-чеклист §4.6 пройден полностью на всех трёх стоп-кадрами: хук
закрывается до первой карточки, тёплый акцент `#FCF5AA` читается
раздельно от белого (не пятном), карточки не висят дольше 4с, иконка
полноразмерная и непрозрачная и выходит на оба упоминания «тренажёр»
в каждом ролике, бегущая подпись идёт непрерывно одним словом в
фиксированном слоте, эмфасис-зум не выталкивает карточку за края
кадра на пике, CTA единый «ссылка в шапке профиля» (после правки
ASR — с корректной грамматикой на экране).
