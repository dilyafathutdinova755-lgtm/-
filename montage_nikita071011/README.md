Заглавная «Н» в написании тега (`Никита071011` против обычного `никита...`) — не отдельный герой, подтверждено прямой сверкой кадров.

- sha256 всех трёх файлов сверен со всеми историческими hash-значениями по всей ветке (обе капитализации тега) — совпадений нет.

  - **Эскалация проведена:** ASR прогнан, транскрипт сопоставлен с архивным `vnikita2609`/video2.

## ASR-правки

- **video1:** «егэ» → «ЕГЭ» caps (генерик); «вига» → «ЕГЭ» (акустически неоднозначный токен в «в вига/его тренажёре» — передекод широким окном дал смешанный результат между «его» и «ЕГЭ», но «его» не имеет грамматического референта в контексте, тогда как «ЕГЭ тренажёр» — фиксированная фраза продукта); «фипи» → «ФИПИ» caps. **CTA полностью реконструирован**: исходный вывод «ссылку на тренажёр шапке профи» содержал три проблемы — «ссылку» (винительный падеж вместо правильного «ссылка»), отсутствующий предлог «в» перед «шапке» (передекод узких окон подтвердил чистую тишину/переход между «тренажёр» и «шапке» — предлог был реально проглочен в быстрой речи, а не потерян распознаванием), и усечённое «профи» вместо «профиля». Исправлено на стандартную фразу «ссылка на тренажёр в шапке профиля».
- **video2:** «егэ» → «ЕГЭ» caps (генерик); «его» → «ЕГЭ» (тот же паттерн «в его/ЕГЭ тренажёре», без референта у «его»); «заданием» → «заданиям» (грамматика — «к заданиям есть текстовый разбор», дательный падеж множественного числа). CTA уже содержала корректное «в шапке профиля».
- **video3:** «егэ» → «ЕГЭ» caps (дважды). CTA: исходное «трапки профи» (слипшееся искажение «в шапки» + усечённое «профи») передекодировано широким окном (20.9-22.95с) — дало чистое «в шапке профиля», подтверждено токен-уровневым таймстемпом.

Все вставки/правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `nikita061011` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео (проверка стоп-кадрами: хук, карточка+бегущая подпись, иконка, CTA, пик эмфасис-зума). Хук закрывается до старта первой карточки во всех трёх (2.90с), целиком акцентным цветом (тёплый #FCF5AA), без одновременного показа с обычной карточкой. Карточки не превышают 4с, межстрочный интервал плотный, акцентная строка крупнее белой с тонкой обводкой. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо) — два стоп-кадра (video1, video3) случайно попали в первые 0.01-0.08с фейд-ина и показали полупрозрачную иконку, повторная проверка кадром из середины показа подтвердила полную непрозрачность в обоих случаях, ложного срабатывания не было. Бегущая подпись непрерывна, в одном слоте, по одному слову — полностью реконструированные CTA (video1, video3) и правки «его»→«ЕГЭ» (video1, video2) проверены отдельно стоп-кадром, отображаются корректно без тайминг-глитчей. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Дефектов не найдено.

Рендер выполнялся строго последовательно (video1 → video2 → video3), не параллельно, по установленной в прошлых партиях практике.
