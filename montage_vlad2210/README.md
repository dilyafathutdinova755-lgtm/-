# montage_vlad2210

Монтаж 3 роликов под тегом `влад2210` (студия, холодный сет, серый свитер).

## Источники

| файл | длительность | release asset |
|---|---|---|
| video1.mp4 | 26.135с | `25._1080p.mp4` (36 864 446 байт, sha256 `aee077e5...` по release API) |
| video2.mp4 | 22.658с | `5._1080p.mp4` (34 442 474 байт, sha256 `e786c886...` по release API) |
| video3.mp4 | 22.146с | `_1080p.mp4` (31 062 162 байт, sha256 `c3d6af6e...` по release API) |

Скачаны из релиза `влад2210`, все три совпадают по размеру и digest с release API.

**Как и в предыдущих батчах этой волны:** исходники уже лежат в 1080×1920 (не 4K). `gen_render.py`/`pipeline.py` унаследованы от `влад2110` — там уже был настроен явный `w0=1080, h0=1920`.

## Комната и герой

Референс-кадры (`ffmpeg -ss 10 -frames:v 1`) сравнены с историческими батчами. Подтверждена знакомая студия: серый вязаный свитер, нейтральная бежево-серая стена, характерная поза с опорой на скрещённые руки на столе — та же линия, что во всех предыдущих батчах «влад». Пайплайн унаследован от **`влад2110`** (самый свежий батч этой студии, вчерашний).

## Проверка на дубли (§8)

Длительности всех трёх видео (26.135с, 22.658с, 22.146с) и полные ASR-транскрипты сверены с исторической базой героя (включая вчерашний `montage_vlad2110`) — точных совпадений не найдено. Темы: физика/задача 25 (метод «почему так», разбор шагов), история/задание 5 (банк ФИПИ, решает каждый день), история/правители России (игра на запоминание в паузах между делами) — три разных ролика. Слово «ссылка» встречается в транскрипте каждого видео ровно один раз.

## Палитра

Комната и сет холодные, без переключения — продолжение исторической классификации студии «влад» (`#C9F5FF`). `pipeline.py` унаследован от `влад2110` без правок цвета.

## ASR-правки

Пайплайн: sherpa-onnx zipformer (ru) + silero VAD → `asr_batch.py` → `build_words.py` → ручная правка через `apply_fixes.py`, каждая неоднозначная правка проверена `redecode_ts.py` перед применением.

- **Все три видео:** `"егэ"` → `"ЕГЭ"` (регистр). CTA во всех трёх — широкий передекод подтвердил отдельный токен «в» перед «шапки» (video1: 24.6-26.2с, video2: 21.1-22.7с, video3: 20.6-22.2с), тот же повторяющийся по кампании паттерн; «шапки» → «шапке» в каждом случае.
- **video2:** дополнительно `"банке пи пи"` → `"банке ФИПИ"` — тот же кампанейский паттерн разрыва «ФИПИ» на два токена «пи»; широкий передекод 2.8-5.2с дал чистое «в банке ФИПИ по одному в день», склеено в одно слово. Второе упоминание «фипи» уже было распознано правильно по буквам, исправлен только регистр.
- **video3:** `"каждую автобус"` — **тот же самый паттерн**, что в video3 вчерашнего батча `влад2110` («каждую автобус или лифт»): узкий VAD-сегмент стабильно смазывает «пока жду» этого говорящего в несуществующее «каждую». Широкий передекод 0.0-1.8с дал чистое «пока жду автобус я по[вторяю]...», разбито на два реальных слова в границах исходного токена. Повторяемость этой ошибки на разных записях одного и того же человека подтверждает, что это устойчивая акустическая особенность произношения, а не случайный сбой.

После применения правок — проверка на пересечения временных меток слов: пересечений и отрицательных длительностей не найдено ни в одном видео.

`build_words.py`, `asr_batch.py`, `pipeline.py`, `redecode_ts.py`, `loudnorm.py`, `validate.py` унаследованы из `влад2110` без правок кода (кроме `make_subs.py`/`gen_render.py` — только имя ASS-файла поменялось на `subs_v2210_{i}`, `w0`/`h0` уже были настроены правильно).

## Карточки и тайминги

`data1.py`/`data2.py`/`data3.py` — хук (0-2.6с, акцентный, формулирует боль по конкретной теме, не пересказ первой фразы) + 7-9 карточек на видео (1-3 слова, кегль 85-95/40-48px) + бегущая подпись (из слов, PT Sans Narrow Bold) + 4 эмфасис-зум окна на ролик. Валидация пройдена (`validate.py`): нет пересечений карточек/хука/зума, последняя карточка заканчивается точно на DURATION, хук закрывается строго до первой карточки, зум-окна не пересекаются.

- video1 (физика, задача 25, метод «почему так»): хук «ЗАДАЧА 25 ПО ФИЗИКЕ / НЕ ПОНИМАЕШЬ ПОЧЕМУ?», 9 карточек, CTA.
- video2 (история, задание 5, банк ФИПИ): хук «ЗАДАНИЕ 5 ПО ИСТОРИИ / НЕ РЕШАЕШЬ КАЖДЫЙ ДЕНЬ?», 7 карточек, CTA.
- video3 (история, правители России, игра на запоминание): хук «ПРАВИТЕЛИ РОССИИ / ПУТАЕШЬ ПОРЯДОК?», 7 карточек, CTA.

Иконка приложения (ЕГЭ ТРЕНАЖЁР) появляется на оба голосовых упоминания в каждом ролике (автоматически по паттерну `тренаж` в `words{N}.json`):
- video1: окна (18.276, 21.276) и (24.284, 26.135)
- video2: окна (17.084, 20.084) и (20.828, 22.658)
- video3: окна (14.46, 17.46) и (20.356, 22.146)

## Громкость

Двухпроходный EBU R128 (`loudnorm.py`, TP-цель −2.0 на обоих проходах, §4.5.1) + финальная проверка TP на готовом AAC-файле. Все три прошли на обычном проходе, лимитер-эскалация не понадобилась:

| видео | pass1 измерено | финальный AAC (после кодирования) |
|---|---|---|
| video1 | I=-20.63 TP=-3.28 LRA=4.10 | I=-14.81 LUFS, TP=-1.63 dBTP |
| video2 | I=-20.84 TP=-3.21 LRA=2.80 | I=-14.84 LUFS, TP=-1.19 dBTP |
| video3 | I=-20.58 TP=-3.35 LRA=3.10 | I=-14.74 LUFS, TP=-1.79 dBTP |

## QA

Стоп-кадры на хук/карточка/иконка/зум/CTA извлечены и просмотрены для всех трёх видео (14 кадров). Хук закрывается строго до старта первой обычной карточки; карточки не вылезают за края кадра, текст не на лице/рту, поля соблюдены; иконка приложения полностью непрозрачна, крупная (280px), справа на уровне головы, не перекрывает лицо, появляется на оба упоминания в каждом ролике; CTA «ссылка в шапке профиля» идентичен во всех трёх; акцент только ледяной голубой, один сет на ролик. Один кадр (video3 на 14.6с) попал в начало fade-in окна иконки (0.14с из 0.32с) — переизвлечение из середины того же окна (15.8с) подтвердило полную непрозрачность, это ожидаемый сэмплинг-артефакт на границе fade, не дефект рендера. Дефектов не найдено.

## Файлы в этой папке

`pipeline.py`, `asr_batch.py`, `build_words.py`, `redecode_ts.py`, `loudnorm.py`, `validate.py` — унаследованы от `montage_vlad2110/` без правок кода. `make_subs.py`/`gen_render.py` — правка только на имя ASS-файла (`subs_v2210_{i}`), `w0`/`h0` уже были установлены правильно для 1080p-источников в предыдущем батче. `data1.py`/`data2.py`/`data3.py` — карточки/хук/эмфасис/длительность. `apply_fixes.py` — ASR-правки. `asr{1,2,3}.json`/`words{1,2,3}.json` — распознавание речи. `subs_v2210_{1,2,3}.ass` — готовые субтитры. `render{1,2,3}.sh` — сгенерированные ffmpeg-скрипты рендера.
