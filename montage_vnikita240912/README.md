Герой и комната визуально совпадают с батчами **v.никита2209** и **v.никита23092** (тот же худи NEVORA, тот же тёмный стеллаж с книгами, та же дверь и постер на стене). Запущена усиленная проверка:

- sha256 всех трёх новых файлов сверен со всеми 77 историческими hash-значениями по всей ветке — совпадений нет.
- Длительности (18.306 / 18.370 / 17.730с) не совпадают ни с одной исторической записью этой комнаты (v.никита2209: другие; v.никита23092: 20.120/17.730/19.970 — совпадение только по video3, случайное, см. выше).
- Полный ASR-транскрипт сверен с `v.никита23092` (тот же персонаж, последний батч этой комнаты): новые три сюжета (сборники по ЕГЭ выглядят одинаково, но формат мог измениться / список терминов можно перечитывать много раз и всё равно путать на экзамене / ошибку легко списать на невнимательность, а она возвращается снова) не пересекаются дословно ни с одним прежним скриптом.

**Важное наблюдение (не дубль, повторяется третий раз подряд у этого персонажа).** Темы этой партии — устаревший формат сборников (video1), игры на запоминание (video2), текстовый разбор ошибок (video3) — снова тот же набор из трёх базовых офферов кампании, который уже был у этого же героя в `v.никита2209` и `v.никита23092`. Формулировки, примеры и конкретные сценарии при этом полностью другие:
- video1 здесь: сборники выглядят одинаково, но формат мог сильно измениться vs открытие ещё одного варианта ФИПИ (v.никита2209) vs устаревшие сборники, не совпадающие с форматом (v.никита23092).

Дубликат по протоколу §8 не подтверждён — формулировки и структура фраз каждый раз собственные, это не пересказ и не повторная заливка.
