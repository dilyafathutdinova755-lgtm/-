## ASR-правки

Этот батч дал необычно высокую концентрацию «съеденных» VAD-ом слов — случай, когда сегментация голоса целиком роняет короткий предлог на границе сегмента, а не просто искажает его. Пять отдельных находок на три видео:

- **video1:** «пг» (искажённый токен на стыке сегментов, 1.58-1.96с) — передекодировано 5 разными окнами контекста (0.9-2.3с), все независимо сошлись на «по ЕГЭ» («сборника по ЕГЭ», не «сборника ФИПИ» — первоначальная гипотеза по паттерну отклонена как не совпадающая с реальным звуком); «его» → «ЕГЭ» (12.684-12.904); «пи»+«пипи» слипшиеся токены → объединены в «ФИПИ» (14.004-14.376); «шапки» → «шапке»; «профиль» → «профиля» (конец клэмплен на 19.63, DURATION=19.650).
- **video2:** пропущено «в» перед «тетради» (3.66-3.72) — вставлено по итогам передекода; «его» → «ЕГЭ» (17.26-17.48); пропущено «к» перед «заданиям» (18.2-18.26), «заданием» → «заданиям» (18.332-18.872, грамматика); пропущено «по» перед «которому» (20.572-20.68, «которому» сдвинуто на 20.72-20.872); «шапте» → «шапке»; «профиль» → «профиля» (конец клэмплен на 25.54, DURATION=25.560).
- **video3:** пропущено «в» перед «егэ»→«ЕГЭ» (15.0-15.36 / 15.452-15.712); CTA-хвост — вместо распознанного одного «профиль» реконструированы три отдельных слова «в»(23.56-23.72) + «шапке»(23.76-23.96) + «профиля»(24.12-24.5), подтверждено передекодом.

Все пять пропусков — не искажения, а полное отсутствие слова в выводе ASR (VAD-сегмент целиком исключил звук предлога). Каждый случай подтверждён прямым повторным распознаванием узкого окна вокруг разрыва перед вставкой JSON-записи — ни один не был принят по догадке. Стандартные правки по всей серии: «его/ега» → «ЕГЭ» (с заглавной для упоминаний продукта, строчными — для общих упоминаний экзамена), слипшиеся токены → «ФИПИ», «шапки/шапте» → «шапке», «профиль» → «профиля» (CTA, родительный падеж).

`build_words.py` и `asr_batch.py` унаследованы из `никита0310` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео (проверка стоп-кадрами: хук, карточка+бегущая подпись, иконка, CTA, пик эмфасис-зума). Хук закрывается до старта первой карточки во всех трёх (2.90с), целиком акцентным цветом (тёплый #FCF5AA), без одновременного показа с обычной карточкой. Карточки не превышают 4с, межстрочный интервал плотный, акцентная строка крупнее белой с тонкой обводкой — текст читается раздельно, не пятном. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо). Бегущая подпись непрерывна, в одном слоте, по одному слову — все пять реконструированных пропущенных слов (включая трёхсловную вставку «в шапке профиля» в video3) проверены отдельно стоп-кадром, отображаются корректно без тайминг-глитчей. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Дефектов не найдено.

Технический инцидент при рендере: одновременный запуск всех трёх render{1,2,3}.sh в фоне вызвал OOM-kill процесса video1 (память cgroup исчерпана тремя параллельными ffmpeg по 1.3-1.8GB RSS каждый). video2 и video3 дорендерились штатно; video1 перезапущен отдельно после их завершения и прошёл без ошибок. На итоговом качестве не отразилось — просто последовательный, а не параллельный рендер для этого конкретного железа.
