## Проверка на дубли (протокол §8)

Тот же тёмно-серый худи «NEVORA» и та же тёмная книжная полка, что и в батче **nikitaaaaa**. Это визуальное совпадение запустило усиленную проверку:

- sha256 сверен против всех 18 исторических исходников никита-семьи (nikita, nikita1809, nikita2, nikitaaaaa, nikitka, nikitka1) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio1.wav, audio3.wav) сверен отдельно против nikitaaaaa — совпадений нет.
- Полный ASR-транскрипт сверен именно с nikitaaaaa — два новых сюжета:
  1. Порядок исторических событий восстанавливается свайпом карточек, а не зазубриванием точных дат.
  2. Карточки с историческими терминами группируются по эпохе автоматически, без ручного поиска по общему списку.

Ни один сюжет не пересекается с сюжетами nikitaaaaa (офлайн-доступ к заданию как к фото в галерее; сравнение с ближайшим соперником по конкретной цифре, а не по абстрактному месту в рейтинге). Дубликат исключён.

## Палитра

Пиксельный замер фона (R/B ratio): 1.607 → тёплый сет, совпадает с nikitaaaaa. `pipeline.py` унаследован уже с тёплым акцентом (`ACCENT = "&H00AAF5FC&"`), переключения не требовалось.

## ASR-правки

- video1: «ега» → «егэ» (ослышка бренда).
- video1: пропущенный предлог «в» перед «шапке» восстановлен по контексту, «шапки» → «шапке», «профи» → «профиля» (CTA была обрезана/искажена в конце фразы).
- video3: искажённая пара «про»+«тип» заменена на «в»+«шапке» (CTA "про тип профиля" → "в шапке профиля").

`build_words.py` унаследован из nikitaaaaa уже с фиксом бага переполнения времени последнего слова — повторного исправления не потребовалось. Небольшие остаточные переполнения (0.02с) на последнем слове каждого видео клэмпнуты вручную под фактическую длительность.

`asr_batch.py` и `build_words.py` адаптированы под цикл `['1','3']` вместо `['1','2','3']` — video2 отсутствует.
