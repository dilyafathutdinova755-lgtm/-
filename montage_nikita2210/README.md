# montage_nikita2210

Монтаж 3 роликов под тегом `никита2210` (комната Никиты, тёплый сет, худи NEVORA, тёмный книжный шкаф).

## Источники

| файл | длительность | release asset |
|---|---|---|
| video1.mp4 | 27.97с | `16._1080p.mp4` (23 474 544 байт, sha256 `c92461c6...` по release API) |
| video2.mp4 | 25.324с | `17._1080p.mp4` (23 639 881 байт, sha256 `bf3c2cde...` по release API) |
| video3.mp4 | 16.727с | `_1080p.mp4` (10 894 433 байт, sha256 `330cde1e...` по release API) |

Скачаны из релиза `никита2210`, все три совпадают по размеру и digest с release API. video3 заметно короче остальных (16.7с против 26-28с) — это просто более компактный ролик, не признак обрезки.

**Как и в предыдущих батчах этой волны:** исходники уже лежат в 1080×1920 (не 4K). `pipeline.py`/`gen_render.py` унаследованы от `никита2110` — там уже был настроен явный `w0=1080, h0=1920`.

## Комната и герой

Референс-кадры (`ffmpeg -ss 10 -frames:v 1` для video1/2, `-ss 5` для короткого video3) сравнены с историческими батчами. Подтверждена комната Никиты: худи NEVORA, тёмный книжный шкаф с коллекцией книг, бежевая стена, светлая дверь — та же линия, что во всех прошлых батчах. Пайплайн унаследован от **`никита2110`** (самый свежий батч этой комнаты, вчерашний).

## Проверка на дубли (§8)

Длительности всех трёх видео (27.97с, 25.324с, 16.727с) и полные ASR-транскрипты сверены с исторической базой (включая вчерашний `montage_nikita2110`) — точных совпадений не найдено. Темы: биология/задание 16 (ведение записи сомнений в тетради), история/задание 17 (подчёркивание опорных слов), русский язык/паронимы vs однокоренные слова (игра на запоминание) — три разных ролика. Слово «ссылка» встречается в транскрипте каждого видео ровно один раз.

## Палитра

Комната и сет тёплые, без переключения — продолжение исторической классификации комнаты Никиты (`#FCF5AA`). `pipeline.py` унаследован от `никита2110` без правок цвета.

## ASR-правки

Пайплайн: sherpa-onnx zipformer (ru) + silero VAD → `asr_batch.py` → `build_words.py` → ручная правка через `apply_fixes.py`, каждая неоднозначная правка проверена `redecode_ts.py` перед применением.

- **Все три видео:** `"егэ"` → `"ЕГЭ"` (регистр). CTA во всех трёх — широкий передекод подтвердил отдельный токен «в» перед «шапки» (video1: 26.4-28.0с, video2: 23.8-25.4с, video3: 15.2-16.8с), тот же повторяющийся по кампании паттерн; «шапки» → «шапке» в каждом случае. При вставке «в» в video2 и video3 обнаружено пересечение с концом слова «тренажёр» — нуджено на ~0.1-0.15с позже в обоих случаях.
- **video1:** дополнительно `"фипи"` → `"ФИПИ"` (регистр, слово уже распознано правильно по буквам). `"в одно и тоже время"` → `"в одно и то же время"` (та же омофонная пара «тоже»/«то же», разница только в написании — устойчивая фраза требует раздельного написания; разбито на два слова в границах исходного токена).
- **video2:** `"текстовые разбор"` → `"текстовый разбор"` — широкий передекод 18.5-20.5с дал чистое «и есть текстовый разбор» (согласование по роду), узкий сегмент дал неверное окончание.
- **video3:** `"поранимы"` → `"паронимы"` — несуществующее слово; широкий передекод 0.0-2.7с подтвердил тот же акустический результат («чем поранимы отличаются от однокоренных слов»), то есть это не ошибка узкого сегмента, а устойчивая акустическая особенность модели на этом слове. По смыслу (вопрос про разницу паронимов и однокоренных слов — стандартная тема задания по русскому ЕГЭ) единственный осмысленный вариант — «паронимы»; исправлено по контексту, без альтернативного прочтения.

После применения правок — проверка на пересечения временных меток слов: пересечений и отрицательных длительностей не найдено ни в одном видео.

`build_words.py`, `asr_batch.py`, `pipeline.py`, `redecode_ts.py`, `loudnorm.py`, `validate.py` унаследованы из `никита2110` без правок кода (кроме `make_subs.py`/`gen_render.py` — только имя ASS-файла поменялось на `subs_n2210_{i}`, `w0`/`h0` уже были настроены правильно).

## Карточки и тайминги

`data1.py`/`data2.py`/`data3.py` — хук (0-2.6с, акцентный, формулирует боль ученика по конкретному заданию, не пересказ первой фразы) + 4-10 карточек на видео (1-3 слова, кегль 85-95/40-48px; video3 короче остальных — карточек пропорционально меньше, каденция сохранена) + бегущая подпись (из слов, PT Sans Narrow Bold) + 3-4 эмфасис-зум окна на ролик. Валидация пройдена (`validate.py`): нет пересечений карточек/хука/зума, последняя карточка заканчивается точно на DURATION, хук закрывается строго до первой карточки.

- video1 (биология, задание 16, ведение записи сомнений): хук «ЗАДАНИЕ 16 ПО БИОЛОГИИ / ЗАВИСАЕШЬ НА СОМНЕНИЯХ?», 10 карточек, CTA.
- video2 (история, задание 17, подчёркивание опорных слов): хук «ЗАДАНИЕ 17 ПО ИСТОРИИ / НЕ ВИДИШЬ НА ЧЁМ СТРОИТСЯ ОТВЕТ?», 9 карточек, CTA.
- video3 (русский, паронимы vs однокоренные, игра на запоминание): хук «ПАРОНИМЫ / ПУТАЕШЬ С ОДНОКОРЕННЫМИ?», 4 карточки, CTA.

Иконка приложения (ЕГЭ ТРЕНАЖЁР) появляется на оба голосовых упоминания в каждом ролике (автоматически по паттерну `тренаж` в `words{N}.json`):
- video1: окна (18.924, 22.244) и (25.788, 27.97)
- video2: окна (16.34, 19.66) и (23.412, 25.324)
- video3: одно окно (11.868, 16.727) — оба упоминания «тренажёре»/«тренажёр» попали в один 3-секундный хвост друг друга и склеились в непрерывное появление без мигания туда-обратно (§1.6).

## Громкость

Двухпроходный EBU R128 (`loudnorm.py`, TP-цель −2.0 на обоих проходах, §4.5.1) + финальная проверка TP на готовом AAC-файле. Все три прошли на обычном проходе, лимитер-эскалация не понадобилась:

| видео | pass1 измерено | финальный AAC (после кодирования) |
|---|---|---|
| video1 | I=-31.73 TP=-10.78 LRA=2.30 | I=-15.11 LUFS, TP=-1.75 dBTP |
| video2 | I=-32.45 TP=-11.03 LRA=4.00 | I=-15.56 LUFS, TP=-1.58 dBTP |
| video3 | I=-31.62 TP=-12.05 LRA=2.20 | I=-15.41 LUFS, TP=-1.86 dBTP |

Как и во вчерашнем батче этой комнаты, все три исходника заметно тише обычного (pass1 I ≈ −31.6…−32.5) — в линейном режиме ни один не дотянул ровно до −14 LUFS (сели на −15.1…−15.6), это ожидаемая характеристика конкретных записей при упоре в потолок по TP (§4.5.1), не баг. TP у всех трёх — с комфортным запасом от лимита −1.0 dBTP.

## QA

Стоп-кадры на хук/карточка/иконка/зум/CTA извлечены и просмотрены для всех трёх видео (12 кадров). Хук закрывается строго до старта первой обычной карточки; карточки не вылезают за края кадра, текст не на лице/рту, поля соблюдены; иконка приложения полностью непрозрачна, крупная (280px), справа на уровне головы, не перекрывает лицо, появляется на оба упоминания в каждом ролике (в video3 — одним непрерывным окном); CTA «ссылка в шапке профиля» идентичен во всех трёх; акцент только жёлтый (тёплый сет), один сет на ролик. Дефектов не найдено.
