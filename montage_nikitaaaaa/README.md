# Партия «никитааааа»

6-й тег для семьи презентера Никита (после `никита`, `никита2`, `ник1`, `никитка`, `никитка1`). Комната, худи «NEVORA» и рамка с карандашным портретом на полке визуально **идентичны** прошлой партии `никитка` — тот же ракурс, тот же свет (без лампы-эдисона в кадре).

## Проверка на дубликат (протокол §8, усиленный режим)

Из-за визуального совпадения с `никитка` проверка сделана в два шага:

1. **sha256** всех трёх новых файлов сверен со всеми 15 историческими файлами семьи (`никита`, `никита2`, `ник1`, `никитка`, `никитка1`) — совпадений нет.
2. **Полный ASR-транскрипт** сверен именно с `никитка` (самая похожая по кадру партия): все три сюжета там — про прогресс-линию по месяцу, про старый телефон, про сравнение с прошлым пробником по теме. Новые три сюжета — все три **про предмет «история»** (офлайн-доступ к заданию, метка актуальной версии ФИПИ, сравнение с конкретным соперником по цифре) — ни один не пересекается.

Вывод: новая съёмка в той же комнате и в той же одежде, не повторная заливка.

## Сюжеты (все три — про историю, разные)

1. **Видео 1** — задание ЕГЭ по истории в архиве библиотеки без сети: тренажёр хранит просмотренное дома задание в памяти телефона (как обычное фото), достать можно без обращения к серверу.
2. **Видео 2** — старый бумажный справочник расходится с текущей версией ФИПИ; тренажёр помечает задание меткой актуального года прямо на карточке, метка обновляется сама.
3. **Видео 3** — вместо абстрактного места в общем рейтинге тренажёр показывает разницу в количестве закрытых заданий с конкретным ближайшим по интересу соперником.

## Правки ASR

Стандартный «шапки»→«шапке» повторился во всех трёх (CTA). Плюс более серьёзные исправления:

- **Видео 1**: «проник» → «хранит» (не подходящий по смыслу глагол, искажённое распознавание); «задания»→«задание», «телефон»→«телефона» (падежное согласование); «ега»+«я» слиты в «ЕГЭ»; «сеть не ловят» → «сеть не ловит» (согласование числа).
- **Видео 2**: пропущенный предлог «с» вставлен перед «заданием» («сверяют старый справочник по истории **с** заданием ЕГЭ»); «дига» → «ЕГЭ»; «шапки» → «шапке».
- **Видео 3**: четыре искажённых токена «и не по играй» склеены в частицу «ли» (по параллели со структурой фразы: «обгоняют **ли** своих единомышленников»); «единомышных» → «единомышленников»; «соперникам» → «соперником» (падежное согласование с «с ближайшим... соперником»); «дапте» → «шапке», «профиль» → «профиля».

Отдельно обнаружен и исправлен баг `build_words.py`: последнее слово в сегменте получало `end = last_token + 0.3` безусловно (строка перезаписывала уже посчитанный `min()`), из-за чего расчётный конец последнего слова во всех трёх видео выходил за пределы реальной длительности файла (например видео1: слово «профиля» получило `end=27.68` при видео длиной 27.50с). Вручную подрезано до фактической длительности каждого видео перед версткой карточек.

## QA

Пройден чеклист §4.6 целиком:
- Хук закрывается до старта первой карточки (gate-check пройден на всех трёх перед рендером).
- Карточки ≤4.01с (длинные фразы разбиты на 2 карточки там, где по словам одна карточка вышла бы за лимит — видео3 получилось 13 карточек вместо 8 по этой причине).
- Межстрочный интервал 0.90, акцент крупнее белого на ~10%, обводка тонкая.
- Бегущая подпись непрерывна, один слот, без обводки, по одному слову.
- Иконка «ЕГЭ Тренажёр» — 2 окна на видео (по числу упоминаний голосом), непрозрачность 100%, вне лица.
- Эмфасис-зум — 4 акцентные фразы на видео, без наезда друг на друга.
- CTA единый: «ссылка в шапке профиля».
- Стоп-кадры на хуке/карточке+иконке/CTA проверены для всех трёх видео. На двух кадрах (видео2 CTA t=29.3с, видео3 карточка t=9.5с) первая проверка попала в 0.32с окно фейд-ина иконки/появления карточки и показала смазанные цвета — пересняты кадры чуть позже (внутри стабильной фазы показа), дефекта нет.
