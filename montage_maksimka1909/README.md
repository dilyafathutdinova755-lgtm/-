## Проверка на дубли (протокол §8)

Та же комната, что и в батчах **maksim1709** и **maksim1809** (те же постеры на стене, светлый шкаф-купе, стеллаж с винтажными камерами, тот же герой). Заметное отличие — впервые в этой комнате появился петличный микрофон на свитере. Запущена усиленная проверка:

- sha256 сверен против всех 21 исторического исходника максим-семьи (maks2, maksim1, maksim16, maksim1709, maksim1809, maksim2, maksimka1) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против maksim1809 — совпадений нет.
- Полный ASR-транскрипт сверен именно с maksim1809 — три новых сюжета:
  1. Короткий тег с номером версии ФИПИ ставится прямо рядом с заданием и меняется сам при выходе новой версии.
  2. Ошибка автоматически переносится в отдельную папку на разбор сразу после первого неверного ответа, папка собирает все ошибки за неделю.
  3. Бонусное короткое задание открывается, только если основное закрыто до полудня, и не переносится на завтра.

Ни один сюжет не пересекается с тремя сюжетами maksim1809 (офлайн-доступность задания при потере сигнала, сравнение двух похожих понятий, повтор последней карточки одним нажатием). Дубликат исключён.

## Палитра — отклонение от истории комнаты

Пиксельный замер фона (R/B ratio): 1.32–1.36 на нескольких кадрах и ракурсах — заметно холоднее собственных прошлых замеров той же комнаты (maksim1709 ≈2.32, maksim1809 ≈2.32-2.34). В кадре впервые не видно характерной оранжевой лампы-мухомора, которая давала тёплый каст в предыдущих батчах — судя по всему, съёмка на этот раз дневная, без вечернего лампового света.

По правилу §1.2 CLAUDE.md («тёплый жёлтый сет — исключение только для вечерних съёмок при янтарном свете, где голубой выглядит инородно») — если освещение не даёт выраженного тёплого каста, действует умолчание: холодный сет. Поэтому `pipeline.py` **переключён на холодный акцент** (`ACCENT = "&H00FFF5C9&"`, #C9F5FF), в отличие от предыдущих двух батчей этой комнаты. Комментарий-докстрока в файле обновлён соответственно.

## ASR-правки

- «пустники» → «выпускники» (video1, VAD обрезал приставку — известный класс ошибки).
- «тёк» / «тэк» → «тег» (video1, три вхождения одной и той же ослышки технического термина).
- «шапки» → «шапке» (video1, video2, video3 — повторяющаяся ошибка падежа в CTA).
- «профиль» → «профиля» (video3, падеж после «в шапке»).

`build_words.py` унаследован из maksim1809 уже с фиксом бага переполнения времени последнего слова — повторного исправления не потребовалось (проверено через grep перед началом работы). Остаточное переполнение (0.008с) на последнем слове видео1 клэмпнуто вручную под фактическую длительность.
