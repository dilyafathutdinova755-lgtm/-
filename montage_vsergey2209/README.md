## Проверка на дубли (протокол §8)

Герой и комната — presenter «Сергей» (взрослый мужчина, родительская перспектива), комната с кирпичной стеной, книжным шкафом и торшером с абажуром совпадает с батчами `сергей11` и `сергей115` (не с более свежими `сергей1909`/`сергей19091м`, у которых другая — панельная — комната с оливковым креслом). Визуальное совпадение запустило усиленную проверку:

- sha256 всех трёх новых файлов сверен со всеми 56 историческими hash-значениями по всей ветке — совпадений нет.
- Длительности (23.426 / 24.280 / 20.440с) не совпадают ни с одной исторической записью сергей-семьи.
- Полный ASR-транскрипт сверен с сюжетами `сергей11` (зубрёжка термина дословно, рыбалка без интернета) и `сергей115` (подсмотренный ответ → список на повтор, задание дня вместо напоминаний, единый доступ без сравнения тарифов) — новые три сюжета не пересекаются ни с одним прежним.

**Отдельное наблюдение (не дубль):** темы этой партии совпадают с уже смонтированными в этой сессии `v.влад2209` и `v.максим2209` — текстовый разбор ошибок, игры на запоминание, банк ФИПИ. Здесь тот же набор офферов подан с **родительского ракурса** («ребёнку тяжело», «родители видят») вместо ученического самообращения — другой сценарий, другой транскрипт, другой персонаж кампании. Похоже на системный A/B/C-тест одного оффера через несколько персон (ученик-Влад, ученик-Максим, родитель-Сергей).

## Палитра

Тёплый сет — кирпичная стена и тёплый торшер с абажуром дают выраженный оранжевый каст на всех трёх кадрах (замер пипеткой по стене показывает R/B в диапазоне 4.2-5.5 в зависимости от выбранного патча — кирпич сам по себе тёплого тона плюс лампа; качественно однозначно теплее порога, аналогично историческому замеру `сергей11` R/B≈2.58-2.59). `pipeline.py` унаследован от `сергей115` без переключения (`ACCENT = "&H00AAF5FC&"`, #FCF5AA).

## ASR-правки

- video1: «называют» → «называет» (согласование с единственным числом подлежащего «разбор... объясняет... называет»).
- video3: слипшиеся токены «фи»+«пи» → одно слово «ФИПИ» (та же ослышка технического термина, что в других батчах, только другой раскол токенов).
- «шапке» распознано верно во всех трёх видео без правок (в отличие от большинства прошлых батчей, где встречалась ошибка «шапки»).
- Клэмп переполнения времени последнего слова под фактическую длительность: video2 (24.288→24.26), video3 (20.448→20.42). video1 переполнения не имел.

`build_words.py` и `asr_batch.py` унаследованы из `сергей115` без правок кода — унаследованный фикс бага переполнения последнего слова уже был на месте.
