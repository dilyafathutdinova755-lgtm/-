Исходники: релиз `никита`, ассеты `Untitled.Video.09.09.{1,2,3}_2160p.mp4`.
Тег `никитааа` — побайтовый дубль (те же sha256), отдельно не обрабатывался.

Результаты — `../nikita/*_smontirovano.mp4`, 1080×1920, 25fps.
Первый монтаж по полному новому набору правил CLAUDE.md 06.09.2026:
заголовок-хук (Слой 0), эмфасис-зум, иконка на каждое упоминание,
акцентная строка +10% с обводкой, бегущая подпись по одному слову
(PT Sans Narrow Bold).

финалы («без репетитора» vs «обогнать того, кто занимается с репетитором»).
Тёплый сет (§1.2): акцент `#FCF5AA`, один оранжевый `#FD5D01` на ролик.

## Технические ловушки (важно при повторном использовании pipeline.py)

1. **`pow()` в выражениях `crop` падает**, если находится на "безусловной"
   каскадной else-ветке, куда попадает `t=NaN` при инициализации фильтра
   (до первого кадра). `if`/`lt` безопасны с NaN (ложны), `pow` — нет.
   Поэтому в `zoom_segments_filter` любой pow обязан лежать только под
   явным истинным `lt()`, а самый глубокий fallback — чистая константа.
2. **Гигантская формула на все окна эмфасиса суммой в одном `crop`
   не работает** (парсер зависает/падает) — решение: резать видео на
   сегменты (`trim`+`concat`), у каждого зум-сегмента своя короткая
   независимая формула с локальным t0.
3. **Иконка на `loop=-1` без `:shortest=1` на `overlay`** зависает
   навечно — бесконечный вход никогда не даёт `overlay` завершиться.
   Обязательно ставить `shortest=1` на каждый overlay в цепочке.
4. **`crop` использует `ow`/`oh`** (свои же computed width/height) в
   выражениях `x`/`y` — не дублировать туда весь expr `w`/`h` целиком,
   иначе строка распухает и парсинг критично замедляется.
5. Несколько независимых окон иконки — только через `split` на N копий
   потока, у каждой копии свой изолированный `fade in/out`. Цепочка из
   нескольких `fade` на одном потоке ломает друг друга (`fade=in` для
   второго окна обнуляет альфу всей временной шкалы ДО своего старта,
   включая уже показанное первое окно).
