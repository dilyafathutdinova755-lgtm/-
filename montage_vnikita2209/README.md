## Проверка на дубли (протокол §8)

Герой и комната визуально совпадают с батчем **nikita1909** (тот же худи NEVORA, тот же тёмный стеллаж с книгами, та же дверь и постер на стене, поза стоя). Запущена усиленная проверка:

- sha256 сверен против всех 20 исторических исходников никита-семьи (nikita, nikita2, nikita1809, nikitka, nikitka1, nikita1909, nikitaaaaa) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против nikita1909 — совпадений нет.
- Полный ASR-транскрипт сверен именно с nikita1909 — три новых сюжета:
  1. Банк ФИПИ в тренажёре вместо устаревших сборников заданий, не совпадающих с актуальным форматом ЕГЭ.
  2. Подробный текстовый разбор в тренажёре, объясняющий почему остальные варианты ответа неверны.
  3. Игры на запоминание по русскому, истории и обществознанию вместо открытия ещё одного варианта ФИПИ для повторения.

Ни один сюжет не пересекается с двумя сюжетами nikita1909 (карточки с событиями для восстановления хронологического порядка свайпом; карточки терминов, сгруппированные по эпохе). Дубликат исключён.

## ASR-правки

- video1: «пи»+«пипи» (два токена) → «ФИПИ» (слитная ослышка технического термина); «егэя» → «ЕГЭ»; «шапки» → «шапке» (падеж CTA); «профи» → «профиля» (VAD обрезал окончание).
- video2: транскрипция верна сразу, правок не потребовалось.
- video3: «прифа» → «ФИПИ» (та же ослышка термина, что в video1); «при»+«фак»+«шапте» (три гарблед-токена) → «в»+«шапке» (CTA).

`build_words.py` и `asr_batch.py` унаследованы из nikita1909 (батч с отсутствовавшим video2, цикл был сужен до `['1','3']`) — расширены обратно до `['1','2','3']`, так как в этом релизе присутствуют все три видео. Фикс бага переполнения времени последнего слова уже был на месте (проверено через grep). Остаточное переполнение (0.009с) на последнем слове видео3 клэмпнуто вручную под фактическую длительность (17.504→17.495).
