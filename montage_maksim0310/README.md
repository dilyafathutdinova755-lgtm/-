## Отдельное наблюдение — смена формата повествования

Впервые для этого героя ролики сняты **от первого лица** («я иногда останавливаюсь...», «я случайно перепутал...») вместо привычного для остальных героев серии формата «родитель о ребёнке» («сын»/«дочь»). Presenter — сам ученик, рассказывает о собственном опыте подготовки к ЕГЭ. Комната и внешность (постеры Bastille и чёрно-белых кадров, деревянный шкаф-купе, полка с плёночной камерой и книгами, серый свитер, петличка) полностью совпадают с историей этого героя (`максим0110`, `максим0210`, `максим2909`, `максим3009`) — сверено покадрово.

## Проверка на дубли (протокол §8)

- sha256 всех трёх файлов сверен со всеми историческими hash-значениями по всей ветке — совпадений нет.
- Длительности (28.204/27.266/28.844с) не совпали ни с одним историческим роликом — ни с историей этого героя, ни с какими-либо другими. Самый чистый случай за всю партию недели — усиленная ASR-сверка не требовалась.

Сюжеты партии (впервые — рассказ от первого лица): video1 — друг из другого города присылал задания ЕГЭ, уверяя, что формат везде одинаковый, но часть заданий оказалась региональной пробной версией, которую учитель потом назвал нереалистичной; video2 — иногда останавливается на «красивом круглом числе», не проверив до конца, подходит ли оно под условие — на пробнике такое число оказалось неверным ответом; video3 — может объяснить два близких понятия по обществознанию по отдельности без ошибок, но сравнить их между собой получается хуже, и на пробнике перепутал, чем одно отличается от другого. Три новых, самостоятельных сюжета.

## ASR-правки

- **video1:** «чай заданий» → «часть заданий» (7.412-7.752), подтверждено повторным распознаванием с широким контекстом (6.9-10.8с: «хотя часть заданий там оказалась региональной пробной версией»). Слипшиеся токены «пи»+«пи» (20.924-21.384) объединены в «ФИПИ» — на этот раз сегментация потеряла слог «фи» целиком, а не просто слила его с соседним; подтверждено узким повторным распознаванием (20.5-21.5с → «банк фипи» чисто). «шапки» → «шапке». Клэмп переполнения времени последнего слова (28.224→28.18, факт. длительность 28.204с).
- **video2:** «шапки» → «шапке». Переполнения времени последнего слова нет (27.264 < 27.266).
- **video3:** «ега» → «ЕГЭ» (18.796-19.016) — несколько повторных распознаваний с разными окнами давали нестабильный результат («в его тренажёры», «в егар», «в егацию»), ни один вариант не сложился в осмысленную альтернативу; исправлено по неизменному паттерну «ЕГЭ Тренажёр», которым открывается каждое упоминание продукта во всей серии. «который» → «которые» (22.716-22.976) — грамматическое согласование с «игры» (множественное число), подтверждено повторным распознаванием («которые отдельно тренируют и»). «профиль» → «профиля». Клэмп переполнения времени последнего слова (28.864→28.8, факт. длительность 28.844с).
