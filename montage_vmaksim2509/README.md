- sha256 всех трёх новых файлов сверен со всеми 104 историческими hash-значениями по всей ветке — совпадений нет (кроме одного случайного совпадения длительности, см. выше).
- Полный ASR-транскрипт сверен с `v.максим24091` (последний батч этой комнаты): новые три сюжета (материал по истории читают конспект перед сном одним и тем же способом, наутро значительная часть забывается / решать варианты ЕГЭ по случайному учебнику без указания года издания — часть таких заданий может не пересекаться с реальным форматом / на ЕГЭ можно решить вариант почти без ошибок и не заметить одну систематическую слабость, которую маскируют правильные ответы в остальных заданиях) не пересекаются дословно ни с одним прежним скриптом этой комнаты.

**Отдельное наблюдение (не дубль).** Три темы этой партии — игры на запоминание (video1), банк ФИПИ (video2), текстовый разбор ошибок (video3) — тот же набор из трёх базовых офферов кампании, который систематически повторяется в этой сессии под разными тегами и персонажами, включая прошлые батчи этого же героя. ## QA

Полный чеклист §4.6 пройден для всех трёх видео: хук закрывается ровно на старте первой карточки (2.90с во всех трёх), карточки не превышают 4с (максимум 3.95с у video2), иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы), бегущая подпись непрерывна и не смещается со слота, CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх после ASR-правки video1. Стоп-кадр video1 на 10.5с случайно попал в 140ms-окно pop-in карточки «РУССКИЙ, ИСТОРИЯ / ОБЩЕСТВОЗНАНИЕ» и выглядел почти нечитаемым серым — перепроверено кадром из середины показа (12.0с), опасений не подтвердилось: карточка полностью непрозрачна и в фирменных цветах, это была ожидаемая часть анимации входа, а не брак. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Холодный акцент отрендерился корректно, дефектов не найдено.
