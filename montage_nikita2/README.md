# Монтаж «Никита» — 3 ролика (тег `никита;`, третья партия)

Исходники: релиз с тегом `никита;` (литеральная точка с запятой в теге —
стандартный `browser_download_url` давал 403 от прокси из-за `;` в пути,
скачано через `GET /repos/.../releases/assets/{numeric_id}` с
`Accept: application/octet-stream`). Ассеты:
`Untitled.Video.{1,2,3}.10.09_2160p.mp4`.

Тот же ведущий и комната, что в партиях «никита»/«никитааа» (тёмный
свитшот NEVORA, книжный шкаф, тёплый вечерний свет) — но три новых,
не дублирующих друг друга сюжета (проверено протоколом §8: разная
длительность, разный полный ASR-транскрипт):
1. прокрастинация/скучная тема — короткий формат тренажёра держит внимание;
2. одноклассник списал и назвал «гением» — слух развенчан;
3. счётчик дней подряд (стрик) в тренажёре, средний ученик тоже может.

Результаты — `../nikita2/*_smontirovano.mp4`, 1080×1920, 25fps.
Тёплый сет (§1.2): акцент `#FCF5AA`, оранжевый `#FD5D01` в этой партии
не использован — один сет на ролик выдержан во всех трёх.
Кегль карточки и обводка — по правке 09.09.2026 (85-95/40-48px,
тонкая тёмная обводка `bord3`, не заливка тем же цветом).

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_n{1,2,3}.ass` | готовые субтитры |
| `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды |

Звук: двухпроходный EBU R128 (§4.5.1), TP цель первого прохода −1.35.
Видео 2 нормализовалось до −14.8 LUFS; видео 1 и 3 упёрлись в TP-потолок
исходника и остались на −16.0 / −15.3 LUFS — это ожидаемая характеристика
конкретной записи (см. уточнение 06.09.2026 в CLAUDE.md §4.5.1), TP везде
≤ −1.0 dBTP.

Технические ловушки pipeline.py — см. `../montage_nikita/README.md`
(pow()/NaN на init, split-цепочка для нескольких окон иконки,
`:shortest=1` на overlay с бесконечным loop) — код не менялся, все
решения актуальны и здесь.
