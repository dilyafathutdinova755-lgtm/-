## ASR-правки

- **video1:** слипшиеся токены «пи»+«пи» (19.292-19.792) объединены в «ФИПИ»; «шапки»→«шапке», «профиль»→«профиля». Переполнения времени последнего слова нет (26.71 < 26.760).
- **video2:** клэмп переполнения времени последнего слова (25.344→25.28, факт. длительность 25.324с); «шапки»→«шапке». **Отдельная находка — слово, полностью выроненное распознаванием (не искажённое, а отсутствующее).** На границе VAD-сегмента перед CTA-блоком пропало слово «ответе» — фраза «...напоминает про нужное округление в ссылка на тренажёр...» читалась с обрывом на «в», грамматически незавершённой. Обнаружено по осиротевшему токену «в» прямо перед началом CTA. Перепроверено повторным распознаванием с широким контекстом (20.0-25.35с, затем сужено до 22.0-23.5с для точного таймкода) — слово «ответе» подтверждено как реально произнесённое.
