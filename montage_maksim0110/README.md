## Проверка на дубли (протокол §8)

Герой и комната — presenter «Максим», постеры (Bastille, чёрно-белые кадры, красная афиша), деревянный шкаф-купе, полка с плёночной камерой и книгами, серый свитер, петличка — совпадает с историей этого героя (`максим2609`, `максим2909`, `максим3009`), подтверждено сравнением кадров.

- sha256 всех трёх новых файлов сверен со всеми историческими hash-значениями по всей ветке — совпадений нет.
- Ввиду точного совпадения длительности video1 с `максим3009` video2 запущен полный ASR-транскрипт video1 и сверен построчно с `максим3009` video2: темы разные — «порядок заданий по сборнику немного изменился в этом году, растерялся на пробнике» (этот батч, video1) vs содержание `максим3009` video2 (другая тема, другой сюжет) — дословных совпадений нет. Совпадение длительности признано случайным.

### Отдельное наблюдение — необычно близкая перекличка с `максим3009` (не дубль, но заслуживает внимания сценариста)

В ходе стандартной сверки транскриптов этого батча с полным набором `максим3009` обнаружено, что **video1 и video3** этой партии перекликаются с соответствующими видео прошлого батча заметно ближе, чем обычная «тематическая перекличка» офферов, которая у нас в порядке вещей (см. ниже).

- **video1 vs `максим3009` video1:** почти дословно повторяется фраза «немного изменился» (про порядок заданий/формат) и близкая по формулировке фраза про «в актуальном порядке этого года» в офферной части. Структура шутки («думал, что всё знаю по старому формату → не сразу заметил изменения → растерялся/разобрался не сразу») также похожа.
- **video3 vs `максим3009` video3:** оба ролика используют одну и ту же структуру панчлайна — «термин на занятии звучит понятно и просто, а точную формулировку из учебника/официального источника вспомнить/сформулировать сложно» — с похожей лексикой («понятно и просто» в этом батче близко к формулировке `максим3009`).

Проверено и исключено:
1. **Не дубль файла.** sha256 всех шести файлов (3 новых + 3 из `максим3009`) различны, длительности не совпадают кадр в кадр (кроме video1 ↔ video2, который содержательно иной, см. выше), это разные дубли/разная съёмка.
2. **Не общекампанийный троп.** Проверено видео1 всех остальных героев этой сессии (`влад3009`, `никита3009`, `дмитрий3009`, `сергей3009`, `никита0110`, `влад0110`) — ни у одного нет такой же посылки «порядок/формат немного изменился в этом году, растерялся не сразу». Аналогично по video3 — структура «термин просто на занятии vs сложно вспомнить точную формулировку» не встречается в видео3 других героев. Это специфично именно для пары максим3009↔максим0110.

**Вывод:** это не копипаста одного и того же дубля (контент, интонация, конкретные примеры отличаются), но похоже, что при повторной съёмке ведущий частично переиспользовал сценарную идею/панчлайн из предыдущей партии для этих двух роликов. Решение — **не блокировать монтаж**, контент фактически различается и является самостоятельным материалом, но зафиксировать это здесь максимально подробно, чтобы сценарист/продюсер мог учесть при планировании следующих тем для этого героя.

**Отдельно (не дубль, обычный паттерн).** Темы этой партии — порядок заданий сборника (video1), текстовый разбор первого шага решения (video2), игры на запоминание формулировок (video3) — тот же набор базовых офферов кампании, систематически повторяющийся у всех героев во всех прошлых батчах. Это ожидаемо и не является проблемой само по себе.

## ASR-правки

- **video1:** «пробники» (12.332-13.032, искажённая форма) → «пробнике», проверено повторным распознаванием сегмента 11.5-13.5с («пока на пробнике не»); слипшиеся токены «пи»+«пи» (18.652-19.112) объединены в «ФИПИ»; «шапки» → «шапке». Клэмп переполнения времени последнего слова (24.48→24.44, факт. длительность 24.471с).
- **video2:** «они» (23.612-23.832) — характерное для этой серии искажение, разбито на «а»+«не» по пропорции времени (паттерн неоднократно подтверждён в прошлых батчах, применено без повторного распознавания); «шапки» → «шапке».
- **video3:** «который» (21.244-21.544) → «которые» (согласование числа с «игры на запоминание», проверено повторным распознаванием сегмента 19.8-22.5с — результат «игры на запоминания которые тренируют именно»; при этом соседнее слово «запоминание» из оригинального ASR сохранено как есть, а не заменено на «запоминания» из передекода — по установленному принципу доверять полноконтекстному распознаванию, а не изолированному сегменту, когда выбор неоднозначен). «шапки» → «шапке». Клэмп переполнения времени последнего слова (27.2→27.15, факт. длительность 27.180с).

`build_words.py` и `asr_batch.py` унаследованы из `максим3009` без правок кода.
