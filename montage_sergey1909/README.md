## Проверка на дубли (протокол §8)

Комната визуально совпадает с батчем **sergey1y** (тот же панельный интерьер, торшер с абажуром, оливковое кресло, голубая рубашка). Это визуальное совпадение с конкретным прошлым батчем запустило усиленную проверку:

- sha256 сверен против всех 15 исторических исходников сергей-семьи (sergey1, sergey11, sergey115, sergey1_v2, sergey1y) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против sergey1y — совпадений нет.
- Полный ASR-транскрипт сверен именно с sergey1y — три новых сюжета:
  1. Скорость видео-разбора подстраивается под тему (ускорить/замедлить голос без искажения звука), не нужно пересматривать ролик дважды.
  2. Прогресс по ЕГЭ выводится одним понятным предложением, без графиков и процентов для расшифровки.
  3. Пробник можно начать в любое время суток без привязки к расписанию семьи и без сдвига итогового дедлайна.

Ни один сюжет не пересекается с тремя сюжетами sergey1y (родительский телефон занят видео-разбором, сравнение двух репетиторов по предметам, ручной пересчёт баллов по бумажной таблице). Дубликат исключён.

## Палитра

Пиксельный замер фона (R/B ratio): 2.188 → тёплый сет, совпадает с sergey1y (тёплая лампа, деревянная панель). `pipeline.py` унаследован уже с тёплым акцентом (`ACCENT = "&H00AAF5FC&"`), переключения не требовалось.

## ASR-правки

- «дедлайн» → «дедлайна» (video3, падеж после «без сдвига итогового ___» требует родительный).

`build_words.py` унаследован из sergey1y с непочиненным багом переполнения времени последнего слова — исправлен повторно (см. известный системный баг: скрипт вычислял корректно клэмпнутое значение и тут же затирал его безусловной строкой `end = round(last + 0.3, 3)`). После фикса ещё остались микро-переполнения (0.005–0.02с) на последнем слове каждого видео — клэмпнуты вручную под фактическую длительность.
