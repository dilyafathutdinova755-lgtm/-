## Проверка на дубли (протокол §8)

Комната визуально совпадает с батчем **dmitry11** (тот же домашний кабинет: доска с числами Q1-132,7/Q2-163,9/Q3-186,1/Q4-229,7/Итог-712,4, монитор со spreadsheet-графиками, тёмный стеллаж, тёмно-синее поло). Это визуальное совпадение с конкретным прошлым батчем запустило усиленную проверку:

- sha256 сверен против всех 15 исторических исходников дмитрий-семьи (dima1, dimaaa, dmitry1, dmitry11, dmitry115) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против dmitry11 — совпадений нет.
- Полный ASR-транскрипт сверен именно с dmitry11 — три новых сюжета:
  1. Другой способ решения задачи (пусть и более длинный путь к ответу) не засчитывается как повторение прошлой ошибки.
  2. Место в рейтинге ЕГЭ показывается просто цифрой, без имён одноклассников рядом — сравнивать себя со списком класса не приходится.
  3. Задания синхронизируются ночью по домашнему вай-фаю заранее, без спешки перед утренним выходом из дома.

Ни один сюжет не пересекается с тремя сюжетами dmitry11 (распределение вечернего времени по цифре нерешённых заданий, все предметы одним бесплатным доступом без отдельного взноса, пробник без драматичной музыки и обратного отсчёта). Дубликат исключён.

## Палитра

Пиксельный замер фона (R/B ratio): 1.233 → холодный сет, совпадает с dmitry11. `pipeline.py` унаследован уже с холодным акцентом (`ACCENT = "&H00FFF5C9&"`), переключения не требовалось.

## ASR-правки

- «одиннадцати» + «классников» (два отдельных токена) → «одиннадцатиклассников» (video1, склеенные части слова объединены в одно с суммарным временным диапазоном).
- «ошибоки» → «ошибки» (video1, опечатка распознавания).
- «ек» → «ЕГЭ» (video2, ослышка бренда).
- Пропущенный предлог «в» перед «шапке» восстановлен по контексту стандартной CTA-фразы (video3, VAD, судя по всему, съел короткий предлог между «тренажёр» и «шапке» — вставлен с оценённым таймингом 30.56–30.70с по аналогии с той же фразой в video1/video2, где «в» присутствует).
- «шапки профиля» → «шапке профиля» не потребовалось отдельно чинить в video3, так как падеж восстановился вместе со вставкой «в» — в самом слове «шапке» ошибки не было, отсутствовал только предлог.

`build_words.py` унаследован из dmitry11 с непочиненным багом переполнения времени последнего слова — исправлен повторно (систематическая ошибка: скрипт вычислял корректно клэмпнутое значение и тут же затирал его безусловной строкой `end = round(last + 0.3, 3)`). После фикса остались микро-переполнения (0.008–0.009с) на последнем слове каждого видео — клэмпнуты вручную под фактическую длительность.
