## ASR-правки

Необычно много реально искажённых токенов в этом батче (не просто пропуски/падежи — слова, которых в русском языке не существует), все подтверждены передекодом перед правкой:

- **video1:** «стают» → «ставит» (исходный вывод «и стают с ней галочки» бессмысленен; передекод широким окном 3.0-5.0с дал чёткое «и ставит с ней галочки» — третье лицо единственного числа, согласуется с подлежащим «друг»); «его» → «ЕГЭ» (установленный паттерн «в его/ЕГЭ тренажёре» для этой комнаты, передекод подтвердил «в ега тренажёре»); «фипи» → «ФИПИ» caps; «егэ» → «ЕГЭ» caps. **Особенность CTA, не исправлена:** передекод тремя независимыми окнами (20.1-22.9с, 19.0-22.9с) стабильно даёт «ссылка на тренажёр всего и в шапке профиля» — лишние слова «всего и» реально произнесены (не артефакт распознавания), оставлены в бегущей подписи как есть; карточка-CTA (Слой 1) остаётся стандартной «ССЫЛКА» / «в шапке профиля» независимо от этой речевой особенности.
- **video2:** «начинаю» → «начинать» (10.2-10.6с, грамматика — «с какой начинать», передекод подтвердил инфинитив); пропущенное «к» перед «заданием»→«заданиям» (передекод 13.9-14.9с дал «джори к заданиям» — «к» ранее проглочено распознаванием); «капти» → «в шапке» в CTA (явное искажение, передекод 19.2-21.4с подтвердил «в шапке», но дал «профит» вместо «профиля» на самом конце — исправлено на стандартное «профиля»); «профиль»→«профиля»; «егэ»→«ЕГЭ» caps.
- **video3:** «подказ» → «подкаст» (не существующее в русском слово; три независимых передекода, включая расширенный до 1.6с, стабильно дают «подказ» — явно обрезанное/смазанное «подкаст», подтверждено семантикой «слушаю подкаст про историю пока бегаю»); «ну» → «но» (передекод 3.2-4.3с подтвердил противительный союз «но даты для ЕГЭ», а не вводное «ну» — согласуется с контрастом предыдущего предложения); пропущенное «в» и «шапки»→«шапке» в CTA (передекод 17.0-19.1с дал «шапте» — явное искажение); «профиль»→«профиля»; «егэ»→«ЕГЭ» caps.

Все вставки/правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `nikita071011` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео (проверка стоп-кадрами: хук, карточка+бегущая подпись, иконка, CTA, пик эмфасис-зума). Хук закрывается до старта первой карточки во всех трёх (2.90с), целиком акцентным цветом (тёплый #FCF5AA). Карточки не превышают 4с, межстрочный интервал плотный, акцентная строка крупнее белой с тонкой обводкой. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике, 100% непрозрачность, справа на уровне головы, не задевает лицо. Бегущая подпись непрерывна, в одном слоте, по одному слову. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Один стоп-кадр video3 (карточка 2) случайно попал на первые 140ms pop-in перехода — перепроверен кадром из середины показа карточки, непрозрачность подтверждена полной. Дефектов не найдено.

Рендер выполнялся строго последовательно (video1 → video2 → video3).
