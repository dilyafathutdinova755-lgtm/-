Общий только финальный оффер «банк ФИПИ» — стандартный повторяющийся элемент кампании. Совпадение длительности признано случайным, не дубль.
- Полный ASR-транскрипт video2 и video3 также сверен с соответствующими video2/video3 из `дмитрий0110`: video2 этого батча («дочь списала у подруги верный ответ, но не смогла объяснить способ решения, самостоятельно решить похожие задания не вышло») не пересекается дословно с `дмитрий0110` video2 («ошибка в знаке случайно компенсируется другой, итоговый ответ верен почти случайно»). video3 этого батча («понятие выучено по номерам карточек учителя, без номеров путает к какому понятию относится») не пересекается с `дмитрий0110` video3 («правило верно применяется устно, но та же ошибка повторяется на письме»).

Сюжеты партии (дочь-ученица, рассказ от лица родителя — установленный формат этого героя): video1 — купленный сборник с годом на обложке, не совпадающим с реальным возрастом заданий внутри; video2 — списанный у подруги ответ без понимания способа решения; video3 — понятия, выученные по номерам карточек, путаются без привычной нумерации.
