# montage_maksim2010

Монтаж 3 роликов под тегом `максим2010` (холодный сет, подростковая комната с постерами, серый свитер).

## Источники

| файл | длительность | release asset |
|---|---|---|
| video1.mp4 | 28.375с | `Untitled.Video.2010.1_2160p.mp4` (142 689 240 байт, sha256 `6ceb246d...` по release API) |
| video2.mp4 | 27.415с | `Untitled.Video.2010.2_2160p.mp4` (147 626 615 байт, sha256 `5be0626b...` по release API) |
| video3.mp4 | 28.311с | `Untitled.Video.2010.3_2160p.mp4` (162 033 538 байт, sha256 `59a91294...` по release API) |

Скачаны из релиза `максим2010` (теговый URL `.../releases/tag/максим2010`), все три совпадают по размеру и digest с release API.

## Комната и герой

Референс-кадры сравнены визуально с историческими батчами. Подтверждена знакомая подростковая комната: серый вязаный свитер, постеры на стене (Bastille, фотографии), деревянный шкаф, стеллаж с книгами и камерой — та же линия, что в `maksim1610`/`maksim1710`. Пайплайн унаследован от **`maksim1710`** (самый свежий батч этой комнаты на момент монтажа).

## Проверка на дубли (§8)

Длительности всех трёх видео (28.375с, 27.415с, 28.311с) и полные ASR-транскрипты не совпадают ни с одним историческим батчем героя (темы разные: химия/тестовая часть, биология/задача 27, история/даты смуты — три разных ролика, не дубли). Слово «ссылка» встречается в транскрипте каждого видео ровно один раз — по одному ролику на файл, резать по паузам не требовалось.

## Палитра

Комната и свет холодные, без переключения — продолжение исторической классификации комнаты «максим» (`#C9F5FF`).

## ASR-правки

Пайплайн: sherpa-onnx zipformer (ru) + silero VAD → `asr_batch.py` → `build_words.py` → ручная правка через `apply_fixes.py`, каждая неоднозначная правка проверена `redecode_ts.py` перед применением.

- **Все три видео:** `"егэ"` → `"ЕГЭ"` (регистр).
- **video1:** CTA («ссылка на тренажёр в шапке профиля») распознана полностью и чисто, без фиксов.
- **video2:** `"к заданием"` → `"к заданиям"` (падежное согласование с «по биологии»); CTA — широкий передекод 25.6-27.6с подтвердил отдельный токен «в» перед «шапки» (VAD/токенизатор не выделил его отдельным словом), «шапки» → «шапке».
- **video3:** `"да"+"ты"` (9.02-9.28с, межтокенный разрыв 0.02с — идентичен обычному внутрисловному интервалу этой модели) → склеено в `"даты"`: вариант «да ты там надо ставить по порядку» не согласуется грамматически, тогда как «даты там надо ставить по порядку» совпадает по конструкции с устойчивой фразой этого же ролика («где даты смуты надо расставить по порядку», 20.9с) и с первым упоминанием «даты смуты» (1.1с); CTA — широкий передекод 26.6-28.5с подтвердил отдельный токен «в» перед «шапки», «шапки» → «шапке».

После применения правок — проверка на пересечения временных меток слов: пересечений и отрицательных длительностей не найдено ни в одном видео.

`build_words.py`, `asr_batch.py`, `pipeline.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` унаследованы из `maksim1710` без правок кода.

## Карточки и тайминги

`data1.py`/`data2.py`/`data3.py` — хук (0-2.4...2.6с, акцентный, формулирует боль ЕГЭ-предмета ученика, не пересказ первой фразы) + 7-8 карточек на видео (1-3 слова, кегль 85-95/40-48px) + бегущая подпись (из слов, PT Sans Narrow Bold) + 4 эмфасис-зум окна на ролик. Валидация пройдена (`validate.py`): нет пересечений карточек/хука/зума, последняя карточка заканчивается точно на DURATION, хук закрывается строго до первой карточки, зум-окна не пересекаются.

- video1 (химия, тестовая часть ЕГЭ): хук «ТЕСТЫ ПО ХИМИИ / НЕ ИДУТ?», 8 карточек, CTA.
- video2 (биология, задача 27): хук «ЗАДАЧА 27 / НЕ СХОДИТСЯ?», 9 карточек, CTA.
- video3 (история, даты смуты): хук «ДАТЫ СМУТЫ / НЕ ЛЕЗУТ В ГОЛОВУ?», 9 карточек, CTA.

Иконка приложения (ЕГЭ ТРЕНАЖЁР) появляется на оба голосовых упоминания в каждом ролике (автоматически по паттерну `тренаж` в `words{N}.json`):
- video1: окна (18.46, 21.46) и (26.876, 28.36)
- video2: окна (18.132, 21.132) и (25.716, 27.4)
- video3: окна (17.948, 20.948) и (26.684, 28.28)

## Громкость

Двухпроходный EBU R128 (`loudnorm.py`, TP-цель −2.0 на обоих проходах, §4.5.1) + финальная проверка TP на готовом AAC-файле. Все три прошли на обычном проходе, лимитер-эскалация не понадобилась:

| видео | pass1 измерено | финальный AAC (после кодирования) |
|---|---|---|
| video1 | I=-18.76 TP=-5.03 LRA=2.70 | I=-14.17 LUFS, TP=-1.87 dBTP |
| video2 | I=-18.47 TP=-4.44 LRA=3.20 | I=-14.18 LUFS, TP=-1.82 dBTP |
| video3 | I=-18.97 TP=-4.48 LRA=3.40 | I=-14.37 LUFS, TP=-1.68 dBTP |

## QA

Стоп-кадры на хук/карточка/иконка/зум/CTA извлечены и просмотрены для всех трёх видео (23 кадра). Хук закрывается строго до старта первой обычной карточки; карточки не вылезают за края кадра, текст не на лице/рту, поля соблюдены; иконка приложения полностью непрозрачна, крупная (280px), справа на уровне головы, не перекрывает лицо, появляется на оба упоминания в каждом ролике; CTA «ссылка в шапке профиля» идентичен во всех трёх; акцент только ледяной голубой, один сет на ролик. Дефектов не найдено.

## Файлы в этой папке

`pipeline.py`, `asr_batch.py`, `build_words.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` — унаследованы от `montage_maksim1710/` без правок кода. `gen_render.py` — правка на один путь (имя ASS-файла `subs_m2010_{i}` вместо `subs_m1710_{i}`). `data1.py`/`data2.py`/`data3.py` — карточки/хук/эмфасис/длительность. `apply_fixes.py` — ASR-правки. `validate.py` — инлайн-проверка таймингов карточек/хука/зума (нет пересечений, последняя карточка = DURATION). `asr{1,2,3}.json`/`words{1,2,3}.json` — распознавание речи. `subs_m2010_{1,2,3}.ass` — готовые субтитры. `render{1,2,3}.sh` — сгенерированные ffmpeg-скрипты рендера.

Исходные видео (video1/2/3.mp4) и промежуточные/финальные рендеры НЕ архивируются — только код и транскрипты. Готовые ролики лежат в `work/максим2010/максим2010_{1,2,3}.mp4`.
