## ASR-правки

- **video1:** «фипи» → «ФИПИ» (регистр); «шапки» → «шапке». Переполнения времени последнего слова нет (24.128 < 24.130).
- **video2:** без искажений текста. Отдельно проверено слово «находят» (18.908-19.368, «текстовый разбор который находят такие скрытые ошибки») — грамматически ожидалось бы «находит» (согласование с единственным числом «разбор»), но независимый повторный передекод сегмента дважды подтвердил именно «находят» — это реально произнесённая форма (небольшая оговорка диктора), а не искажение ASR. Оставлено как есть в бегущей подписи по установленному принципу не «исправлять» подтверждённую реальную речь; в крупной карточке использована грамматически чистая формулировка «НАХОДИТ» — карточки являются пересказом, а не дословной цитатой. Переполнения времени нет (24.008 < 24.364).
- **video3:** искажённый первый токен «точь» (0.22-0.52) → «дочь», подтверждено повторным распознаванием сегмента 0.0-4.9с («дочь верно применяет правила по русскому языку...»); слипшийся фрагмент «без работы в работ» (12.988-13.928, 4 токена) → «из работы в работу», подтверждено повторным распознаванием сегмента 11.5-17.2с («почти всегда одна и та же из работы в работу в егэ тренажёре...») — токен-в-токен замена «без»→«из» и «работ»→«работу», середина («работы», «в») не изменилась. Переполнения времени нет (24.704 < 24.706).

## QA

Полный чеклист §4.6 пройден для всех трёх видео. Хук (Слой 0) закрывается до старта первой карточки во всех трёх (2.90с). Карточки не превышают 4с. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо). Бегущая подпись непрерывна, в одном слоте, по одному слову. CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх после ASR-правок. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Ложных срабатываний на фейд-окне иконки не зафиксировано. Дефектов не найдено.
