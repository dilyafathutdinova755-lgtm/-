## Проверка на дубли (протокол §8)

Комната визуально совпадает с батчем **dmitry115** (тёмный стеллаж с книгами, кремовая стена, тёплая лампа, кашпо с растением, чёрно-белое фото в рамке, деревянный стол) — запущена усиленная проверка:

- sha256 сверен против всех 18 исторических исходников дмитрий-семьи (dima1, dimaaa, dmitry1, dmitry11, dmitry115, dmitry1809) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против dmitry115 — совпадений нет.
- Полный ASR-транскрипт сверен именно с dmitry115 — три новых сюжета:
  1. Короткое утверждение «верно/неверно» вместо необходимости вчитываться в развёрнутое задание целиком.
  2. Время последнего показа карточки вместо порядкового номера.
  3. Короткое уведомление за 5 минут до конца пробника вместо узнавания об окончании только по факту закрытия теста.

Ни один сюжет не пересекается с тремя сюжетами dmitry115 (проверка объяснения прямо в приложении вместо случайного видео блогера; ответ блокируется до автосинхронизации с ФИПИ; приложение само выбирает дневное задание по слабым темам). Дубликат исключён.

## ASR-правки

- «шапки» → «шапке» (video2, video3 — повторяющаяся ошибка падежа в CTA; video1 транскрибировано верно сразу).
- «приходят» → «приходит» ×2 (video3 — согласование подлежащего «уведомление» (ед.ч., ср.р.) со сказуемым: «уведомление приходит один раз», «уведомление приходит заранее»).

`build_words.py` унаследован из dmitry115 уже с фиксом бага переполнения времени последнего слова — повторного исправления не потребовалось (проверено через grep перед началом работы). Остаточное переполнение (0.009с) на последнем слове видео3 клэмпнуто вручную под фактическую длительность (32.544→32.535).
