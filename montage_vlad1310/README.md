## Проверка на дубли (протокол §8)

Длительности новых файлов (19.586с / 18.540с / 19.970с) сверены со всей исторической базой длительностей по git-истории всей семьи тегов «влад» (`vlad0110`, `vlad0210`, `vlad0310`, `vlad061011`…`vlad101011`, `vlad11`, `vlad1809`, `vlad1909`, `vlad2`, `vlad2609`, `vlad2909`, `vlad3009`, `vladik`, `vladik1`, `vladik11`, `v.влад2209`, `v.влад23092монтаж`, `v.влад24091`, `v.влад2509`).

Найдено два формальных совпадения длительности, оба эскалированы до полного ASR-сравнения:

- **video2 (18.540с)** совпал с `v.влад2509`/video2. Это другая комната/семья тегов (`v.влад`, отдельная линия с иным визуальным сетом, хоть и похожим гардеробом) — sha256 не совпадает. ASR-сравнение: новый сюжет — «пишешь решение без обоснования „получаем", экзаменатор снимает балл, в приложении есть текстовый разбор» — не пересекается ни словом со старым сюжетом `v.влад2509`/video2 («орфографическое правило повторяют одним способом — перечитывают учебники, держится недолго, в приложении есть игры на запоминание»). Разные темы — не дубль.
- **video3 (19.970с)** совпал с `влад091011`/video3 — та же студия/линия героя. ASR-сравнение: оба сюжета используют один и тот же оффер приложения (игры на запоминание по истории), но с полностью разным конкретным содержанием — новый про запоминание имён князей Руси, старый про расстановку по порядку событий Великой Отечественной. Формулировки не совпадают ни одной фразой — presenter повторяет рабочий оффер с новым конкретным сценарием, это уже наблюдавшийся паттерн (см. `nikita101011`, `maksim101011`), не переливка.

sha256 всех трёх новых файлов не совпадает ни с одним историческим — не переливка.

Сюжеты партии: video1 — сборник ЕГЭ в подарок с надписью «чтоб сдал на сто» ощущается как давление, а не подарок; решение — по одному заданию в день через банк ФИПИ без давления; video2 — записанное в решении «получаем» без обоснования стоит балла на экзамене, в приложении есть текстовый разбор, где объяснено каждое «получаем»; video3 — князей Руси слишком много, чтобы зазубрить по одному, в приложении есть игры на запоминание короткими раундами. Три новых, самостоятельных сюжета.

## Палитра

Пиксельный замер по участку стены (три кадра): R/B≈1.229-1.234 — холодный сет (нейтральная нейтрально-бежевая стена, не янтарный свет). `pipeline.py` унаследован от `vlad101011` без переключения (`ACCENT = "&H00FFF5C9&"`, #C9F5FF, холодный сет).

## ASR-правки

- **video1:** «егэ» → «ЕГЭ» caps. Слипшиеся токены «пи»+«пи» → объединены в «ФИПИ» (подтверждено передекодом сегмента 12.8-14.5с: «есть банк фипи где можно»). CTA распознан полностью корректно без правок.
- **video2:** «егэ» → «ЕГЭ» caps. Орфография «бал» → «балл» (дважды, тот же корень, явная опечатка распознавания). В CTA VAD потерял слово «в» перед «шапке» — вставлено по передекоду сегмента 16.4-18.7с, подтвердившему «ссылка на тренажёр в шапке профиля» целиком.
- **video3:** «егэ» → «ЕГЭ» caps (дважды). Явная ошибка распознавания «сука» → «ссылка» и пропущенное VAD «в» перед «шапки»→«шапке» — оба подтверждены одним передекодом сегмента 17.6-20.0с («сука на тренажёр в шапке профиля» → реальный смысл «ссылка на тренажёр в шапке профиля»).

Все вставки/правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `vlad101011` без правок кода.
