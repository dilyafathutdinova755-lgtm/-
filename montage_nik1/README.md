# Монтаж «Никита» — 3 ролика (тег `ник1`, четвёртая партия)

Исходники: релиз с тегом `ник1` (сокращённое имя тега, тот же герой,
что в партиях `никита`/`никитааа`/`никита;` — зелёный свитер, книжный
шкаф с тёплой лампой-эдисон, MacBook со стикером тигра). Файлы датированы
`12.09`. Тёплый сет (§1.2): акцент `#FCF5AA`.

Три новых сюжета про технические особенности ЕГЭ Тренажёра, проверено
протоколом §8 (разные транскрипты и длительности, не дублируют прежние
партии Никиты):
1. Офлайн-доступ: банк ФИПИ сохраняется на устройство заранее, задания
   и разбор открываются без сети (например, в метро по дороге в школу).
2. Актуальность вариантов: старые формулировки автоматически заменяются
   новыми сразу после публикации официальной демоверсии ФИПИ.
3. Статистика по темам: процент верных ответов виден по каждой теме
   отдельно на одном экране, без перехода в разделы.

## Исправлены два речевых артефакта ASR (до рендера)

1. **Обрезанное первое слово.** Видео 1 и видео 2 начинаются точно на
   t=0.284 без запаса тишины — VAD/ASR откусил приставку «вы» у слова
   «выпускники», распознав только «пустники». Исправлено вручную в
   `words1.json` и `words2.json` — иначе бегущая подпись показала бы
   несуществующее слово первым кадром ролика.
2. **Развалившееся «ЕГЭ» в CTA видео 1.** ASR разбил слово «ЕГЭ» на
   два токена «ега» + «я» (акустическая путаница на быстрой речи, не
   реальная запинка — интервал между токенами слишком плотный для
   настоящего фальстарта). Склеено обратно в `words1.json` до генерации
   субтитров.

Оба исправления — только в JSON с таймкодами речи, сам звук ролика не
трогали; на экране в готовых видео отображается корректный текст.

Результаты — `../nik1/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_n{1,2,3}.ass` | готовые субтитры |
| `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды (1 и 2 — с ручными правками) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1): исходники
необычно тихие (−23…−24 LUFS до нормализации, шире обычного LRA).
Видео 1 и 3 упёрлись в TP-потолок и остались выше цели (−15.8/−15.5
LUFS) — ожидаемая характеристика этой конкретной записи (см. §4.5.1),
видео 2 легло точно на −14.75. TP на всех трёх — около −1.7…−1.8 dBTP
на готовом AAC-файле, с запасом.
