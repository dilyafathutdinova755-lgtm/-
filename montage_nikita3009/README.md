## ASR-правки

- video1: «задание» → «задания» (падежное согласование после «тип», подтверждено повторным распознаванием с контекстом); «экзамен» → «экзамена» (падеж после «формата»); слипшийся токен «вига» (13.948-14.168) разобран на «в»+«ЕГЭ» по пропорциональному таймингу; «капти» → «шапке» (искажённое распознавание CTA, характерное для этого героя — «в» перед «шапке» устойчиво не транскрибируется отдельным токеном); «профиль» → «профиля» (падеж).
- video2: «его» → «ЕГЭ» (искажение, «в» уже был отдельным токеном); слипшийся токен «заданием» (14.396-14.936) разобран на «к»+«заданиям» по пропорциональному таймингу (тот же паттерн, что в `никита2909`); «шапки» → «шапке» (падеж); клэмп переполнения времени последнего слова (22.4→22.35, факт. длительность 22.380с).
- video3: слипшийся токен «лига» (2.364-2.888) — не расслышан с первого раза; повторное распознавание с расширенным контекстным окном («по истории для егэ очень похоже на») подтвердило разбор на «для»+«ЕГЭ»; слипшийся токен «напробуйте» (9.54-10.12) аналогично перепроверен расширенным контекстом («такие две даты на пробнике хотя») и разобран на «на»+«пробнике» («пробник» = разговорное «пробный экзамен», по смыслу и по звучанию подходит точно); «капти» → «шапке» (тот же паттерн, что в video1); «профиль» → «профиля»; клэмп переполнения времени последнего слова (23.264→23.23, факт. длительность 23.255с).

`build_words.py` и `asr_batch.py` унаследованы из `никита2909` без правок кода.
