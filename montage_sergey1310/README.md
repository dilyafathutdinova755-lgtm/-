## Проверка на дубли (протокол §8)

Длительности новых файлов (20.360с / 17.964с / 19.080с) сверены со всей исторической базой длительностей по git-истории всей семьи тегов «сергей» (номерная линия `сергей0110`…`сергей101011`, отдельная семья «отец» `сергейй1`/`сергей1`/`сергей1й`/`сергей11`/`сергей115` — разный герой/комната, и `v.сергей2209/230911/240926/2509/2609` — та же студия, другая тег-конвенция).

Найдено одно формальное совпадение длительности: **video3 (19.080с)** совпал с `v.сергей2609`/video1 — та же студия/герой. Эскалировано до полного ASR-сравнения: новый сюжет — «сын уверен, что запятые на ЕГЭ по русскому — дело вкуса, я не могу его переубедить, запятые подчиняются правилам, в ЕГЭ тренажёре есть игры на запоминание, где запятые проверяются на коротких примерах» — не пересекается ни словом со старым сюжетом `v.сергей2609`/video1 («сын может месяцами решать задания ЕГЭ которые давно не встречаются в реальном экзамене, я сверил тетрадь с демоверсией, в ЕГЭ тренажёре есть банк ФИПИ с заданиями которые обновляются под текущий формат»). Разные темы, разный конкретный оффер — не дубль.

sha256 всех трёх новых файлов не совпадает ни с одним историческим — не переливка.

Сюжеты партии: video1 — сын считает ЕГЭ лотереей, и готовиться бессмысленно; отец приводит пример: даже в лотерее выигрывают те, у кого больше билетов, а решённые задания и есть билеты, банк ФИПИ в приложении помогает их легко набирать; video2 — сын сдал пробник без разбора ошибок, баллы показывают только итог, а работа над ошибками начинается с разбора каждой, в приложении есть текстовый разбор к каждому заданию; video3 — сын уверен, что запятые — дело вкуса, на деле они подчиняются правилам, проще всего убедить его короткими примерами, в приложении есть игры на запоминание по русскому языку. Три новых, самостоятельных сюжета.

## Палитра

Пиксельный замер по участку кирпичной стены (три кадра): R/B≈4.281-4.482 — тёплый сет, продолжает исторический рост для этой комнаты (`v.сергей2609`: 2.961-3.001 → `сергей0310`: 3.308-3.389 → `сергей071011`: 3.501-3.508 → `сергей091011`: 3.698-3.742 → теперь 4.281-4.482). `pipeline.py` унаследован от `сергей091011` без переключения (`ACCENT = "&H00AAF5FC&"`, #FCF5AA, тёплый сет, оранжевый не использован).

## ASR-правки

- **video1:** «егэ» → «ЕГЭ» caps (дважды). Слипшиеся токены «пи»+«пи» → объединены в «ФИПИ» (подтверждено передекодом сегмента 13.2-14.8с: «есть банк фипи где»). В CTA вставлено пропущенное VAD «в» перед «шапки»→«шапке» (подтверждено передекодом сегмента 18.1-20.4с).
- **video2:** «егэ» → «ЕГЭ» caps (дважды). CTA распознан полностью корректно без дополнительных правок — редкий случай без VAD-потерь.
- **video3:** «егэ» → «ЕГЭ» caps (дважды). «запоминания» → «запоминание» (падеж, установленная формулировка «игры на запоминание»). В CTA вставлено пропущенное «в» перед «шапке» (форма «шапке» в этот раз распознана верно изначально, не требовала отдельной правки) — подтверждено передекодом сегмента 16.8-19.1с.

Все вставки/правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `сергей091011`, цикл расширен с `['1','2']` на `['1','2','3']`.
