## Палитра

Пиксельный замер по участку нейтральной стены (два кадра, видео1 и видео2): R/B=1.562 и R/B=1.547. Значение продолжает исторический тренд роста для этой комнаты (`v.дмитрий240912`: 1.295-1.302 → `vdmitry2509`: 1.510-1.517 → теперь 1.547-1.562), отмеченный ещё в архиве `vdmitry2509` как выходящий за формальный порог, но классифицируемый холодным по визуальной и предметной преемственности комнаты (тот же свет, тот же реквизит, нет амбер-подсветки на глаз). Решение по этому же принципу: классифицировано холодным, не по формальному порогу R/B, а по непрерывности комнаты/героя. `pipeline.py` унаследован от `vdmitry2509` без переключения (`ACCENT = "&H00FFF5C9&"`, #C9F5FF).

## ASR-правки

- **video1:** «егэ» → «ЕГЭ» caps (генерик и продуктовое упоминание); «пи»+«пи» слипшиеся токены → объединены в «ФИПИ». CTA: вставлено пропущенное «в» перед «шапки»→«шапке» (падежная правка).
- **video2:** «егэ» → «ЕГЭ» caps (дважды). CTA уже содержала корректное «в шапке профиля» — правок не потребовалось. Пронаблюдано и оставлено без изменений легитимное местоимение «сравнить его с образцом» (речь о шаге решения, не о продукте) — не спутано с «ЕГЭ».
- **video3:** «егэ» → «ЕГЭ» caps. **Найдена акустически неоднозначная замена** — исходный ASR дал «в его тренажёре по истории есть игры...», что не имеет грамматического референта («его» = чьём? — предыдущее предложение не называет владельца). Передекод несколькими окнами показал смешанный результат («его» в одном широком окне, «ЕГЭ» в двух более узких), но «ЕГЭ тренажёре» — единственный вариант, совпадающий с фиксированной фразой продукта, используемой во всех видео проекта. Исправлено: «его» → «ЕГЭ». CTA: вставлено пропущенное «в» перед «шапке».

Все вставки/правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `vdmitry2509` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео (проверка стоп-кадрами: хук, карточка+бегущая подпись, иконка, CTA, пик эмфасис-зума). Хук закрывается до старта первой карточки во всех трёх (2.90с), целиком акцентным цветом (холодный #C9F5FF), без одновременного показа с обычной карточкой. Карточки не превышают 4с, межстрочный интервал плотный, акцентная строка крупнее белой с тонкой обводкой. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо) — первый стоп-кадр video3 случайно попал на 0.05с внутрь 0.32с фейд-ина и показал полупрозрачную иконку, повторная проверка кадром из середины показа (по методологии §1.4 применительно к иконке) подтвердила полную непрозрачность, ложного срабатывания не было. Бегущая подпись непрерывна, в одном слоте, по одному слову — реконструированные вставки «в» в CTA (video1, video3) и правка «его»→«ЕГЭ» (video3) проверены отдельно стоп-кадром, отображаются корректно без тайминг-глитчей. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Дефектов не найдено.

Рендер выполнялся строго последовательно (video1 → video2 → video3), не параллельно, по установленной в прошлых партиях практике.
