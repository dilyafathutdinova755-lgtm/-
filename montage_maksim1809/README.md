## Проверка на дубли (протокол §8)

Комната визуально совпадает с батчем **maksim1709** (те же постеры на стене, оранжевая лампа-мухомор, светлый шкаф-купе, стеллаж с книгами и камерой, тот же чёрный худи с принтом). Это визуальное совпадение с конкретным прошлым батчем запустило усиленную проверку:

- sha256 сверен против всех 18 исторических исходников максим-семьи (maks2, maksim1, maksim16, maksim1709, maksim2, maksimka1) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против maksim1709 — совпадений нет.
- Полный ASR-транскрипт сверен именно с maksim1709 — три новых сюжета:
  1. Задания ЕГЭ помечаются значком «доступно офлайн» заранее дома, ещё до потери сигнала в зале.
  2. Два похожих тактических понятия из задания показываются рядом с одним отличием, видным сразу, а не после финального балла всего теста.
  3. Последняя открытая карточка с термином повторяется одним нажатием прямо во время короткого перерыва между подходами, без пролистывания всего списка заново.

Ни один сюжет не пересекается с тремя сюжетами maksim1709 (слабый предмет выделяется цветом по проценту решённых заданий; доступ не привязан к сроку абонемента; соревнование по количеству решённых заданий с друзьями и командой). Дубликат исключён.
