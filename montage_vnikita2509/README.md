# v.никита2509 — монтаж 3 роликов

Release tag: `v.никита2509` (id 396751237).

**Особые обстоятельства этой партии.** В начале задачи обнаружено, что локальный чекаут репозитория в этой сессии был на посторонней, не связанной ветке истории (коммиты про эпизоды другого — Remotion/React-based — пайплайна монтажа: `auto-montage.yml`, эпизоды presenters «Вера22», «Соня22», «Арина22» и т.д.), из-за чего CLAUDE.md временно подменился на устаревшую версию гайда без трёхслойных субтитров и с реверченными правками (кегль карточки, обводка акцента, TP-цель громкости). Проверка `git fetch` + сверка с реальным `origin/claude/session-vb0g3j` показала, что настоящий актуальный коммит ветки на GitHub — это `a81e3e3` («Монтаж 3 роликов: v.максим24091», последний коммит предыдущей партии), т.е. вся история этой сессии (54 прошлых архива `montage_*`) цела на сервере — просто локальная копия контейнера была развёрнута неверно. Исправлено через `git reset --hard origin/claude/session-vb0g3j`; CLAUDE.md, все `montage_*/` и рабочий пайплайн восстановлены. Также в этом контейнере пришлось заново поставить `ffmpeg`, `Pillow`, `sherpa-onnx`, `numpy` и скачать ASR-модель (`sherpa-onnx-zipformer-ru-2024-09-18`), `silero_vad.onnx` и шрифты (`GolosText-Black.ttf`, `PTSansNarrow-Bold.ttf` — через `fonts.gstatic.com`, т.к. `fonts.google.com`/raw.githubusercontent.com для этого репозитория закрыты сетевой политикой) — это разовая рабочая инфраструктура, к содержанию монтажа отношения не имеет.

## Проверка на дубли (протокол §8)

Герой и комната — presenter «Никита», худи NEVORA, тёмный стеллаж с книгами — совпадает с батчами v.никита2209, v.никита23092, v.никита240912. Запущена усиленная проверка:

- sha256 всех трёх новых файлов сверен со всеми 92 историческими hash-значениями по всей ветке — совпадений нет.
- Длительности (14.615 / 14.700 / 13.250с) — эти ролики заметно короче обычных (14-15с против типичных 18-23с), но не совпадают ни с одной исторической записью.
- Полный ASR-транскрипт сверен с `v.никита240912` (последний батч этого героя): новые три сюжета (ошибка в задании ЕГЭ может повторяться, объяснение каждый раз новое, но у похожих ошибок одна общая причина / определение можно перечитать 10 раз и всё равно путать на экзамене — игры на запоминание / сборники выглядят солидно, но давно не обновлялись — банк ФИПИ) не пересекаются дословно ни с одним прежним скриптом.

**Важное наблюдение (не дубль, но почти дословное совпадение одной фразы).** В video2 фраза «простое чтение списка плохо превращается в уверенное...» почти буквально повторяет фразу из `v.никита240912`/video2 («простое чтение списка плохо превращается в уверенное знание») — тот же герой, та же формулировка-клише про механизм запоминания. Остальной текст обоих роликов разный (разные вступления, разный порядок пунктов). Это похоже на повторяющуюся заготовку-клише в речи presenter'а, а не на повторную заливку — sha256 разные, окружающий текст разный. Кроме того, три темы этой партии (текстовый разбор, игры на запоминание, банк ФИПИ) — снова тот же набор из трёх базовых офферов кампании, который уже был у этого героя во всех трёх прошлых батчах.

## ASR-правки

Партия потребовала обычный набор правок для этой комнаты (у ASR систематически плохо получается слово «ЕГЭ» и хвост CTA):

- video1: «г» → «ЕГЭ» (искажённый токен вместо «в задании ЕГЭ»); «иг» → «ЕГЭ» (аналогично, «в ЕГЭ тренажёре»); «профиль» → «профиля» (падеж CTA); клэмп переполнения времени последнего слова (14.624→14.60).
- video2: «его» → «ЕГЭ» («в ЕГЭ тренажёре»); «шапки» → «шапке»; клэмп переполнения времени последнего слова (14.72→14.68). Фраза «в уверенное...» оставлена без добавления недостающего слова в words.json (нет объективных данных о его таймкоде), но карточка Слоя 1 сформулирована с «ЗНАНИЕ» на основе идентичной фразы из архива этого же героя (см. наблюдение выше).
- video3: «ега» → «ЕГЭ»; слипшиеся токены «пи»+«пи» → «ФИПИ»; «шапки» → «шапке».

`build_words.py` и `asr_batch.py` унаследованы из `v.никита240912` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео (короткие ролики ~13-15с потребовали меньше карточек, чем обычно, но структура хук→карточки→CTA сохранена полностью): хук закрывается до старта первой карточки, карточки не превышают 4с, иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы), бегущая подпись непрерывна и не смещается со слота, CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх. Стоп-кадры (hook/card+icon/CTA/эмфасис-зум) проверены визуально для всех трёх роликов — дефектов не найдено, тёплый акцент отрендерился корректно.
