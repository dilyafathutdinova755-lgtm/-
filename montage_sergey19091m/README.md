## Проверка на дубли (протокол §8)

Комната визуально совпадает с батчем **сергей1909** (тот же панельный интерьер, торшер с абажуром, оливковое кресло, голубая рубашка) — это самый свежий предыдущий батч того же героя. Запущена усиленная проверка:

- sha256 сверен против всех 18 исторических исходников сергей-семьи (sergey1, sergey11, sergey115, sergey1909, sergey1_v2, sergey1y) — совпадений нет.
- sha256 извлечённых аудиодорожек (audio{1,2,3}.wav) сверен отдельно против сергей1909 — совпадений нет.
- Полный ASR-транскрипт сверен именно с сергей1909 — три новых сюжета:
  1. ЕГЭ Тренажёр устраивает короткую дуэль с собственным результатом недельной давности вместо поиска случайного соперника онлайн.
  2. Термин ЕГЭ предлагается только голосом, без текста на экране — правильный ответ произносится вслух, текст открывается только после этого.
  3. Сегодняшний результат сравнивается с собственным средним за неделю, а не с чужим местом в рейтинге.

Ни один сюжет не пересекается с тремя сюжетами сергей1909 (регулировка скорости видео-разбора, прогресс одним предложением вместо графиков, старт пробника без привязки к расписанию). Дубликат исключён.
