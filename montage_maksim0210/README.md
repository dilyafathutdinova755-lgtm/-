## Проверка на дубли (протокол §8)

Герой и комната — presenter «Максим», постеры (Bastille, чёрно-белые кадры, красная афиша), деревянный шкаф-купе, полка с плёночной камерой и книгами, серый свитер, петличка — совпадает с историей этого героя (`максим0110`, `максим3009`, `максим2909`).

sha256 всех трёх файлов сверен со всеми историческими hash-значениями по всей ветке — совпадений нет. Самый чистый случай за всю серию: длительности (27.564/26.455/25.090с) не совпали вообще ни с одним историческим роликом — ни с историей этого героя, ни с какими-либо другими. Усиленная ASR-сверка не требовалась.

Сюжеты партии: video1 — задания ЕГЭ, найденные на старом ноутбуке брата, дата создания файлов не проверена, задание оказалось за позапрошлый год; video2 — многократная смена способа решения на ходу без доведения ни одного до конца; video3 — понятие по обществознанию, запомненное по упрощённому посту в соцсетях, не совпадающее с официальной формулировкой. Три новых, самостоятельных сюжета.

## ASR-правки

- **video1:** «тренажаре» → «тренажёре» (искажённая гласная ё→а); «бамк» → «банк»; «фипи» → «ФИПИ» (регистр); «шапки»/«профиль» → «шапке»/«профиля». Клэмп переполнения времени последнего слова (27.584→27.52, факт. длительность 27.564с).
- **video2:** та же искажённая гласная «тренажаре» → «тренажёре». Клэмп переполнения времени последнего слова (26.464→26.42, факт. длительность 26.455с).
- **video3:** без искажений — самая чистая начитка из трёх. Переполнения времени нет (25.088 < 25.090).

Искажение «тренажаре» вместо «тренажёре» повторилось в двух видео подряд этого героя — вероятно, устойчивая особенность произношения или акустики записи, учтено как ожидаемый паттерн для будущих батчей этого ведущего.

`build_words.py` и `asr_batch.py` унаследованы из `максим0110` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео. Хук закрывается до старта первой карточки во всех трёх (2.90с). Карточки не превышают 4с. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо). Бегущая подпись непрерывна, в одном слоте, по одному слову. CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх после ASR-правок. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Ложных срабатываний на фейд-окне иконки не зафиксировано. Дефектов не найдено.
