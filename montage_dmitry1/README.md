# Монтаж «Дмитрий» — 3 ролика (тег `дмитрий1`)

Исходники: релиз с тегом `дмитрий1`. Ассет 1 назван с лишней точкой
(`Untitled.Video.1.10.09._2160p.mp4`) — скачан и проверен как есть,
на монтаж не влияет. Новый герой (отец, домашний кабинет с книжным
шкафом и торшером) — первое появление в этой сессии.

Освещение нейтральное, серо-бежевые стены, дневной свет без выраженного
янтарного оттенка на коже/стенах — классифицирован как **холодный сет**
(§1.2), акцент `#C9F5FF`.

## Дубль внутри партии (важно)

**Видео 1 и видео 3 — один и тот же текст, начитанный дважды**
(«заметил что сын угадывает ответы в тестах по егэ… важнее процента
правильных ответов»), почти слово в слово (единственное отличие —
«родителя» vs «родителей»). Длительности разные (37.27с и 35.88с),
файлы не битые и не идентичные побайтово — это два разных дубля одного
сценария, а не поломка. Видео 2 — отдельный сюжет (чек-лист порядка
тем за учебный год).

Перед монтажом это было явно вынесено пользователю на решение (см. чат):
выбран вариант **смонтировать оба дубля как отдельные полноценные
ролики**, с разными формулировками хука, чтобы они не читались как
буквальный повтор при показе рядом:
- Видео 1: «ЗНАЕТ ИЛИ УГАДЫВАЕТ?»
- Видео 3: «ХОРОШИЙ БАЛЛ — ЭТО ЗНАНИЯ?»

Карточки по содержанию неизбежно близки (тот же сценарий), но таймкоды
и хук у каждого свои, под собственную дорожку слов из ASR.

Результаты — `../dmitry1/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_d{1,2,3}.ass` | готовые субтитры |
| `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды |

Видео 2 — второй случай в этой ветке с тремя раздельными голосовыми
упоминаниями «тренажёр» без нахлёста окон (4.4с, 23.7с, 30.3с).

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1, правка
10.09.2026): все три ролика легли в −1.5…−1.9 dBTP на готовом
AAC-файле, интегральная громкость −14.2…−14.7 LUFS — с первой попытки.
