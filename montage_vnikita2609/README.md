## ASR-правки

Партия потребовала более серьёзных правок, чем обычно у этой комнаты — систематическое искажение фразы «в ЕГЭ тренажёре»:

- video1: «игр» — один искажённый токен, слипший «в»+«ЕГЭ» → разбит на два слова по таймингу (пропорционально длительности исходного токена); «тренажёры» → «тренажёре» (сбитое число/падеж); «шапки» → «шапке».
- video2: **самая серьёзная правка партии** — «тренажёрик» слипал сразу четыре слова «в ЕГЭ тренажёре к» → разбит на 4 токена по таймингу; «заданием» слипал «каждому заданию» (два слова, неверный падеж) → разбит на 2 токена. CTA «в шапке профиля» распознан корректно с первого раза. Слово «они» на хвосте фразы «...показывает развилку в решении они» оставлено как есть — судя по отсутствию паузы перед ним, речь была продолжена, но следующий сегмент ASR не захватил продолжение; в карточку это слово не выносилось (карточка Слоя 1 построена только на уверенной части фразы «текстовый разбор»).
- video3: «вига» → «ЕГЭ» (искажённый токен, «в» уже был распознан отдельно); «шапки» → «шапке»; «профи» → «профиля» (последнее слово ролика ASR распознал не полностью, хотя таймкод заканчивается ровно на границе длительности файла — похоже на фонетически неуверенное распознавание хвоста слова, а не реальный обрыв записи).

`build_words.py` и `asr_batch.py` унаследованы из `v.никита2509` без правок кода.
