# Монтаж «Сергей» — 3 ролика (тег `сергейй1`)

Исходники: релиз с тегом `сергейй1`. Ассеты называются так же, как в
других недавних партиях (`Untitled.Video.{1,2,3}.10.09_2160p.mp4`), но
это новый герой — отец, родительская перспектива (а не подросток), тёплая
вечерняя комната с торшером, кресло. Первое появление этого героя в этой
сессии; отдельный тег `сергей` (другой id релиза, обработан ранее ДРУГИМ
пайплайном на Remotion — см. коммиты `31b0bee`/`7683ac8`/`c6fbf68` на
`main`, не в этой ветке) содержит другие конкретные истории — не дубль.

Три новых сюжета от родительского лица, все проверены протоколом §8
(разный полный ASR-транскрипт, по одному «ссылка» на видео):
1. Отец сам, без сына, открыл ЕГЭ Тренажёр проверить комментарий «все
   бесплатные варианты одинаково поверхностные» — разбор оказался чётче,
   чем в его школьные годы.
2. Спросил сына не «нравится ли», а что именно путает прямо сейчас —
   конкретный вопрос сработал лучше общего, подтверждено на пробнике.
3. Собственный ежемесячный чек-лист из трёх пунктов, по которым отец
   проверяет приложение, прежде чем доверять ему учебное время сына.

Результаты — `../sergey1/*_smontirovano.mp4`, 1080×1920, 25fps.
Тёплый сет (§1.2): акцент `#FCF5AA`, оранжевый не использован.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_s{1,2,3}.ass` | готовые субтитры |
| `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды |

Видео 3 — первый случай в этой ветке с **тремя** отдельными голосовыми
упоминаниями «тренажёр» без нахлёста окон (4.08с, 25.59с, 32.53с — интервалы
больше 3с хвоста, поэтому иконка выходит трижды отдельными окнами, не
склеиваясь). Проверено на кадре при каждом окне (§1.6).

Звук — двухпроходный EBU R128 с уже исправленным запасом TP `-2.0`
(правка 10.09.2026, см. `../montage_vlad2/README.md`): все три ролика
партии легли в −1.2…−2.0 dBTP на готовом AAC-файле, интегральная
громкость −14.4…−14.9 LUFS — с первой попытки, без повторной правки.
