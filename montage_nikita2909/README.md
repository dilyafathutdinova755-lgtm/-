## ⚠ Особый случай — video3 без спетого CTA

Транскрипт video3 заканчивается фразой «...тренируют узнавание именно тестовых формулировок» — и всё, дальше тишина до конца файла. Ни в одном другом ролике этой или прошлых партий такого не было: обычно каждый ролик заканчивается «ссылка на тренажёр в шапке профиля» голосом.

Проверено отдельно, что это не ошибка распознавания: хвост аудио (20.5-22.4с) прогнан через ASR повторно с усилением громкости (+12dB) — распознавание вернуло чистое «именно тестовых формулировок» и ничего больше, амплитуда в хвосте (0.39) сопоставима с максимумом по всему файлу (0.47), то есть звук не был слишком тихим для распознавания — presenter просто не произнёс CTA в этом дубле.

Вопрос вынесен на согласование с пользователем: решено добавить CTA-карточку «ССЫЛКА / в шапке профиля» в последние ~2.6с ролика (19.8-22.38) без голосовой синхронизации — единственное отклонение от обычного правила «голос + карточка вместе» (§1.7) в этой партии, зафиксированное здесь явно. Icon-окно на "тренажёр" в video3 всего одно (14.716-17.716, только на "в ЕГЭ тренажёре"), а не два, как в video1/video2 — второго голосового упоминания «тренажёр» в CTA нет, это корректное поведение при отсутствующем озвученном CTA, не брак.

## ASR-правки

- video1: искажённый токен «г» → «ЕГЭ» («задание ЕГЭ помогает решить быстро»); слипшийся кластер «игр»+«тренажорик»+«заданием» (13.82-15.04, 3 токена на 1.22с) разобран на 5 слов по пропорциональному таймингу длины: «в», «ЕГЭ», «тренажёре», «к», «заданиям»; «понятно» → «понятный» (согласование с «чертёж», м.р.); «шапки» → «шапке»; «профиль» → «профиля» (падежная форма). Слово «хуже» во втором сравнении («получалось гораздо [...]») ASR не зафиксировал — не восстановлено намеренно, чтобы не придумывать не подтверждённое слово; бегущая подпись просто заканчивает фразу на «гораздо».
- video2: «тон» → «но» (искажённый союз, «файла не подсказало мне, но давно устарел»); слипшийся токен «его»(14.308-14.608) разобран на «в»+«ЕГЭ»; «фипи» → «ФИПИ» (регистр); «сука» → «ссылка» (грубое искажение распознавания, timing и контекст соответствуют стандартной CTA-фразе); «шапки» → «шапке»; клэмп переполнения времени последнего слова (21.984→21.955).
- video3: «перескате» → «пересказе» (искажение); добавлено слово «формулировок» (21.884-22.248) — подтверждено повторным распознаванием с усилением звука (см. раздел выше), завершает фразу «тренируют узнавание именно тестовых формулировок» грамматически и по смыслу.

`build_words.py` и `asr_batch.py` унаследованы из `v.никита2609` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео: хук закрывается ровно на старте первой карточки (2.90с во всех трёх), карточки не превышают 4с (максимум 3.348с у video2), иконка «ЕГЭ Тренажёр» появляется на голосовые упоминания (260-300px, 100% непрозрачность, справа на уровне головы) — в video3 один раз (см. раздел про отсутствующий CTA), в video1/video2 дважды как обычно. Бегущая подпись непрерывна и не смещается со слота. CTA «ССЫЛКА в шапке профиля» корректен в video1/video2 (с ASR-правками), в video3 — карточка добавлена без голоса по согласованию с пользователем (см. выше). Два ложных срабатывания на стоп-кадрах (иконка в video1 при t=20.3, ~56мс в окно фейд-ина) перепроверены кадром из середины показа — опасения не подтвердились. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике во всех трёх — карточки не уезжают за края кадра. Тёплый акцент отрендерился корректно, кегли карточки читаются раздельно (унаследованы уже исправленные значения с 09.09.2026).
