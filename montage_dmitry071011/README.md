Пиксельный замер по участку нейтральной стены (два кадра, видео1 и видео2): R/B=1.578 и R/B=1.569 — продолжает исторический тренд роста для этой комнаты (`v.дмитрий240912`: 1.295-1.302 → `vdmitry2509`: 1.510-1.517 → `dmitry061011`: 1.547-1.562 → теперь 1.569-1.578). Как и в прошлых батчах этой комнаты, классифицировано холодным не по формальному порогу R/B, а по визуальной и предметной преемственности (тот же свет, тот же реквизит, нет амбер-подсветки на глаз). `pipeline.py` унаследован от `dmitry061011` без переключения (`ACCENT = "&H00FFF5C9&"`, #C9F5FF).

## ASR-правки

- **video1:** «егэ» → «ЕГЭ» caps (дважды); «пи»+«пи» слипшиеся токены → объединены в «ФИПИ». CTA уже содержала верное «в шапке профиля» без правок.
- **video2:** «егэ» → «ЕГЭ» caps; «в его тренажёре» → «в ЕГЭ тренажёре» (распознавание спутало продуктовое название с местоимением — исправлено только это конкретное вхождение; более раннее законное «откладывает его до последнего», где «его» верно означает «разбор», не тронуто). CTA: вставлено пропущенное «в» перед «шапке». Тайминг последнего слова («профиля») слегка превышал реальную длительность файла (20.640 vs 20.631с) — clamp до 20.631.
- **video3:** «егэ» → «ЕГЭ» caps (дважды); «думал» → «думала» (грамматика — подлежащее «дочь», подтверждено передекодом сегмента 11.0-11.9с: «чем думала»). CTA уже содержала верное «в шапке профиля» без правок.

Все вставки/правки подтверждены прямым передекодом сегмента перед применением. `build_words.py` и `asr_batch.py` унаследованы из `dmitry061011` без правок кода.
