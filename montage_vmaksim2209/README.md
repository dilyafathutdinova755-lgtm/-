## Проверка на дубли (протокол §8)

Герой и комната — узнаваемая «семья Максим» (постеры групп на стене, светлый шкаф-купе, стеллаж с винтажной камерой и книгами) — та же комната, что в `maksim1709`, `maksim1809`, `maksimka1909`, `maks2`, `maksim16`, `maksim2`, `maksimka1`. Визуальное совпадение с историческим кластером запустило усиленную проверку:

- sha256 всех трёх новых файлов сверен со всеми 53 историческими hash-значениями, зафиксированными в README прошлых партий (по всей ветке) — совпадений нет.
- Длительности (21.64 / 25.815 / 23.66с) не совпадают ни с одной из длительностей `maksim1709` (26.52/37.16/33.67с) и `maksimka1909` (32.92/35.01/33.73с) — по протоколу совпадение длительности не выявлено, но проверка транскриптом всё равно проведена вручную из-за совпадения комнаты.
- Полный ASR-транскрипт сравнён с прошлыми сюжетами этой комнаты — новых три сюжета, ни один не повторяет прежние (подсветка слабого предмета цветом, доступ без привязки к сроку, соревнование по количеству заданий, спортсмен и балл +9, деньги друга на курс, троечники и три дня).

**Отдельное наблюдение (не дубль, но важно зафиксировать):** все три сюжета этой партии по теме совпадают один в один с партией `v.влад2209`, смонтированной в этой же сессии несколькими часами ранее — текстовый разбор ошибок (video1 здесь = video2 там), банк ФИПИ (video2 здесь = video3 там), игры на запоминание (video3 здесь = video1 там). Это **разные сценарии, начитанные разными людьми** — полный ASR-транскрипт отличается словесно при совпадении рекламного посыла (разные формулировки, разная структура фраз, разные хронометражи). Похоже на A/B-тестирование одного и того же набора офферов разными лицами — обычная практика в перформанс-рекламе, не случайная повторная заливка. Дубликат по протоколу §8 не подтверждён (разный текст = разные ролики), но хук и карточки написаны заново под конкретный транскрипт этой партии, а не скопированы с `v.влад2209`.
