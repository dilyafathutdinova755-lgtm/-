# Монтаж «Сергей» — 3 ролика (тег `сергей1`, вторая партия этого героя)

Исходники: релиз с тегом `сергей1`. Файлы датированы `12.09`
(`Untitled.Video.12.09.{1,2,3}_2160p.mp4`, у первого файла на GitHub
суффикс `.1` в имени — сам ассет не задваивался, не влияет на монтаж).

**Важно про теги этого героя.** Это уже третий отдельный релиз одного
и того же героя (отец, тёплая комната с торшером и креслом) под
похожими, но разными тегами:
- `сергей` — самая первая партия, обработана ДРУГИМ (Remotion) пайплайном,
  коммиты `31b0bee`/`7683ac8`/`c6fbf68` на `main`, не в этой ветке.
- `сергейй1` (двойное «й») — вторая партия, эта ветка, результаты в
  `../sergey1/`, см. `montage_sergey1/README.md`.
- `сергей1` (одно «й», плюс «1») — **эта партия**, третья по счёту.

Проверено протоколом §8 перед монтажом: другие хэши файлов (sha256 не
совпадает ни с одним файлом партии `сергейй1`), другие длительности
(29.32/31.40/29.82с против 29.83/21.7.../... у предыдущей), другой
полный ASR-транскрипт — три новых сюжета, ни один не повторяет три
истории из `сергейй1` (о комментарии про бесплатные варианты, о вопросе
сыну и о ежемесячном чек-листе отца). Это не дубль, а новая съёмка того
же героя.

Тёплый сет (§1.2): акцент `#FCF5AA`, оранжевый не использован.

## Сюжеты (родительская перспектива)

1. **На даче без интернета?** Родители знают, что летом на даче у
   ребёнка почти нет доступа к заданиям ЕГЭ из-за плохой сети. ЕГЭ
   Тренажёр работает без интернета: банк ФИПИ загружается один раз
   дома, а задания и разбор потом открываются на даче в любой момент
   с той же скоростью — вне зависимости от сети. Дачный сезон больше
   не превращается в потерянные недели без единого задания.
2. **Гора учебников перед сном?** Родители видят гору учебников на
   столе у ребёнка вместо короткого повторения по ЕГЭ за пару минут.
   ЕГЭ Тренажёр заменяет горы учебников короткими карточками по
   предметам — главное помещается на один экран, карточку можно
   просмотреть повторно на следующий день, если тема не запомнилась.
   Гора учебников уступает место телефону на пять минут.
3. **Спрашиваешь про ЕГЭ — слышишь «нормально»?** Родители получают в
   ответ только одно слово без подробностей. В Тренажёре есть раздел
   со статистикой по каждой теме: сколько решено, сколько ошибок, где
   именно они повторяются чаще всего — динамика по неделям, а не
   только текущее состояние. Раздел со статистикой отвечает подробнее
   одного слова «нормально».

## Исправленные артефакты ASR (до рендера)

1. **Видео 1:** «заданиям егэ**я**» → «заданиям егэ» (спутанное
   окончание) и «банк **пипи**» → «банк **ФИПИ**» (акустическая
   путаница — ФИПИ произносится сжато, распознано как бессмысленное
   «пипи»; см. CLAUDE.md §5.7, официальное название «Открытый банк
   заданий ФИПИ»).
2. **Видео 3:** CTA «**сука** на егэ тренажёр» → «**ссылка** на егэ
   тренажёр» — тот же паттерн акустической путаницы, что уже
   встречался в партии `дима1`: слово «ссылка» на быстрой речи ASR
   расслышал как обсценную лексику. Без правки на экране в последней
   карточке отображалось бы нецензурное слово вместо CTA.

Все правки — только в JSON с таймкодами речи для отображения на
экране, звук ролика не трогали.

Результаты — `../sergey1_2/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя, тёплый сет) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_s{1,2,3}.ass` | готовые субтитры |
| `gen_render.py`, `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `loudnorm.py` | двухпроходный EBU R128 + финальная проверка TP на AAC |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды (с ручными правками, см. выше) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1):

| видео | I (LUFS) | TP на готовом AAC (dBTP) |
|---|---|---|
| 1 | −14.25 | −1.79 |
| 2 | −14.13 | −1.78 |
| 3 | −14.08 | −1.48 |

Все три легли точно на целевые −14 LUFS с комфортным запасом от
потолка −1.0 dBTP.

QA-чеклист §4.6 пройден полностью на всех трёх стоп-кадрами: хук
закрывается до первой карточки, тёплый акцент читается раздельно от
белого, карточки не висят дольше 4с, иконка полноразмерная и
непрозрачная и выходит на оба упоминания «тренажёр»/«тренажёре» в
каждом ролике, бегущая подпись идёт непрерывно одним словом в
фиксированном слоте, эмфасис-зум не выталкивает карточку за края
кадра на пике, CTA единый «ссылка в шапке профиля» (после правки
ASR в видео 3 — без обсценной лексики на экране).
