# Монтаж «Влад» — 3 ролика (тег `владик1`)

Исходники: релиз с тегом `владик1`. Файлы датированы `12.09`, тот же
формат имён, что и у партии `ник1` (`Untitled.Video.12.09.{1,2,3}_2160p.mp4`).
Герой — молодой человек, тёмные волосы, чёрная рубашка/футболка,
съёмка у окна днём, нейтральный серо-белый интерьер (дверь, стена,
стул). Холодный сет (§1.2): акцент `#C9F5FF`.

## Проверка на дубли (протокол §8)

Видео 2 и видео 3 совпали по длительности (32.22с у обоих) — формальный
повод заподозрить дубль. Разрешено полным ASR-транскриптом: это два
совершенно разных сюжета (см. ниже), совпадение длительности —
случайность, не признак повторной записи одного и того же текста.

## Сюжеты

1. **Ошибка в терминах.** Выпускники месяцами повторяют одну и ту же
   ошибку в терминах, не замечая закономерность. В ЕГЭ Тренажёре это
   отдельная игра с карточками с интервальным повторением — путаница
   не уходит, пока не отработана многократно, что быстрее, чем читать
   правила заново.
2. **Готовишься в одиночку?** Весь учебный год без соперника рядом. В
   ЕГЭ Тренажёре подготовка становится игрой: рейтинг обновляется за
   задания и миссии, список друзей — в реальном времени, место видно
   сразу. Соревнование с друзьями заменяет рутину.
3. **Закрываешь вкладку и забываешь ошибку?** Неверный ответ — сразу
   к следующему заданию, без разбора причины. В ЕГЭ Тренажёре задание
   попадает в раздел ошибок и не даёт исчезнуть бесследно: можно
   открыть в любой момент, а не только сразу, иначе причина теряется
   навсегда.

ASR всех трёх роликов вышел чистым — без узнаваемых артефактов вроде
обрезанной приставки или развалившегося слова (как было в партии
`ник1`), ручной правки `words{N}.json` не потребовалось.

## Особенность окружения этой сессии

При старте партии в контейнере не оказалось `ffmpeg` (переустановлен
через `apt-get install -y --no-install-recommends ffmpeg`, ~92MB
пакетов). Плюс параллельный запуск всех трёх тяжёлых 4K-рендеров
(`render{1,2,3}.sh`) одновременно упёрся в память — рендер видео 2
был убит (`Killed`, файл повреждён, `moov atom not found`), пришлось
перезапустить его отдельно после завершения первых двух. Не
методологическая правка для CLAUDE.md — разовая особенность
инфраструктуры этой сессии, не сюжета/стиля ролика.

Результаты — `../vladik1/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_vl{1,2,3}.ass` | готовые субтитры |
| `gen_render.py`, `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `loudnorm.py` | двухпроходный EBU R128 + финальная проверка TP на AAC |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды (без ручных правок) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1). Все три
видео упёрлись в TP-потолок (LRA источников узкий, 2.3-3.6) и легли
чуть выше цели −14 LUFS — ожидаемая характеристика этой конкретной
записи (см. §4.5.1), не брак:

| видео | I (LUFS) | TP на готовом AAC (dBTP) |
|---|---|---|
| 1 | −14.77 | −1.58 |
| 2 | −14.48 | −1.43 |
| 3 | −14.84 | −1.61 |

Все три — с запасом от потолка −1.0 dBTP.

QA-чеклист §4.6 пройден полностью на всех трёх: хук закрывается до
первой карточки, карточки не висят дольше 4с, иконка полноразмерная и
непрозрачная и выходит на оба упоминания «тренажёр» в каждом ролике,
бегущая подпись идёт непрерывно одним словом в фиксированном слоте,
эмфасис-зум не выталкивает карточку за края кадра на пике (проверено
стоп-кадром), CTA единый «ссылка в шапке профиля».
