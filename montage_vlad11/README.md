## Сюжеты

1. **Отмечаешь карточку выученной, не проверив себя?** Выпускники
   отмечают карточку с термином как выученную, толком не проверив
   себя — термин потом забывается, и ощущение готовности оказывается
   обманчивым на самом экзамене. ЕГЭ Тренажёр ставит пометку «выучена»
   только после того, как термин верно вспомнили без подсказки —
   вручную без проверки пометку поставить не получится, самообман
   «уже выучил» исключается самим устройством карточки.
2. **Теряешь связь в метро между станциями?** Выпускники теряют связь
   для задания ЕГЭ в метро между станциями, где сигнал пропадает на
   полминуты каждый раз. ЕГЭ Тренажёр не требует новой сети для
   заданий, которые уже открывали хотя бы раз — открыть задание один
   раз на станции хватает на весь перегон без сигнала.
3. **Путаешь союзников и противников в задании по истории?** Выпускники
   путают, кто кому был союзником, а кто противником, в сложном периоде
   истории. ЕГЭ Тренажёр выводит две страны или фигуры рядом и просит
   отметить союзники это или противники одним касанием — ответ
   проверяется сразу же, новая пара берётся из тех сторон, которые
   путались в предыдущий раз.

## Исправленные артефакты ASR (до рендера)

1. **Видео 1:** «самообманс» → «самообман» (спурийная лишняя буква на
   конце слова, тот же паттерн, что и «егэя»/«гэя» в прошлых партиях);
   CTA «шапки профиль» → «шапке профиля» (падеж + пропущенное
   окончание).
2. **Видео 2, 3:** чисто, правок не потребовалось.

Все правки — только в JSON с таймкодами речи для отображения на экране,
звук ролика не трогали.

единый «ссылка в шапке профиля» с корректной грамматикой на экране во
всех трёх.

## Компрессия (§4.7 — эскалация)

Источник необычно детализированный/высокобитрейтный (как и в партии
`владик`): при crf23 все три файла вышли за лимит отправки ~30MB
(36.3/34.7/34.4MB). Эскалировано до crf27 — 20.0/19.0/18.7MB, легибельность
текста и иконки проверена отдельным стоп-кадром на crf27, потерь не
обнаружено.
