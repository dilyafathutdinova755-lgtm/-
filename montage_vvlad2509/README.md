## ASR-правки

- video1: слипшиеся токены «пи»+«пипи» → «ФИПИ» (искажённое распознавание банка заданий); «шапки» → «шапке» (падеж в фиксированной CTA-фразе).
- video2: **содержательная правка** — ASR потерял приставку и дал «фографическое» вместо «орфографическое» (первое слово ролика, начало сегмента речи) — восстановлено по контексту («правило» далее по тексту однозначно указывает на «орфографическое правило»); «шапки» → «шапке»; клэмп переполнения времени последнего слова (18.56→18.52, превышало реальную длительность файла на 0.02с).
- video3: «заметит» → «заметить» — ASR дал форму 3-го лица будущего времени, не согласующуюся по грамматике с конструкцией «можно закрыть... и не заметить» (инфинитив после «можно... и»); «шапки» → «шапке».

`build_words.py` и `asr_batch.py` унаследованы из `v.влад24091` без правок кода.
