## Проверка на дубли (протокол §8)

Герой и комната — presenter «Влад», нейтральная бежево-серая стена без мебели, серый вязаный свитер, поза сидя с рукой на столе — совпадает с историей этого героя (`v.влад2509`, `v.влад24091`, `влад2609`, `влад2909`, `влад3009`).

- sha256 всех трёх новых файлов сверен со всеми историческими hash-значениями по всей ветке — совпадений нет (кроме случайных совпадений длительности, см. выше).
- Ввиду точного совпадения длительности video3 с `влад3009` запущен полный ASR-транскрипт video3 и сверен построчно с видео1 из того батча. Результат: темы разные — «два конфликта с похожими названиями по истории до сих пор иногда путаю между собой, хотя помню детали каждого по отдельности» (video3 этой партии) vs «тренироваться на лёгких заданиях удобно, но реальный вариант устроен не весь из лёгких» (`влад3009` video1) — не пересекаются дословно. Совпадение длительности признано случайным.
- Полный ASR-транскрипт всех трёх новых видео также сверен с `влад3009` целиком: новые сюжеты («анонимный архив заданий без подписи источника, часть которых оказалась снята с реального экзамена» / «ответ записывается раньше хода решения, порядок действий забывается» / «два похожих названия исторических конфликтов путаются») не пересекаются дословно ни с одним из трёх прежних скриптов.

## QA

Полный чеклист §4.6 пройден для всех трёх видео: хук закрывается ровно на старте первой карточки (2.90с во всех трёх), карточки не превышают 4с (максимум 4.0с у video2), иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы). Бегущая подпись непрерывна и не смещается со слота. CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх после ASR-правок. Ложное срабатывание на стоп-кадре video3 CTA (t=20.8, иконка в первые ~120мс 300-350мс-окна фейда выглядела полупрозрачной) перепроверено кадром из середины окна показа (t=21.3) — опасения не подтвердились, иконка полностью непрозрачна и корректно позиционирована. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Холодный акцент отрендерился корректно, дефектов не найдено.
