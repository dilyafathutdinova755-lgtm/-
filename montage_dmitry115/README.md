# Партия «дмитрий115»

4-й тег для семьи презентера Дима/Дмитрий (после `дима1`, `димааа`, `дмитрий11`). Комната — шкаф с рамками, рамка с горным пейзажем, растение, тёплая настольная лампа — визуально совпадает с `димааа` (НЕ с `дима1`/`дмитрий11`, у той — доска с цифрами и другой шкаф).

## Проверка на дубликат (протокол §8, усиленный режим)

Из-за визуального совпадения с `димааа`:

1. **sha256** всех трёх новых файлов сверен со всеми 12 историческими файлами семьи (`дима1`, `димааа`, `дмитрий11`) — совпадений нет.
2. **Полный ASR-транскрипт** сверен с тремя сюжетами `димааа` (сравнение с двоюродным братом, звонок бабушке за термином, похожие юридические термины) — новые три сюжета (проверенный в приложении разбор vs случайный блогер, автосверка ответа с ФИПИ vs поиск третьего источника, автовыбор задания дня по слабым местам vs хаотичный перескок между предметами) не пересекаются ни с одним прежним.

Дополнительно проверено: видео 2 и видео 3 этой партии совпадают по длительности (32.45с) и по размеру извлечённого аудио — на первый взгляд похоже на дубль-дубль. Полный ASR-транскрипт обоих (разные sha256 аудиодорожек, разный текст: видео 2 — про расхождение ответов между приложениями, видео 3 — про хаотичный выбор предмета) подтвердил, что это два разных сюжета, совпадение длительности случайно.

Вывод: новая съёмка в комнате `димааа`, не повторная заливка.

## Сюжеты (все три — разные)

1. **Видео 1** — ребёнок смотрит видеоразбор задания у случайного блогера с сомнительными объяснениями и рекламой курсов; тренажёр прикладывает к заданию разбор, проверенный внутри самого приложения, соответствующий именно требуемому решению.
2. **Видео 2** — разные приложения дают разные ответы на одно и то же задание; тренажёр закрывает доступ к ответу, пока формулировка не сверена с ФИПИ автоматически при обновлении, поэтому третий источник для проверки не нужен.
3. **Видео 3** — ребёнок хватается то за один предмет, то за другой без системы; тренажёр сам выбирает одно задание дня из слабых мест по всем предметам сразу, система складывается сама, без внешнего распределения по дням недели.

## Правки ASR

- **Видео 1**: вставлено пропущенное «без» перед повторным «случайного блогера со стороны» в хвосте («разбор соответствует заданию напрямую, **без** случайного блогера со стороны» — без предлога фраза не имела смысла).
- **Видео 2**: искажённый токен «спи» разбит на «с»+«ФИПИ» («формулировка не сверена **с ФИПИ** автоматически при обновлении приложения»).
- **Видео 3**: «и» → «из» (мисхиринг предлога: «одно задание дня **из** слабых мест по всем предметам сразу»).

Заново применён фикс `build_words.py` (последнее слово сегмента больше не вылетает за пределы длительности видео) — унаследован баг из копии `дмитрий11`, сделанной до исправления.
