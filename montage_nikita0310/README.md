## ASR-правки

Этот батч оказался заметно грязнее обычного — множественные искажения на границах VAD-сегментов.

- **video1:** «номероздании» → «номера заданий» (8.14-8.88, подтверждено повторным распознаванием — «я выучу номера заданий именно по системе центра»); «пробники» → «пробнике» (согласование с «на настоящем»); «ега» → «ЕГЭ»; «нумерации» → «нумерацией» (грамматика, согласование с «официальной», подтверждено); «эмираций» → «нумерации» (смысловая правка — бессмысленное слово заменено на соответствующее контексту «без собственных систем нумерации сбоку», подтверждено повторным распознаванием). **Отдельная находка — тяжело искажённый CTA-хвост.** Сегмент 22.7-24.96с несколько раз подряд распознавался как явная бессмыслица («в этом буфт в шапте профит» / «в этом буфт в шапте профиль» — стабильно воспроизводилось в разных окнах). Поскольку стандартная, неизменная по всей серии фраза «ссылка на тренажёр в шапке профиля» не имеет разумных альтернатив, а фрагмент содержит реальную речевую энергию (не тишина/шум — проверено по RMS), текст реконструирован по этому паттерну: «ссылкан» разделено на «ссылка»+«на», искажённый хвост сведён к «в шапке профиля». Клэмп не потребовался (24.94 = DURATION).
- **video2:** «напробуйте» → «на»+«пробнике» (известный повторяющийся паттерн для этого героя — подтверждено узким повторным распознаванием «на пробники»); «ега» → «ЕГЭ»; «тренажорик» → «тренажёре»+«к» (слипшиеся токены); «заданием» → «заданиям» (грамматика, подтверждено повторным распознаванием — «тренажёре к заданиям есть»); «шапки» → «шапке»; «профит» → «профиля». Переполнения нет (21.7 < 21.72).
- **video3:** «егэ» (продуктовое упоминание, 25.292с) → «ЕГЭ» для единообразия с остальными батчами (генерическое «для егэ» в начале ролика оставлено строчными). Короткий аналог CTA-искажения: токен «и» на границе сегмента (36.668-36.768) заменён на «в»+«шапке» по итогам повторного распознавания широким окном (35.9-37.4с → чисто «в шапке профиля»). Переполнения нет (37.26 < 37.271).

`build_words.py` и `asr_batch.py` унаследованы из `никита0210` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео (проверка стоп-кадрами: хук, карточка+бегущая подпись, иконка, CTA, пик эмфасис-зума). Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо). Бегущая подпись непрерывна, в одном слоте, по одному слову — реконструированный CTA-хвост video1 и video3 проверен отдельно стоп-кадром, отображается корректно («ССЫЛКА в шапке профиля», верная грамматика). Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае, включая длинные акцентные слова («ВЫЧИСЛЕНИЯМ»). Дефектов не найдено.
