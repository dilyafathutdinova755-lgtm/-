**Важное наблюдение — две фразы обрываются на середине.** В video2 фраза «...который показывает единственно верную [...]» (аудио заканчивается на слове «верную», 17.212-17.712с, дальше 0.8с паузы до следующей реплики) и в video3 фраза «...настоящая проверка обычно наступает только через несколько [...]» (аудио заканчивается на «несколько», 10.356-10.656с, дальше более секунды паузы до следующего сегмента ASR) — обе явно грамматически незавершены (не хватает существительного после «верную» и «несколько»). Судя по характеру пауз (полноценная тишина, а не оборванный звук на полуслове), это похоже на реальный обрыв в самой записи (presenter не договорил или сделал монтажную склейку в исходнике), а не на потерю слов распознаванием. Слово додумывать не стали — карточки для этих моментов построены только на словах, подтверждённых аудио («ПОКАЗЫВАЕТ / ЕДИНСТВЕННО ВЕРНУЮ» и «НАСТОЯЩАЯ ПРОВЕРКА / ЧЕРЕЗ НЕСКОЛЬКО»), без попытки закончить фразу текстом на экране.
