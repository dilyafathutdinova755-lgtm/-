## ⚠ Особый случай — повтор дубля внутри video3

Транскрипт исходного video3 (29.655с) содержал явный повтор одной и той же реплики подряд:

- Первая версия (0.12-9.42с): «Другу я объясняю термин по обществознанию для ЕГЭ простыми словами без запинки. А в тесте официальная формулировка сбивает с толку.»
- Вторая версия (10.08-17.80с): «Я объяснял термин одноклассникам просто и понятно. А в тесте официальная формулировка звучала почти незнакомо.»

Это классический повтор дубля по протоколу §2.3 (одна и та же мысль проговорена дважды подряд), а не два разных примера: содержание идентично, различается только формулировка. Первая версия в настоящем времени («объясняю... другу») не соответствует грамматическому паттерну личной истории, который использует эта кампания во всех сценариях («я решал», «я перепутал», «я объяснял» — прошедшее время); вторая версия («я объяснял... одноклассникам») ему соответствует.

По умолчанию §2.3 предписывает оставлять последний дубль — он здесь и грамматически более чистый. Между двумя версиями найдена чистая пауза в звуке (9.385-10.085с, silencedetect подтвердил тишину 0.7с) — по ней вырезан первый повтор (обрезка на 9.7с), после чего проведён ASR и вся дальнейшая работа заново на укороченном файле. Итоговая длительность video3 — 19.975с, что укладывается в обычный диапазон партии наравне с video1/video2.

Герой и комната — presenter «Максим», светлая комната, шкаф-купе со светлым деревом, постеры групп (Bastille и др.) на стене слева, полка с фотоаппаратом и книгами, серый свитер с петличным микрофоном — совпадает с историей этого героя (`vmaksim2209`, `v.максим24091`, `v.максим2509`, `v.максим2609`, `максим2909`).

- sha256 всех трёх новых файлов (video3 — по исходнику до монтажной правки) сверен со всеми историческими hash-значениями по всей ветке — совпадений нет (кроме случайного совпадения длительности video2 с другим героем, см. выше).
- Полный ASR-транскрипт сверен с `максим2909` (последний батч этого героя): новые три сюжета (порядок заданий в варианте ЕГЭ меняется год к году, из-за чего можно растеряться и пропустить задание / решение по интуиции редко сопровождается умением сформулировать правило / простое объяснение термина другу vs официальная формулировка на экзамене) не пересекаются дословно ни с одним прежним скриптом этого героя.

**Отдельное наблюдение (не дубль).** Темы этой партии — банк ФИПИ (video1), текстовый разбор ошибок (video2), игры на запоминание (video3) — тот же набор базовых офферов кампании, систематически повторяющийся у этого героя и у других героев во всех прошлых батчах.
