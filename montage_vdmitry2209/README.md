## Проверка на дубли (протокол §8)

Герой и комната совпадают с историческим кластером «Дмитрий» — шкаф с рамками, рамка с горным пейзажем, комнатное растение, тёплая настольная лампа, деревянный стол с блокнотом (та же комната, что в `dmitry115` и `dmitry1909`). Запущена усиленная проверка:

- sha256 всех трёх новых файлов сверен со всеми 59 историческими hash-значениями по всей ветке — совпадений нет.
- Длительности (25.324 / 21.975 / 19.080с) не совпадают ни с одной исторической записью дмитрий-семьи.
- Полный ASR-транскрипт сверен с сюжетами `dmitry1909` (короткое верно/неверно вместо развёрнутого задания, время последнего показа карточки, уведомление за 5 минут до конца пробника) и `dmitry1809`/`dmitry11`/`dmitry115` — новые три сюжета не пересекаются ни с одним прежним.

**Отдельное наблюдение (не дубль):** темы этой партии — игры на запоминание, банк ФИПИ, текстовый разбор ошибок — совпадают с уже смонтированными в этой сессии `v.влад2209`, `v.максим2209` и `v.сергей2209` (тот же набор из трёх базовых офферов кампании). Здесь снова родительский ракурс («ребёнку», «ребёнок»), как в `v.сергей2209`, но другой сценарий, другая формулировка, другой транскрипт — не дубль, похоже на системный A/B/C/D-тест одного набора офферов через несколько персон кампании (ученик-Влад, ученик-Максим, родитель-Сергей, родитель-Дмитрий).

## ASR-правки

- video1: «они» → «чем» (бессвязное местоимение вместо сравнительного союза в конструкции «закрепляется быстрее... чем просто заново прочитать»).
- video2: слипшиеся токены «пи»+«пипи» → одно слово «ФИПИ»; «шапки» → «шапке» (повторяющаяся ошибка падежа CTA).
- video3: «тренажёра» → «тренажёр» (неверный падеж — винительный вместо родительного после «ссылка на»).
- Клэмп переполнения времени последнего слова под фактическую длительность: video1 (25.344→25.31), video2 (21.984→21.96). video3 переполнения не имел.

`build_words.py` и `asr_batch.py` унаследованы из `dmitry1909` без правок кода.
