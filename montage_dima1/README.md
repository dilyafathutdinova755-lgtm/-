# Монтаж «Дима» — 3 ролика (тег `дима1`)

Исходники: релиз с тегом `дима1`, файлы датированы `11.09`. Новый герой
(другая комната — офис с доской, финансовыми цифрами Q1-Q4 и монитором
с Excel-графиками; тёмно-синее поло Tommy Hilfiger) — не тот же
человек, что в `дмитрий1` (там домашний кабинет с книжным шкафом и
торшером). Нейтральный дневной свет — холодный сет (§1.2), акцент
`#C9F5FF`.

## Формат ролика — отличается от предыдущих партий

Впервые в этой ветке — не личная история от первого лица, а обзор
конкретных фич приложения от третьего лица, обращённый к родителям:
все три ролика начинаются с «родители одиннадцатиклассников
видят/замечают, что...». Сюжеты:
1. Подготовка в одиночку буксует без стимула → друзья, общий рейтинг,
   ежедневные миссии превращают рутину в игру с видимым результатом.
2. Много материала по нескольким предметам сразу → карточки по
   предметам, короткие частые повторения вместо сплошного перечитывания.
3. Ежедневная подготовка держится только на самодисциплине → конкретные
   ежедневные миссии и позиция в рейтинге среди друзей вместо стихийных
   редких занятий.

Проверено протоколом §8: разные транскрипты и длительности, ни один не
дублирует другие партии.

## Найден и исправлен баг распознавания речи

В видео 3 ASR (`sherpa-onnx`) на слове CTA «ссылка на егэ тренажёр в
шапке профиля» (та же фраза, что говорится во всех роликах серии)
ошибочно распознал первое слово как ненормативную лексику вместо
«ссылка» — чисто акустическая путаница, не то, что реально сказано.
Исправлено вручную в `words3.json` **до** генерации субтитров и рендера
— на экране в готовом видео отображается корректное «ССЫЛКА», ошибка
нигде не попала в кадр. Итоговые файлы проверены визуально по стоп-кадру
на этом месте.

Результаты — `../dima1/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя) + сегментный эмфасис-зум + окна иконки |
| `data{1,2,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому ролику |
| `subs_dm{1,2,3}.ass` | готовые субтитры |
| `render{1,2,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `asr{1,2,3}.json`, `words{1,2,3}.json` | распознавание речи и таймкоды (words3.json — с ручной правкой) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1): все три
ролика легли в −1.9 dBTP на готовом AAC-файле, интегральная громкость
−14.1…−14.5 LUFS — с первой попытки.
