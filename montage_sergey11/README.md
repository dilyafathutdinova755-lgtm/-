# Монтаж «Сергей» — 2 ролика из 3 (тег `сергей11`, новая партия, новая комната)

Исходники: релиз с тегом `сергей11`. Файлы датированы `16.09`
(`Untitled.Video.16.09.{1,2,3}_2160p.mp4`). Тот же presenter, что и в
прошлых четырёх партиях «Сергея» (`сергей`, `сергейй1`, `сергей1`,
`сергей1й`), но **совершенно новая комната** — кирпичная стена, книжный
шкаф, светильник с абажуром, кремовая льняная рубашка вместо голубой
хлопковой (прежняя комната была со светлой панельной стеной, деревянным
торшером и зелёным креслом). Проверено протоколом §8: sha256 всех трёх
новых файлов не совпадает ни с одним файлом всех четырёх прошлых партий.

**Тёплый сет** — определён замером пикселей стены: R/B≈2.58-2.59 во
всех трёх кадрах (кирпич сам по себе тёплого тона + тёплый светильник
на полке) — заметно теплее всех прежних тёплых эталонов. Акцент
`#FCF5AA`, оранжевый не использован.

## Дубль сценария внутри партии (важно)

Видео 2 и видео 3 внутри этой партии — **два дубля одного и того же
сценария** («родители боятся, что поездка на рыбалку без интернета
обернётся пропущенным днём подготовки к ЕГЭ»), текст совпадает почти
дословно. По уже установленной в партии `максим2` политике (взять
только один дубль, по умолчанию последний, §2.3) — смонтирован только
**видео 3**, видео 2 исключено. Видео 1 — отдельный, самостоятельный
сюжет. `asr2.json` оставлен в архиве для прозрачности сверки, но
`words2.json`, субтитры и рендер для него не делались.

Итог: смонтированы и сданы **2 ролика вместо 3** — `sergey11_1` и
`sergey11_3` (нумерация сохранена по исходным файлам).

## Сюжеты

1. **(видео 1) Зубришь термин дословно, не понимая смысла?** Родители
   видят, что ребёнок зубрит формулировку термина по ЕГЭ дословно из
   учебника, не понимая смысла — такая зубрёжка забывается сразу после
   экзамена. ЕГЭ Тренажёр позволяет подписать карточку своими словами
   вместо дословной цитаты — термин запоминается через смысл, а не
   зазубренную фразу, и вернуться к своей версии формулировки можно в
   любой момент.
2. **(видео 3) Боишься пропустить день ЕГЭ из-за поездки без
   интернета?** Родители боятся, что поездка на рыбалку без интернета
   обернётся пропущенным днём подготовки. ЕГЭ Тренажёр сохраняет ранее
   открытое задание прямо на телефоне, будто обычную фотографию в
   галерее — достать его на берегу можно без единого обращения к
   оператору связи, и день без интернета больше не превращается в
   пропущенный день ЕГЭ.

## Исправленные артефакты ASR (до рендера)

1. **Видео 1:** финальная фраза «они дословный зубрёшь» — сильно
   искажённый ASR-хвост, восстановлен по параллели с более ранней
   фразой того же ролика («а не через зазубренную фразу») в «а не
   дословную зубрёжку»; CTA «шапке профиль» → «шапке профиля»
   (пропущенное окончание).
2. **Видео 3:** «раннее открытое задание» → «ранее открытое задание»
   (перепутана словоформа — нужно наречие «ранее», не прилагательное
   «раннее»).

Все правки — только в JSON с таймкодами речи для отображения на экране,
звук ролика не трогали.

Результаты — `../sergey11/*_smontirovano.mp4`, 1080×1920, 25fps.

## Файлы
| файл | что это |
|---|---|
| `pipeline.py` | генератор ASS (3 слоя, тёплый сет) + сегментный эмфасис-зум + окна иконки |
| `data{1,3}.py` | HOOK/CARDS/EMPHASIS/DURATION по каждому смонтированному ролику |
| `subs_s11_{1,3}.ass` | готовые субтитры |
| `gen_render.py`, `render{1,3}.sh` | сборка финального рендера (crop-zoom сегменты + ass + иконка) |
| `loudnorm.py` | двухпроходный EBU R128 + финальная проверка TP на AAC |
| `asr{1,2,3}.json` | распознавание речи всех трёх исходников (asr2 — только для сверки дубля) |
| `words{1,3}.json` | таймкоды слов смонтированных роликов (с ручными правками, см. выше) |

Звук — двухпроходный EBU R128 с запасом TP `-2.0` (§4.5.1):

| видео | I (LUFS) | TP на готовом AAC (dBTP) |
|---|---|---|
| 1 | −13.98 | −1.85 |
| 3 | −14.20 | −1.75 |

Оба легли точно на целевые −14 LUFS с комфортным запасом от потолка
−1.0 dBTP.

QA-чеклист §4.6 пройден полностью на обоих стоп-кадрами: хук закрывается
до первой карточки, тёплый акцент читается раздельно от белого, карточки
не висят дольше 4с, иконка полноразмерная и непрозрачная и выходит на оба
упоминания «тренажёр» в каждом ролике, бегущая подпись идёт непрерывно
одним словом в фиксированном слоте, CTA единый «ссылка в шапке профиля» с
корректной грамматикой на экране в обоих.

Компрессия — crf23 хватило без эскалации (11.2/10.3MB).
