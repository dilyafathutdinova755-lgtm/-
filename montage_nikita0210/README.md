## Проверка на дубли (протокол §8)

Герой и комната — presenter «Никита», худи NEVORA, тёмный стеллаж с книгами, бежевая стена — совпадает с историей этого героя (`никита0110`, `никита3009`, `никита2909` и более ранние `v.никита*`).

- sha256 всех трёх новых файлов сверен со всеми историческими hash-значениями по всей ветке — совпадений нет.
- Ввиду точного совпадения длительности video1 с `никита0110` video1 запущен полный ASR-транскрипт video1 и сверен построчно с `никита0110` video1: «задание ЕГЭ которое распечатал в копицентре, несколько страниц случайно продублировались, а часть других вообще пропала» (этот батч) vs «фотографии страниц из библиотечного учебника для подготовки к ЕГЭ делал быстро не глядя на год издания, через месяц заметил на обложке год, из-за которого часть заданий уже неактуальны» (`никита0110` video1) — дословных совпадений нет, это разные конкретные проблемы (брак печати в копицентре vs устаревшее издание учебника). Общий только финальный оффер «банк ФИПИ» — стандартный повторяющийся элемент кампании. Совпадение длительности признано случайным.
- Полный ASR-транскрипт video2 и video3 также сверен с соответствующими video2/video3 из `никита0110`: video2 этого батча («упрощённая версия задания из учебника решается без ошибок, а в настоящем варианте экзамена есть дополнительное условие, которое легко пропустить») не пересекается дословно с `никита0110` video2 («считаю столбик в уме на экзамене, не записываю шаг, кажется что ответ возникает из ниоткуда»). video3 этого батча («два слова с разным типом склонения путаю, применяя правила одного к другому, получаю неверную форму») тематически близко к `никита0110` video3 («два похожих по написанию слова-исключения путаю визуально») — оба про пары похожих слов по русскому языку с правкой «игры на запоминание», но механизм ошибки разный (склонение/грамматическая форма vs визуальная спутанность написания). Это тот же тип рутинной тематической переклички, что системно встречается у ВСЕХ героев в видео3 этой кампании (см. ниже) — не является дублем и не требует особого флага.

**Отдельно (не дубль, обычный паттерн).** Проверено видео3 всех героев партии 01.10 (`влад0110`, `максим0110`, `сергей0110`, `дмитрий0110`) — у каждого в видео3 используется один и тот же базовый оффер «игры на запоминание» с разной конкретной парой путаемых вещей (события истории, термины, цитаты и авторы, правила письма, похожие слова). Это системный повторяющийся паттерн кампании, не специфичный для Никиты.

## ASR-правки

- **video1:** искажённое «ега» (14.948-15.128) → «ЕГЭ» (установленная брендовая фраза «в ЕГЭ тренажёре», встречается во всех видео кампании); «фипи» → «ФИПИ» (регистр); сильно искажённый токен «давте» (22.492-22.752) → разбит на «в»+«шапке», подтверждено повторным распознаванием сегмента 21.3-23.2с («ссылка на тренажёр в шапке профиля»). Слово «копицентре»/«копицентра» (в ASR — «капицентре»/«капицентра») дважды независимо подтверждено повторным распознаванием с тем же результатом — оставлено как реально произнесённое название копи-сервиса, не исправлялось. Клэмп переполнения времени последнего слова (23.2→23.15, факт. длительность 23.191с).
- **video2:** в CTA-сегменте отсутствовал токен «в» перед «шапке», а «шапки»/«профиль» были в неверной форме — повторное распознавание сегмента 24.0-24.9с дало чистое «в шапке профиля», добавлен токен «в» и обе формы исправлены. Клэмп переполнения времени не потребовался (24.82 < 24.855).
- **video3:** искажённое «яга» (15.396-15.616) → «ЕГЭ»; «шапки» → «шапке». Токен «длига» (4.996-5.496, между «языку» и «я до сих пор умудряюсь путать») — при трёх независимых попытках повторного распознавания с разными окнами контекста каждый раз получен другой, грамматически бессвязный результат («длига» / «для» / «кудлига»), сходящегося к одному слову не произошло. Поскольку фраза полностью сохраняет смысл и без этого токена («...по русскому языку я до сих пор умудряюсь путать между собой»), и ни один из вариантов распознавания не дал уверенного кандидата, токен удалён из бегущей подписи, а не заменён на угаданное слово. Клэмп переполнения времени последнего слова (25.856→25.79, факт. длительность 25.840с).

`build_words.py` и `asr_batch.py` унаследованы из `никита0110` без правок кода.

## QA

Полный чеклист §4.6 пройден для всех трёх видео. Хук закрывается до старта первой карточки во всех трёх (2.90с). Карточки не превышают 4с. Иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы, не задевает лицо). Бегущая подпись непрерывна, в одном слоте, по одному слову — удаление нераспознанного токена в video3 не создало видимого разрыва или скачка. CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх после ASR-правок. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Ложных срабатываний на фейд-окне иконки не зафиксировано. Дефектов не найдено.
