# montage_sergey2010

Монтаж 3 роликов под тегом `сергей2010` (панельная комната, тёплый сет).

## Источники

| файл | длительность | release asset |
|---|---|---|
| video1.mp4 | 29.320с | `Untitled.Video.2010.1_2160p.mp4` (88 334 269 байт, sha256 `7d79c5ce...` по release API) |
| video2.mp4 | 22.764с | `Untitled.Video.2010.2_2160p.mp4` (69 292 347 байт, sha256 `53000d4c...` по release API) |
| video3.mp4 | 25.175с | `Untitled.Video.2010.3_2160p.mp4` (77 541 205 байт, sha256 `9ab395fc...` по release API) |

Скачаны из релиза `сергей2010`, все три совпадают по размеру с release API.

## Комната и герой

Референс-кадры (`ffmpeg -ss 10 -frames:v 1`) сравнены с историческими батчами. Кадры показывают **панельную комнату**: кремовые панельные стены, торшер на деревянном треноге с льняным абажуром, оливовое кресло, голубая рубашка, взрослый мужчина (отец) — **не** кирпичную комнату `сергей1710`/`сергей1610`/`сергей1510` (другое семейство кадров этого же номинального героя «сергей»). Пайплайн унаследован от **`сергей1410`** (самый свежий батч именно этой, панельной комнаты) — хронологически более свежие `сергей1510`/`1610`/`1710` относятся к другой, кирпичной физической комнате и для этого батча не подходят.

## Проверка на дубли (§8)

Длительности всех трёх видео (29.320с, 22.764с, 25.175с) и полные ASR-транскрипты сверены с исторической базой панельной комнаты — точных совпадений не найдено. Содержание всех трёх тематически и лексически различно (задание 17 по истории / задание 14 по истории / слитное-раздельное написание), слово «ссылка» встречается в транскрипте каждого видео ровно один раз — по одному ролику на файл.

## Палитра

Пипетка по кадру подтверждает тёплый сет этой комнаты (янтарные стены, лампа с тёплым светом) — продолжение исторической классификации панельной комнаты героя «сергей»: accent `#FCF5AA`, без переключения на холодный. `pipeline.py` — та же версия, что в `сергей1410`, с заменой только значения ACCENT/комментария (идентично по формуле).

## ASR-правки

Пайплайн: sherpa-onnx zipformer (ru) + silero VAD → `asr_batch.py` → `build_words.py` → ручная правка через `apply_fixes.py`, каждая неоднозначная правка проверена `redecode_ts.py` перед применением.

- **Все три видео:** `"егэ"` → `"ЕГЭ"` (регистр).
- **video1:** позиционная правка `"ега"` → `"ЕГЭ"` в «в ега тренажёре» (19.852-20.272с) — слитное/смазанное произношение «ЕГЭ», распознанное как отдельное несуществующее слово; тот же паттерн, что `"его"`→`"ЕГЭ"` в `сергей1410/video3`. Легитимное `"егэ"` в начале транскрипта (4.004с) исправлено отдельно, блочная замена не применялась. CTA — широкий передекод 26.6-29.3с подтвердил отдельный токен «в» перед «шапки» (VAD/токенизатор не выделил его отдельным словом, нуждалась в нудже таймкода на 20мс от сырого передекода, чтобы не пересечься с концом «тренажёр» в этом прогоне выравнивания); «шапки» → «шапке».
- **video2:** CTA («ссылка на тренажёр в шапке профиля») распознана полностью и чисто, без фиксов кроме регистра.
- **video3:** CTA — широкий передекод 22.9-25.3с подтвердил отдельный токен «в» перед «шапки», «шапки» → «шапке».

После применения правок — проверка на пересечения временных меток слов: пересечений и отрицательных длительностей не найдено ни в одном видео (после нуджа timestamp в video1 для устранения 16мс overlap, возникшего из-за расхождения двух независимых ASR-проходов).

`build_words.py`, `asr_batch.py`, `pipeline.py` (формула), `make_subs.py`, `redecode_ts.py`, `loudnorm.py` унаследованы из `сергей1410` без правок кода (кроме ACCENT-константы под текущий тег и имени ASS-файла в `gen_render.py`).

## Карточки и тайминги

`data1.py`/`data2.py`/`data3.py` — хук (0-2.6с, акцентный цвет, формулирует боль родителя/ученика по конкретному заданию, не пересказ первой фразы) + 8 карточек на видео (1-3 слова, кегль 85-95/40-48px) + бегущая подпись (из слов, PT Sans Narrow Bold) + 4 эмфасис-зум окна на ролик. Валидация пройдена (`validate.py`): нет пересечений карточек/хука/зума, последняя карточка заканчивается точно на DURATION, хук закрывается строго до первой карточки.

- video1 (история, задание 17): хук «СЫН ЗАВИСАЕТ / НА ЗАДАНИИ 17?», 8 карточек, CTA.
- video2 (история, задание 14): хук «СЫН ПУТАЕТСЯ / В ЗАДАНИИ 14?», 8 карточек, CTA.
- video3 (русский, слитно/раздельно): хук «ПИШЕТ СЛИТНО / ТАМ ГДЕ НЕ НАДО?», 8 карточек, CTA.

Оранжевый акцент (`#FD5D01`, максимум 1 слово на ролик) не использован ни в одном из трёх — все акцентные слова жёлтые, как и в унаследованном прецеденте `сергей1410`.

Иконка приложения (ЕГЭ ТРЕНАЖЁР) появляется на оба голосовых упоминания в каждом ролике (автоматически по паттерну `тренаж` в `words{N}.json`):
- video1: окна (20.292, 23.292) и (27.492, 29.32)
- video2: окна (14.5, 17.5) и (21.244, 22.76)
- video3: окна (16.404, 19.404) и (23.58, 25.16)

## Громкость

Двухпроходный EBU R128 (`loudnorm.py`, TP-цель −2.0 на обоих проходах, §4.5.1) + финальная проверка TP на готовом AAC-файле. Все три прошли на обычном проходе, лимитер-эскалация не понадобилась:

| видео | pass1 измерено | финальный AAC (после кодирования) |
|---|---|---|
| video1 | I=-16.16 TP=-4.08 LRA=4.80 | I=-14.08 LUFS, TP=-2.01 dBTP |
| video2 | I=-16.24 TP=-3.67 LRA=3.00 | I=-14.04 LUFS, TP=-1.81 dBTP |
| video3 | I=-17.87 TP=-4.21 LRA=5.00 | I=-14.42 LUFS, TP=-1.75 dBTP |

## QA

Стоп-кадры на хук/карточка/иконка/зум/CTA извлечены и просмотрены для всех трёх видео (21 кадр). Хук закрывается строго до старта первой обычной карточки; карточки не вылезают за края кадра, текст не на лице/рту, поля соблюдены; иконка приложения полностью непрозрачна, крупная (280px), справа на уровне головы, не перекрывает лицо, появляется на оба упоминания в каждом ролике; CTA «ссылка в шапке профиля» идентичен во всех трёх; акцент только жёлтый (тёплый сет), один сет на ролик. Один кадр (video3, 16.5с) попал в окно fade-in иконки — переизвлечение из середины того же окна (17.5с) подтвердило полную непрозрачность, это сэмплинг-артефакт на границе fade, не дефект рендера (тот же паттерн отмечен в `сергей1410`/`максим1710`). Дефектов не найдено.

## Файлы в этой папке

`pipeline.py` (палитра — accent #FCF5AA вместо #C9F5FF, формула не менялась), `asr_batch.py`, `build_words.py`, `make_subs.py`, `redecode_ts.py`, `loudnorm.py` — унаследованы от `montage_sergey1410/` (панельная комната) без правок кода. `gen_render.py` — правка на один путь (имя ASS-файла `subs_s2010_{i}`). `data1.py`/`data2.py`/`data3.py` — карточки/хук/эмфасис/длительность. `apply_fixes.py` — ASR-правки. `validate.py` — инлайн-проверка таймингов. `asr{1,2,3}.json`/`words{1,2,3}.json` — распознавание речи. `subs_s2010_{1,2,3}.ass` — готовые субтитры. `render{1,2,3}.sh` — сгенерированные ffmpeg-скрипты рендера.

Исходные видео (video1/2/3.mp4) и промежуточные/финальные рендеры НЕ архивируются — только код и транскрипты. Готовые ролики лежат в `work/сергей2010/сергей2010_{1,2,3}.mp4`.
