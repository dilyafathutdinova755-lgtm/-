## Проверка на дубли (протокол §8)

- sha256 всех трёх новых файлов сверен со всеми 110 историческими hash-значениями по всей ветке — совпадений нет (кроме одного случайного совпадения длительности, см. выше).
- Полный ASR-транскрипт сверен с `v.влад2509` (последний батч этого героя): новые три сюжета (интуитивное решение задания ЕГЭ иногда даёт верный ответ без понимания, откуда он взялся — так можно пройти тесты неделю, пока похожее задание с другими числами не поставит в тупик / прошлогодняя демоверсия может выглядеть актуальной, хотя формат уже изменился / слово-исключение можно выучить наизусть и всё равно перепутать на письме) не пересекаются дословно ни с одним прежним скриптом этого героя.

**Отдельное наблюдение (не дубль).** Три темы этой партии — текстовый разбор ошибок (video1), банк ФИПИ (video2), игры на запоминание (video3) — тот же набор из трёх базовых офферов кампании, который систематически повторяется у этого героя во всех прошлых батчах. ## QA

Полный чеклист §4.6 пройден для всех трёх видео: хук закрывается ровно на старте первой карточки (2.90с во всех трёх), карточки не превышают 4с (максимум 3.82с у video1), иконка «ЕГЭ Тренажёр» появляется на оба голосовых упоминания в каждом ролике (260-300px, 100% непрозрачность, справа на уровне головы), бегущая подпись непрерывна и не смещается со слота, CTA «ССЫЛКА в шапке профиля» с верной грамматикой во всех трёх после ASR-правки video3. Ложное срабатывание на стоп-кадре video3 (карточка «ЗНАЛ ПРАВИЛА / ПОЧТИ ИДЕАЛЬНО» в 140ms-окне pop-in выглядела полупрозрачной) перепроверено кадром из середины показа — опасений не подтвердилось, обычная часть анимации входа. Эмфасис-зум (4 фразы на ролик, ×1.14) проверен стоп-кадрами на пике — карточки не уезжают за края кадра ни в одном случае. Холодный акцент отрендерился корректно, дефектов не найдено.
