# START HERE — гайд по продакшену роликов (ЕГЭ-ниша)

Набор правил по продакшену вертикальных «говорящая голова» видео: бренд, монтажный вкус, форматы, звук, анти-паттерны, эталоны. Файлы самодостаточны — работают в любом редакторе (CapCut / Premiere / DaVinci / код) и как контекст для Claude.

**Статус:** заполнено по разбору 6 роликов (ffmpeg: кадры, склейки, палитра по пикселям, громкость). Всё, что можно было измерить, — измерено и записано как правило. Обновлено 26.08.2026 по итогам монтажа `IMG_3709` — см. «Изменения» в конце файла.

## Что за бренд (короткая сводка)

- **Ниша:** подготовка к ЕГЭ, разборы заданий, обзор приложений/сервисов, выбор специальностей.
- **Формат:** вертикаль 9:16, ~45-60с, говорящая голова дома + скриншоты приложений + мем-вставки.
- **Тон:** разговорный энергичный, обращение на «ты», без академизма.
- **Узнаваемое:** двухслойные субтитры (крупная ключевая карточка + непрерывная бегущая подпись), ледяной голубой акцент, мем-стикеры вырезкой, «пул-аут» кадра в белую рамку.

## Для Claude — протокол при загрузке этих файлов

1. Гайд уже заполнен. Интервью по палитре / шрифтам / форматам не проводить — значения выведены из реальных роликов, они в `brand-kit.md` и `delivery-specs.md`.
2. Крафт (уровни звука, тайминги анимаций, safe-зоны, каденция графики) — профессиональные дефолты. Менять только по явной просьбе.
3. Перед монтажом спросить только то, что в блоке «Открытые поля» ниже и ещё не закрыто.
4. При монтаже работать циклом: черновик → прогон по QA-чеклисту (`delivery-specs.md` §6) → правки → повторный прогон. Отдавать только то, что прошло чеклист целиком.
5. Для работы с видео нужна среда с выполнением кода (ffmpeg). В обычном чате mp4/mov не читаются — не притворяться, что «посмотрел».
6. Правки, которые должны повторяться в каждом ролике, вносить в эти файлы и коммитить. Разовые правки под конкретный ролик в гайд не писать.

## Решения (закрыто, менять только осознанно)

- Ник и подписи на экране — не используем. Вотермарки нет.
- CTA всегда один: «ссылка в шапке профиля». Без «пишите в комментарии» и «подпишись».
- «ЕГЭ Тренажёр» — свой продукт. Говорим о нём прямо, дисклеймер о рекламе не нужен.
- Основной акцент — ледяной голубой `#C9F5FF`. Тёплый жёлтый сет — только для вечерних съёмок при янтарном свете.

## Открытые поля (монтаж не блокируют)

- Ассеты: пути к папкам SFX / музыки (пока своих нет — генерируем и берём CC0). Шрифты закрыты, см. `assets-manifest.md` §3.
- Точное имя приложения в сторах — как писать на экране, если понадобится текстом.

## Изменения

**26.08.2026 — по итогам монтажа `IMG_3709`.** Три правки, все отменяют прежние формулировки:

1. **Иконка приложения** больше не «small в углу с прозрачностью». Теперь крупная и полностью непрозрачная — `brand-kit.md` §6.
2. **Бегущая подпись** больше не «плавает по кадру». Теперь один фиксированный слот сверху, крупнее, без обводки, идёт непрерывно весь ролик и не снимается под карточкой — `brand-kit.md` §4.
3. **Межстрочный интервал в карточке** задан явно: 0.90 от кегля — `brand-kit.md` §4.

Соответственно обновлены `anti-patterns.md` §3-§4 и QA-чеклист `delivery-specs.md` §6.
