# Editing Taste — ритм и монтажные решения

Как ролик должен ОЩУЩАТЬСЯ. Работает в любом редакторе. При конфликте с «best practices из интернета» — прав этот файл. Числа выведены из замеров роликов, это не «примерно».

## 1. Каркас нарратива

```
хук → боль/ошибка → метод → доказательство → пример → CTA
```

- Каждый бит = один чистый посыл. Хук решает всё — первые 1-2с.
- Хук = крупная карточка-обещание + первая фраза одновременно. Не «здравствуйте, сегодня».
- Первая треть — самая слабая по динамике. Фронт-лоадь туда визуал: скриншот, стикер, панч-ин, круговой номер пункта. Лицо не должно висеть без смены картинки дольше 3с.

## 2. Ритм и склейки (измерено)

- **Смена картинки в среднем каждые 1.8-2.3с.** Замер: 22-25 визуальных событий (склейка / вход графики / стикер) на 43-58с. Это планка — держать её.
- **Склейка — король:** ~98% переходов — прямой рез (джамп-кат в том же кадре). Фэнси-вайпы / спины / кубы — нет. Диссолв — только на осознанном разрыве сцены, редко.
- **Крупность варьируется между дублями** — лёгкий зум 1.06-1.28× на джамп-катах, чтобы рез не читался как «дыра». Съёмка в 4K даёт запас на кроп до 2× без потери качества.
- **J-cut:** звук следующего дубля заходит на ~0.25с раньше его видео.
- Линия глаз ~40-45% высоты кадра.

## 3. Выбор дублей (критично — фразы переснимаются)

- В исходнике одна фраза проговаривается несколько раз подряд. **Оставляем ровно один дубль.**
- По умолчанию берём последний дубль — он обычно самый чистый по интонации. Исключение: если в последнем есть запинка/фальш-старт — берём предпоследний целиком, а не склеиваем половинки из разных дублей.
- Перед сдачей — прогон текста на повторы: две одинаковые фразы подряд зритель ловит мгновенно.

## 4. Воздух и паузы

- Воздух ищем по провалам громкости голосовой дорожки (в готовом ролике музыка их маскирует — мерить надо ДО подкладки музыки, по чистому голосу).
- **Норма паузы между фразами: 0.15-0.35с.** Меньше — речь «слипается», больше — монтаж провисает.
- **Хвосты слов не подрезать.** Резать по реальному затуханию звука +0.08с, а не по видимой волне или авто-концу слова.
- Провал ≥2.5с без смены картинки закрывать графикой / стикером / панч-ином.

## 5. Каденция графики

- Каждая вставка ≤6с, и в ней всегда что-то движется (скролл, курсор, счётчик, медленный зум). Статичная картинка на 4с = мёртвый кадр.
- Короткие хиты, чередующиеся с лицом. Три цифры — это три вставки по 2-3с с лицом между ними, а не один дашборд на 8с.
- Старт вставки — на склейке или ≥1.5с после предыдущей.
- Конец — на склейке или ≥1с до следующей (иначе мёртвая вспышка лица <1с).
- Субтитр-карточка и графическая вставка не стартуют в один кадр — разносить на 200-300ms.

## 6. Тайминг анимаций

- Ревилы текста/титров: 400-800ms, держать <1с.
- Каскад (стаггер): 50-100ms между элементами.
- Вход: `ease-out`. Никогда `ease-in`, никогда `linear` на входе. Лупы/фон — `linear`.
- Мелкое = быстро, крупное = медленно.
- Отскок только на «живых» элементах (стикеры, pop-in субтитров), слабый 0.1-0.3.
- Не резкий `scale(0)` поп-ин — старт с 0.94-0.95× + прозрачность.

## 7. Не-обсуждаемое (ловится глазом зрителя мгновенно)

1. Нет дублей / повторов фраз — ровно один чистый дубль на реплику.
2. Нет фальш-стартов. Слушать стык, начинать с реального первого звука — в авто-транскрипте они не видны.
3. Нет обрезанных хвостов слов.
4. Нет мёртвого воздуха / статики ≥2.5с.
5. Нет сплайса посреди протяжной гласной.
6. Нет слоёв и вспышек лица короче 1с.
7. Нет субтитра-карточки, висящего дольше 4с.
8. Нет разрывов бегущей подписи — она идёт непрерывно весь ролик. *(правка 26.08.2026)*

## 8. Финальная проверка кадра

Останови ролик на характерном кадре в обычном размере телефона:

- Главный посыл читается за <1с? Один очевидный фокус?
- Текст не налезает на лицо, на края, друг на друга?
- Кадр имеет смысл, если мелькнёт долю секунды? Если нет — переделать.
