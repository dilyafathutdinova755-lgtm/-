# Delivery Specs — форматы, звук, safe-зоны, QA

Технические цели вывода. Команды зависят от редактора — важны ЦЕЛИ.

## 1. Форматы

| назначение | разрешение | соотношение | статус |
|---|---|---|---|
| TikTok / Reels / Shorts | 1080×1920 | 9:16 | основной, сюда идёт всё |
| YouTube (длинные) | 1920×1080 | 16:9 | по необходимости |
| Лента / промо | 1080×1080 | 1:1 | по необходимости |

## 2. Съёмка и fps

- Снимать 4K (2160×3840) — даёт запас на панч-ин / рекадрирование до 2× без потери резкости.
- Мастер: 1080×1920.
- **Выходной fps = fps исходника.** Не смешивать fps внутри таймлайна и не ресемплить отдельные куски — это даёт рассинхрон A/V.
- В части файлов встречается fps 60.0024 (`500000/8333`) — при импорте привести таймлайн к 60, а не к 59.94, иначе на минуте набежит рассинхрон.

## 3. Длительность

- Целевая: 45-60с. Замер роликов: 42-58с, медиана ~46с — рабочий коридор.
- Дольше 70с — только если тема реально требует.

## 4. Safe-зоны и субтитры

- Title-safe: ключевой текст ≥10% от каждого края. Action-safe: ключевая графика ≥5%.
- Боковые поля субтитров: ≥70px при ширине 1080.
- Нижние ~420px держим свободными от важного текста — там UI TikTok (описание, кнопки). Ключевая карточка — в полосе 55-75% высоты кадра.
- Верхние ~180px — зона иконок платформы, крупный текст туда не ставим. Бегущая подпись идёт ниже этой границы.
- Иконка приложения — графика, ей достаточно action-safe: поле ≥54px при ширине 1080.
- Никогда поверх лица и рта.

## 5. Звук

### 5.1 Громкость

Замер интегральной громкости 6 роликов серии:

| ролик | LUFS |
|---|---|
| IMG_3428 | −9.8 |
| IMG_3524 | −23.7 |
| c2eac… | −15.8 |
| copy_43ED… | −25.8 |
| copy_8DB6… | −23.5 |
| copy_DE42… | −28.8 |

Разброс 19 dB между роликами. Платформы нормализуют примерно к −14 LUFS: тихие ролики поднимутся вместе с шумом и музыкой, громкий (−9.8) будет прижат и зазвучит плоско.

**Целевой мастер: −14 LUFS integrated, True Peak −1.0 dBTP.** Нормализовать каждый ролик перед сдачей. Цель по TP при нормализации ставить −1.3…−1.4, иначе AAC-кодирование вернёт пик выше −1.0.

### 5.2 Микс (без дакинга)

Голос = 1.0, всё остальное просто тише. Голос не в лимитер.

| источник | уровень |
|---|---|
| музыка (BGM) | 0.10-0.12 |
| whoosh | ~0.11 |
| pop | 0.12-0.14 |
| ping | 0.10 |
| sparkle / chime | ~0.13 |
| notification | 0.15 |
| riser | 0.18 |
| impact | 0.24 |

Плейсмент SFX = моменты моушн-хитов: whoosh на входе вставки/пул-аута; pop на карточке субтитра и на цифрах; ping на стикере; riser нарастает в пейофф, impact на ревиле.

Монтировать и оценивать воздух надо на выключенной музыке, подкладывать её последней. Музыка — только своя / лицензионная / сгенерированная. Если музыка «бегает» по стерео, сузить ширину до ~55/45; голос всегда в центре, моно.

## 6. QA-чеклист перед сдачей (проходить каждый пункт)

### Речь и склейки
- [ ] Нет повторов фраз — по каждой реплике оставлен ровно один дубль (по умолчанию последний).
- [ ] Нет фальш-стартов в началах дублей (прослушать каждый стык).
- [ ] Хвосты слов целы (рез по затуханию +0.08с).
- [ ] Паузы между фразами 0.15-0.35с, нет провалов ≥2.5с.
- [ ] Нет сплайса посреди гласной.

### Звук
- [ ] Интегральная громкость −14 LUFS, пик ≤ −1.0 dBTP.
- [ ] Голос без дакинга, уровни по таблице §5.2.
- [ ] Музыка лицензионно чистая.

### Картинка
- [ ] Смена картинки в среднем каждые ~2с, нет статики ≥2.5с.
- [ ] Нет слоёв <1с и вспышек лица <1с между графиками.
- [ ] Нет субтитр-карточек, висящих >4с.
- [ ] Текст вне лица, поля ≥70px, нижние 420px и верхние 180px чисты.
- [ ] Акцент — голубой `#C9F5FF` (жёлтый сет только для вечерних съёмок), один сет на ролик.
- [ ] CTA один: «ссылка в шапке профиля». Ника и вотермарки в кадре нет.
- [ ] Первая треть не провисает — есть визуал в хук→метод.

### Субтитры и иконка *(добавлено 26.08.2026)*
- [ ] Бегущая подпись идёт непрерывно от первого кадра до последнего, без разрывов в паузах.
- [ ] Бегущая подпись стоит в одном слоте и по кадру не перемещается.
- [ ] Бегущая подпись не снимается под крупной карточкой — оба слоя идут параллельно.
- [ ] У бегущей подписи нет чёрной обводки.
- [ ] Межстрочный интервал в карточке 0.90 от кегля.
- [ ] Карточка непрозрачна на всём протяжении показа — замер яркости текста по кадрам, а не на глаз (кадр из середины карточки, не из первых 140ms).
- [ ] Иконка приложения крупная (260-300px), непрозрачность 100%, не в углу, вне лица.

### Ассеты
- [ ] Скриншоты приложений читаемы, без личных данных в кадре.
- [ ] Стикеров ≤3, без варпов и артефактов.
- [ ] Если использовалась AI-генерация — текст/лого на ней проверены покадрово.
