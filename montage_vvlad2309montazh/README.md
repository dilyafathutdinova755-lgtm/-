## Проверка на дубли (протокол §8)

Тот же герой и комната, что в **v.влад2209** (простая нейтральная стена, серый вязаный свитер) — визуальное совпадение с конкретным прошлым батчем запустило усиленную проверку:

- sha256 всех трёх новых файлов сверен со всеми 65 историческими hash-значениями по всей ветке, включая три файла v.влад2209 — совпадений нет.
- Длительности (17.324 / 20.930 / 18.690с) не совпадают с v.влад2209 (22.764 / 19.415 / 17.260с).
- Полный ASR-транскрипт сверен построчно с v.влад2209.

**Важное наблюдение (не дубль).** Три сюжета этой партии — по темам ровно те же, что и в `v.влад2209`: текстовый разбор ошибок (video1), игры на запоминание (video2), банк ФИПИ (video3). Это тот же самый герой, повторяющий тот же набор из трёх базовых офферов кампании, который уже несколько раз воспроизводился в этой сессии другими персонажами (`v.максим2209`, `v.сергей2209`, `v.дмитрий2209`, `v.никита2209`, `v.никита23092`). Построчное сравнение с транскриптом `v.влад2209` не выявило ни одной дословно совпадающей фразы — сценарии написаны заново:
- video1 здесь («на ЕГЭ легко закрыть много заданий и почти ничего не понять из решённого неправильно») vs vvlad2209 video2 («больше решённых вариантов ЕГЭ не всегда признак хорошей подготовки») — разная формулировка одной идеи.
- video2 здесь («материал часто держат в голове ровно до следующего повторения, потому что просто перечитывают, а не пытаются вспомнить сами») vs vvlad2209 video1 («иногда куда полезнее один раз нормально закрепить тему, чем в сотый раз решать новый вариант») — разный заход.
- video3 здесь («скачивать варианты ЕГЭ случайных источников — обычная практика, которая не всегда себя оправдывает») vs vvlad2209 video3 («если оценивать подготовку к ЕГЭ только числом решённых вариантов, легко обмануть самого себя») — разный угол подачи.

Дубликат по протоколу §8 не подтверждён, но это уже шестой раз за сессию, когда эти три темы повторяются (пятый раз — другими презентерами, здесь — тем же самым). Похоже на систематическое переиспользование одного набора офферов по всей кампании.
